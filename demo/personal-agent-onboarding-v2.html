Demo v2 设计说明 · 对话式 Onboarding

这一版改了什么

  • 一题一卡：不再把多题并排成一张表单卡；每题先由 Agent 流式说话，说完才出选项。
  • 全部可跳过：每一题（含模型 / 起名 / 称呼）都有「跳过这一题」，跳过不阻断流程、不影响后续题；跳过项在完成摘要与 Soul.md / User.md 里显式记为「未设置」。
  • 每题可自由输入：任何有选项的题都附「都不是，我自己说」，原话会原样写进 Soul.md / User.md。
  • 伪流式保留：逐字 + 标点停顿 + 段落间隔，提问与反馈都走打字机；打字期间可「跳过打字」。

回答 → 产出 的映射

  • 起名 → Agent 名（标题栏 / 会话列表 / 气泡来源 / Soul.md）
  • 称呼 · 身份 · 当前关注 → User.md
  • 角色 · 语言风格 · 主动程度 · 相处约定 · 性格速写 → Soul.md
  • 模型（厂商 / Base URL / API Key / 模型 ID）→ 大脑配置；本地 Ollama 免 Key

最小可用路径

全部跳过也能走完：仍会生成一份带「未设置」占位的 Soul.md + User.md 骨架与完成摘要，不是空壳。
