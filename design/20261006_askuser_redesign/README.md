## 装配核验记录（2026-10-06）

- **12 件套齐**：style-1/2/3 各含 mockup.html + light.png + dark.png + DESIGN.md，无缺件。
- **图片有效性**：8 张 PNG（三套 6 张 + before 2 张）均为 2560×1600（`sips` 实测），像素统计无纯白/空白图（灰阶 spread 174–239、uniq 163–211），逐张目检文字可读、按钮主次分明、无裁切、双主题同构。
- **渲染管线**：三套均按 BRIEF §7.1 逐字命令实渲（`shot.cjs`，非空白 probe + 主题真切 + ≥2KB 自检全过），零端口零进程、不碰 :8080。
- **① 去名渲染核验**：三套 Header 名字区均留空、气泡均无发送者名（N2/N3 口径 A 形态）；before 图保留「Nebula」现样作对照。
- **语言替换申报**：三套均**无**，沿用槽位语言。

## 口径与声明

- **落码时点**：作者对比选定其一后，才与 ①「未命名态去名」行为规格（BRIEF §3，index.html 顶部有摘要）同批落码；本包零代码改动，`src/` 零触碰。
- **文案零变更**：三稿产品固定文案逐字取 `src/main/resources/web/js/locales/zh-CN.js` 真源；场景 B 问句/选项词与 textarea 键入文本为合成演示内容（AskUser 卡本为动态注入、无固定真源，与 before 同口径，三稿 DESIGN.md 均披露）。
- **红线保持**：三套布局同源（BRIEF §1 同一内容结构），「每题必有跳过」只改形未删位，主题机制一律 `prefers-color-scheme` + CSS 变量（§7.2 级联红线）。
