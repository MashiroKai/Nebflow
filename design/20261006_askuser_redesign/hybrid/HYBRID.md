# HYBRID · 「纸上浮层」设计语言说明（1×2 杂交稿）

> 槽位性质：作者裁定方案 1×2 杂交——基底取 style-1「留白极简线框」的规整骨架，叠层取 style-2「轻浮层卡片」的浮层容器气质与幽灵座，主按钮取 style-2 品牌绿实底＋绿影。本位纯视觉稿，零仓内代码改动；文案逐字取 BRIEF §1.8 真源（场景 B 沿用 before 合成演示文，与 style-1 稿同内容对照）。

## 1 · 一句话总则

**浮层只做容器处理，内里控件守 style-1 的细线规整**：纸面（L0）与对话泡（L1）是平的细线世界；只有题卡与 AskUser 卡（L2）脱底上浮成柔影浮层；卡内一切控件回到纸上表格的纪律（透明底＋1px 细线，零投影）；唯一允许发光的是主行动按钮（L3）——品牌绿实底渐变＋绿影。高度差与线稿纪律同屏分工，互不越层。

## 2 · 分层合同（逐层来源申报）

| 层 | 元素 | 来源 | 关键参数 |
|---|---|---|---|
| L0 地面 | 纸面底色 | style-1 | 亮 `#fafaf8` / 暗 `#121419`，**平色无渐变**（平地更衬浮起） |

## 3 · 绿按钮 token（取 style-2 确切色值）

```css
--green:  #0ac065;   /* 品牌绿，亮暗两档恒定（style-2 原值） */
--green2: #069a4e;   /* 渐变深端（style-2 词表内的深档绿） */
--btn-ink: #ffffff;
--sh-btn: 0 2px 6px rgba(7,193,96,.30), 0 6px 18px rgba(7,193,96,.20);  /* 亮档绿影（style-2 原值） */
          /* 暗档：0 2px 8px rgba(7,193,96,.32)（style-2 原值） */
--ring:   0 0 0 3px rgba(7,193,96,.14);   /* 聚焦光环，亮档；暗档 .22（style-2 原值） */
/* 按钮体：linear-gradient(180deg, var(--green), var(--green2))，radius 12px，13.5px/600 白字 */
```

- 色相纪律：**全稿绿色只出现在主行动按钮与其同族的聚焦光环上**——meta 不加绿点、chips 不染绿、描边不泛绿，保住「每屏一个主行动」的最高对比读法（style-1 的去彩纪律在非主行动位全部保留）。
- 对比度实测读数（WCAG 相对亮度法）：

| 档 | 被测 | 对地面/卡面 | 读数 |
|---|---|---|---|
| 亮 | `#0ac065`（渐变顶端） | 对纸面 `#fafaf8` / 对卡面 `#ffffff` | **2.30 : 1** / 2.40 : 1 |
| 亮 | `#069a4e`（渐变深端） | 对纸面 | **3.50 : 1** |
| 暗 | `#0ac065` | 对深地 `#121419` / 对卡面 `#272c3a` | **7.67 : 1** / 5.80 : 1 |

- 判定与申报：暗档充足；亮档渐变顶端 2.30:1 系品牌绿（style-2 确切值，与现网 `--color-primary:#07c160` 同族同读数）的固有属性——在**不动 `--green` 确切色值**的前提下，本稿把亮档渐变深端在其词表内取到最深档 `#069a4e`（3.50:1），并以绿影外晕扩展可视边界；实渲双档中按钮均一眼可辨。若作者愿为亮档再让一步色值（如 `#07a854` 全底），是落码批的一行改动，候示。

## 4 · 幽灵座与题卡的咬合方式

1. **承卡泡去面**：题文泡不再画框——lead 句与题干以幽灵座形态直接坐在纸面上（style-2 手法），AskUser 卡则由幽灵座直托，卡外无任何中介框。
2. **内轴对齐**：幽灵座题文 `padding: 0 14px`，与浮层卡 `padding: 13px 14px` 的内容轴对齐——题干左缘与卡内 meta / 输入框左缘同一条竖轴，视觉上「文字是卡的引言」而非漂浮散行。
3. **间距咬合**：题干 → 卡 12px（style-1 泡内距律）；卡与卡之间沿用泡间 12px 节奏。
4. **影落纸面完成闭环**：卡底柔影（32px 级）落回平色纸面、并轻搭在下方邻卡顶缘——上层浮卡在物理上「罩着」下层，高度叙事由投影本身收尾，无需额外连接件。
5. **对比锚**：相邻的纯对话泡保持细线框（不上浮），平泡 × 浮卡同屏即现高度差——幽灵座因此不会与题卡打架，也不会让整屏失重。

## 5 · 梯队（半径 / 字号 / 主次）

- 半径梯队：卡 16（style-2 容器）＞ 绿钮 12（style-2 元素）＞ 输入框/虚线框 8（style-1）＞ chips 999 胶囊（两稿同构）——半径随离地高度递减。
- 字号梯队：meta 11px/字距 1.2 → 正文 14.5px/1.6 → 题干与问句 15px/600 → 钮 13.5px/600（题头小字、正文字号均 ≥ BRIEF §4.4 下限）。
- 主次梯：绿实底（主）＞ 细线控件（中）＞ 纯文字跳过/取消（次，可点且每题必有）。

## 6 · 主题机制与红线遵守

- 唯一主题机制 `prefers-color-scheme`；`:root` 定义全部变量，暗档 `@media` **只覆写 `:root` 变量值**，规则体一律 `var()` 引用（BRIEF §7.2 级联红线遵守）。
- 两档逐像素同构：布局、字号、间距、圆角零差；差异只在变量值（纸⇄墨反转、影深翻转、卡面换档、绿影收敛）。
- 截图：`pipeline/shot.cjs` 工艺实渲，1280×800 @2x，产物 `light.png` / `dark.png`（非空白 + 主题真切上断言全过）。
