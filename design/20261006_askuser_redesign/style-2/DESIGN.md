# style-2 设计语言：轻浮层卡片

本套沿用任务令给定的槽位语言「轻浮层卡片」（未替换），核心动作是把「高度」当作唯一的主次标尺：地面（L0）是一片近乎全平的浅灰纵向微渐变，对话气泡（L1）退为安静的薄片——白/深卡面、发丝描边、一层极轻投影；真正承载交互的题卡与 AskUser 卡（L2）则整体「脱底」上浮：16px 大圆角、上下轻渐变面（亮档 #ffffff→#f5f7fa、暗档 #272c3a→#1f232d）、发丝描边、双层柔和投影加一道顶缘内高光，且承载它们的题文气泡刻意做成无面「幽灵座」（去底色去投影），让卡片直接浮在地面上、与周边气泡拉开可见的高度差；主行动按钮（L3，「用这句」「✓ 确认」）取实色高对比——品牌绿实底微渐变加绿色投影，与描边幽灵态的「取消」、无底色的「跳过这一题」形成一眼可辨的三级梯次，chips 与选项按钮统一为白底描边小浮丸，输入框用低一度的内陷浅面、聚焦时翻白并亮绿描边加光环，层层只靠「离地高度 + 光」表达主次而不靠装饰堆叠。亮暗同构策略：同一份布局、同一套规则体，全部颜色与投影收进 CSS 变量，`prefers-color-scheme` 暗档只覆写 `:root` 变量值（遵守简报 §7.2 级联红线），暗档靠「更亮一档的卡面 + 更深的投影 + 更细的顶缘高光」复现亮档的高度叙事，品牌绿恒定不动，两档并排看是同一张桌面的白天与黑夜。与另两套的预期差异：style-1 留白极简线框走「去底色、纸上细线」，层级靠线与留白；style-3 气泡融合式让卡片长在气泡里、与对话流同材质同语态；本套则反向拉开材质差——气泡刻意退后成幽灵座、卡片作为独立浮层登场，观感是「界面上浮着一块精致面板」而非「一张纸」或「一句话」，表单感最弱化、控件精致感最强，是三套中唯一以投影高度差为核心语法的方案。（备注：场景 A 全部文案逐字取 zh-CN.js 真源；场景 B 问题与选项为合成演示内容（沿用 before 稿口径），「其他...／输入你的回答...／取消／确认」等固定文案逐字未动；全稿按去名规则渲染——Header 名字区留空、气泡无发送者名。）
