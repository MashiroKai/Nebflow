# style-3 · 气泡融合式（Bubble-Fusion）— 设计语言说明

> 首行申报：**未替换槽位语言**，沿用本位默认槽「气泡融合式」，无替换申报。

## 设计语言说明段

气泡融合式的答案是：不是「把卡做好看」，而是「让卡消失」——题卡不再是被 `.ask-card` 内衬盒（frame-hover 底 + 描边）框出来的第二层物件，它就是一段**结构化气泡**，与开场泡共用同一材质、同一 16px 圆角族（AI 泡同款左下 4px 尾角）、同一 whisper 描边与 1px 投影、同一 10px 纵向间距律，控件全部直接坐在泡壁上，于是题头（第一幕 · 见面 · 第 1 / 10 题）从「盒内小标签」弱化成一条发丝线加一枚 5px 绿点的**泡内行内静音标**（10.5px / 0.6px 字距，与现值同规格），输入框本身被塑造成一枚「还没长出来的小气泡」（14px 圆角、极浅 field 底、hairline 描边），候选 chips（星尘/洛书/阿涅/Nova/海豹）即「答案的雏形小泡」、选中即实心绿汇入对话流（picked 示形见「其他...」），主按钮（用这句 / ✓ 确认）是全卡**唯二实心绿**、与输入框同排同族圆角、带一点绿影前倾，跳过这一题则褪成右下角**无框无底的裸文本**——层级全靠「实心绿 → 描边小泡 → 裸文本」的材质落差表达，一眼可辨主次（每题必有跳过的红线只改形不删位）；亮暗同构策略：同一 DOM、同一布局、同一套规则体，暗档只在 `prefers-color-scheme` 里翻转 `:root` 的六组变量（bg / ink / dim / bubble / hairline / field，全部取自 base.css 现值），规则体一律 `var(--x)` 引用，绿 primary 双主题同值（#07c160，仓 token），仅绿影与发丝线换算到暗底；与另两套的预期差异：style-1 把卡从泡里拿出来退成「纸上的表格」（去底色、细线描边、大留白），style-2 把卡抬成泡之上的柔影浮层（大圆角、微渐变），style-3 反向收敛——信息架构一毫不动，视觉上**题 = 泡**，表单感归零、对话感最大化，三套在同一条对话流上会呈现为「表格 / 浮层 / 对话本体」三种本体论。
