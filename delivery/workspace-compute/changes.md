# 变更说明

## What

本批交付轻量 Git 工作树和多设备测试的设计。R1 在 macOS APFS 上用写时复制共享检出内容，并将提交时的源码冻结为远端测试可验证的输入。第一项作业支持把自足 Playwright 测试交给一台空闲设备，并支持在两台合格设备间分片。

## Why

同仓工作树已经共享 Git 历史。减小每次新增工作树的物理增量，能直接缓解并行开发的磁盘压力。让测试在独立设备上运行，还能绕开同机固定端口争用，为开发机腾出算力。

## Impact

使用者在项目中提交一次测试任务，可在同一处看到设备、输入版本和完整性。实施团队分别验收检出增量、开发机占用和整轮耗时，单列首次基线和后续可回收缓存。按读物化的原生后端和 Scala 套件进入 R2；本次交付仅描述目标行为。
