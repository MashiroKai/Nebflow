分词为什么不用向量检索？
头部「成果复用」节钉了三条约束：零依赖、禁驻守护进程、数据不出机。向量方案 ~90MB 模型 + 可能的 rerank 外判直接出局；落点是 SQLite FTS5 + bigram 影子列仿真（CJK bigram 与 BM25 k1=1.2/b=0.75 两个参数复用自 xerj）。
