# Nebflow 三位一体战略——《单窗口就已足够》

> 总叙事：单入口编排架构打破「并行性 ↔ 上下文连贯」权衡。用户只与 Nebula 一个窗口对话；Delegate/Mail/Flow/Team 把并行移入系统侧；纠偏闭环与两级记忆保障连贯。市场把编排复杂度暴露给用户（多会话/画布/多面板），我们把它消化在窗口背后。

## 实验设计核心（论文成败点）

**E2 三条件对比**：
1. Nebflow 单窗口编排（Nebula + Team/Flow）
2. 同模型多会话手动编排（模拟 Claude Code/Codex 使用模式）
3. 单 agent 直连（无编排 baseline）

**双指标**：横轴并行吞吐（任务完成率/时延）× 纵轴上下文连贯性（纠偏保持率/跨任务记忆命中）——假设：条件 2 并行高但连贯崩，条件 3 连贯但并行弱，**条件 1 唯一右上**。

**榜单即论据**：TB/SWE-V 是单 agent 榜——"单窗口编排系统打出 agent 直连成绩"本身佐证架构无损；Gaia2 A2A 补多 agent 维度。
