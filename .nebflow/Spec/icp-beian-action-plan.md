# neblink.space 腾讯云 ICP 备案全流程行动清单

> 调研时间：2026-08-17 ｜ 纯调研产物，不涉及代码改动
> 场景：neblink-server（Rust + docker compose，现 Vultr 203.0.113.10，国际链路 RTT ~272ms）拟迁腾讯云国内节点；neblink.space 将作为 NebLink（星络）主力域名

## 一句话结论

**.space 后缀可以备案（工信部 2018-12 批复）；个人备案全流程免费，总耗时约 2-5 周（取决于域名是否在境外注册商）；硬门槛只有三个：① 服务器在腾讯云大陆地域包月 ≥3 个月 ② 域名在境内注册商且实名所有者=备案本人 ③ 本人 +86 手机号微信做人脸核验。今天就能启动的是：查注册商 → 买服务器 → 发起域名转入（如需要）。**

## Part 1 六个调研问题的事实结论

### 1. .space 后缀备案可行性 —— ✅ 可行

- 工信部 2018 年 12 月正式批复 `.host / .space / .press / .website`（Radix 注册局运营，批文：信管函〔2018〕489 号），纳入国内域名管理体系，允许办理 ICP 备案。来源：[西部数码：顶级域名 .host/.space/.press/.website 正式通过工信部审批](https://www.west.cn/docs/194150.html)
- 阿里云、腾讯云、西部数码等主流接入商均开放 .space 备案通道，审核标准与 .com 无差异。来源：[快备网：.space后缀域名可以申请ICP备案吗](https://www.ksbaw.vip/html/yuming/2566.html)（第三方佐证）
- 官方可备案后缀清单自查入口：[工信部域名行业管理](https://domain.miit.gov.cn)（提交备案时腾讯云系统也会自动校验后缀）
- ⚠️ 两个例外：港澳台身份证备案时部分新后缀（含 .space）不可用；**北京管局**对个人备案使用新顶级域名历史上有额外限制，若你身份证是北京签发，提交前先在[各省管局要求](https://cloud.tencent.com/document/product/243/3474)查北京条目或直接咨询备案专员。

| 条件 | 具体要求 | 来源 |

| 域名 | ① 后缀在工信部批复列表（.space ✅）② 注册商在工信部公示名单内——**境外注册商（Namecheap/Cloudflare/GoDaddy 等）的域名不能直接备案，必须先转入境内注册商**（如腾讯云）；若已在阿里云等境内注册商，**无需转入**，只需完成实名认证 ③ 域名所有者实名信息 = 备案本人（姓名+证件类型+证件号码逐一比对）④ 实名完成满 3 个自然日（腾讯云注册）/ 3 个工作日（非腾讯云注册）才能提交订单 | [备案域名](https://cloud.tencent.com/document/product/243/18910)、[备案限制说明](https://cloud.tencent.com/document/product/243/18911) |

### 3. 个人备案：材料 / 时长 / 内容限制

**材料**（个人，全部本人）：身份证原件正反面拍照、本人手机号（**必须与腾讯云账号绑定手机号一致**）、邮箱、域名实名认证信息截图（在注册商处截取，含域名/所有者/证件号/过期时间）、部分省份需域名证书（内蒙古/湖南/天津）、若备案省≠身份证地址省，十余个省份需居住证（**建议直接选身份证省份备案，规避此项**）。来源：[备案所需材料](https://cloud.tencent.com/document/product/243/18914)

**核验方式**：已全面电子化——微信小程序（"腾讯云助手"）里完成**人脸视频核身**，不再用幕布拍照。核身要求：中国大陆 +86 手机号认证的微信号、纯白墙背景、定位须在备案省份、安静环境（部分省需朗读文字）。来源：[首次备案（小程序端）](https://cloud.tencent.com/document/product/243/37402)

**时长**（官方口径）：
| 阶段 | 时长 | 说明 |
|---|---|---|
| 提交订单 → 腾讯云初审 | 1-2 个工作日 | 专员电话核实（010-5610-xxxx 来电务必接听，未接 1 小时后再拨一次，再不接驳回） |
| 初审通过 → 工信部短信核验 | **24 小时内必须完成** | 12381 发送验证码，到 beian.miit.gov.cn 核验，超时订单退回 |
| 管局终审 | ≤20 个工作日 | 实际多数省份 1-2 周；结果短信+邮件通知 |
| **合计** | **顺利 7-15 天，保守 4 周** | |

来源：[如何快速备案](https://cloud.tencent.com/document/product/243/39038)、[首次备案](https://cloud.tencent.com/document/product/243/18958)

**内容限制（关键）**：
- 个人备案 = 非经营性。**网站名称**不能用"NebLink 官网/星络官网"这类措辞（含"官网"、公司/组织意味、纯产品名都易被驳回）；规范是 3 字以上、体现个人性质，如 **"星络研发日志""个人技术分享（设备互联）"**。来源：[网站命名建议](https://cloud.tencent.com/document/product/243/11740)
- 网站服务内容勾选"个人博客/技术分享"类即可；**不得出现**购买/价格/订单/收费/会员/广告投放等经营性元素。
- 我们"产品官网 + API + 开源软件下载"的定位：以**个人开发者作品展示 + 技术分享**的形态呈现（介绍自己开发的开源工具、放 GitHub 下载链接）通常可过；直接放本站二进制下载也普遍可过（属于个人作品分发），但页面不要有商业化措辞。若未来商业化（收费/订阅），需**变更为企业备案**（个人→企业变更备案官方支持，不用注销重来）。来源：[变更备案相关](https://cloud.tencent.com/document/product/243/19617)

### 4. 备案期间与通过后的规则

- **备案期间**：未取得备案号前，域名**不得通过大陆服务器开通 web 服务**（"备案成功并获取管局下发的 ICP 备案号后才能开通访问"）。实操含义：提交备案前**不要把 neblink.space 解析到腾讯云大陆服务器的 80/443**（会被腾讯云拦截并提示未备案）；域名不解析、或仅指向境外（Vercel/Vultr）则不受影响。当前 neblink.space 尚未建站，天然满足。来源：[如何快速备案](https://cloud.tencent.com/document/product/243/39038)
- **通过后**：页脚悬挂 ICP 备案号并超链接至 `https://beian.miit.gov.cn`（管局会不定期核查，未悬挂可处 5000-10000 元罚款）。来源：[备案号悬挂](https://cloud.tencent.com/document/product/243/76865)
- **公安备案**：ICP 通过后网站开通 **30 日内**办理（beian.mps.gov.cn，免费）。**豁免条款：网站仅提供 API 接口服务、无面向用户的网页内容，可暂不办理**——这对纯 API 子域方案直接适用。来源：[首次备案文档"ICP 备案后处理"](https://cloud.tencent.com/document/product/243/37402)
- **换服务器/换云商**：腾讯云**内部**换 IP/换实例不用重新备案；**跨云商**（腾讯云→阿里云）需在新云商做"接入备案"（原备案保留）；备案省份不可迁移（跨省需注销重备）。来源：[变更备案相关](https://cloud.tencent.com/document/product/243/19617)
- **解析核查**：已备案域名应保持至少一条解析指向腾讯云（防"空壳网站"清理），子域（如 api.neblink.space）指向腾讯云即可满足。

### 5. 官网策略：方案 A vs 方案 B

| | **方案 A：整域迁腾讯云（推荐）** | **方案 B：备案域只挂 API 子域** |
|---|---|---|
| 结构 | neblink.space（www 官网 + api/relay）全在腾讯云大陆服务器 | api.neblink.space / relay.* 在腾讯云；官网留 Vercel，用 nebflow.space 或其他域 |
| 合规性 | 完全干净：备案域有真实网站、备案号有处悬挂、接入关系真实 | 可行但有瑕疵：① 备案号悬挂义务要求"网站"有网页——纯 API 域无处挂备案号 ② 管局核查已备案网站可访问性/内容一致性时，主域名若解析到境外（Vercel）有被认定接入信息不实的风险 |
| 缓解措施 | — | 需在腾讯云放一个极简落地页（www 挂备案号），实际上就滑向方案 A；公安备案可用"API-only 豁免"，但一旦挂了落地页就应在 30 日内办公安备案 |
| 官网实现 | Vercel 静态站原样搬到轻量服务器（nginx/docker 托管），nebflow.space 可继续留在 Vercel 做海外线/兜底 | 官网零迁移成本 |
| 迁移成本 | 低（静态站复制 + 一台服务器跑 compose：nginx + neblink-server） | 极低 |
| 建议 | **采用**。一台轻量服务器同时跑官网静态页 + Rust API + WS relay，docker compose 原样迁移 | 仅当强烈想保持 Vercel 的开发体验时考虑，且务必加落地页 |

> 延迟收益：大陆节点对国内用户 RTT 约 5-40ms（对比现 Vultr 272ms），WS relay 长连接体验质变。

## Part 3 风险与易错点速查

1. **网站名称带"官网/产品名"** → 个人备案最常见的驳回原因。用"XX研发日志/XX技术分享"。
2. **短信核验超 24 小时** → 订单退回，重走初审。收到 12381 短信立刻处理。
3. **初审电话没接到** → 1 小时后重拨一次，再不接直接驳回。那两周保持手机畅通。
4. **域名所有者 ≠ 备案人** → 初审必驳。域名若在他人/其他主体名下，先过户。
5. **境外注册商直接提交** → 域名核验过不了，必须先转入境内注册商。
6. **服务器买 1 个月或按量计费** → 不满足备案条件，必须包月 ≥3 个月且大陆地域（香港节点不行）。
7. **备案中把域名解析到腾讯云大陆服务器开 web** → 被拦截，且可能留下不良记录。
8. **备案通过后长期无解析指向腾讯云** → 空壳网站清理风险，保持 api 子域在线即可。
9. **手机号/微信不满足条件** → 备案手机号 = 账号绑定手机号；人脸核验必须是 +86 微信。
10. **北京身份证 + .space** → 提交前核实北京管局对个人新顶级域名的现行口径。

## Part 4 需要用户拍板/提供的 3 件事

1. **neblink.space 当前注册商是哪家？**（决定走不走转入流程，影响总时间约 1-2 周）
2. **身份证省份？**（决定管局细则；北京需额外核实新后缀口径）
3. **服务器地域与规格确认**：建议 2C2G4M 轻量（上海或广州），年付；是否直接年付以拿折扣。
