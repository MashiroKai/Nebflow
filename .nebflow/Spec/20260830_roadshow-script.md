各位评委老师好，我们是 Nebflow 团队，来自中国科学技术大学。Nebflow 是一套多智能体协同与工作流执行平台。一句话介绍我们：我们解决的是 Agent 在垂直领域和复杂任务场景下交付质量不高的问题——让 Agent 不只是"能聊"，而是"能交付"。

## [页 3] 痛点总览

**讲稿正文**

现在市面上 Agent 产品很多，但真到干活的时候，三个问题普遍存在：第一，垂直领域交付质量低；第二，复杂任务下 Agent 容易偷懒；第三，多任务并行有上限。三个问题，我们一个个说。

## [页 4] 痛点① 垂直领域交付质量低

**讲稿正文**

先说垂直领域。以我们最熟悉的 FPGA 场景为例：FPGA 开发需要的训练数据少，通用 Agent 在这个领域基本没有经验积累，交付质量一般。垂直领域缺数据、缺专业经验，通用模型够不着——这是第一个痛点。

**页面提示**
- FPGA 开发场景示例图/代码界面截图【待定：放 FPGA 电路或综合布线界面】

## [页 5] 痛点② 上下文窗口限制，复杂任务 Agent 偷懒

**讲稿正文**

第二个痛点：上下文窗口是有限的。复杂任务一长，上下文装不下，Agent 就开始"偷懒"——跳过步骤、简化处理、糊弄过去，交付质量明显下降。任务越复杂，这个现象越严重。

**页面提示**
- 上下文窗口溢出/任务链条断裂的示意图
- 可配一句话：「上下文装不下，Agent 就偷懒」

## [页 6] 痛点③ 多工作流、多任务交叉，并行开发有瓶颈

**讲稿正文**

第三个痛点：多个工作流、多个任务交叉进行时，并行开发有上限。一方面人盯不过来，另一方面各个会话互相隔离，Agent 之间不知道对方在干什么——多开几个任务，质量就往下掉。我们实测过，人脑并行管理任务的经验上限大约 5 个。

- 数据：「人脑并行上限约 5 个」「Nebflow 可稳定跟踪 10-20 个任务，实测并发效率提升 200%~400%」（申请书实证）

## [页 7] 解决方案总览——统一调度与设计

**讲稿正文**

我们的方案，直接看产品。所有任务从一个统一入口进来，由系统在后台统一调度、统一设计：理解目标、拆解任务、分配给不同的 Agent 并行执行，再汇总结果。用户只需要提出目标，剩下的交给系统。

**页面提示**
- 产品界面演示/录屏（Web UI 主界面：单会话统一入口 + 任务面板）【待定：截产品真实界面】

## [页 8] 解决方案——Team：深化垂直领域应用

**讲稿正文**

我们有两个核心机制。第一个是 Team——"团队"。针对一个垂直领域，我们把不同角色、不同能力的 Agent 组织成一个团队，像组建一支专业队伍一样。比如给 FPGA 场景配一个专属团队，成员各有分工、协同作战，把垂直领域的活干深、干好。

- 可放 FPGA Team 的真实配置截图

## [页 9] 解决方案——Flow：自动管理复杂工作流

**讲稿正文**

第二个是 Flow——"流水线"。复杂工作流，比如代码审查、版本发布、研究调研，都可以固化成一条自动化流程：一个指令触发，全流程自动跑完，不需要人一步步盯着。复杂工作流的执行，从"人管"变成"系统管"。

## [页 14] 团队介绍

**讲稿正文**

团队方面，负责人开宇，地空学院行星科学与探测技术博士，做 FPGA 探测器电子学和束流实验，以第一作者身份在 NIM-A 等期刊发表论文；翟宸，物理学院物理电子学硕士；管致远，地空学院直博。我们大部分成员是天文、物理背景——做科研的人，最懂科研过程里 Agent 哪里不好用。

## [页 15] 战略路线

## [页 16] 融资诉求与里程碑

**讲稿正文**

我们的主要开销就两块：买大模型 token，和租服务器。token 按人头算，重度科研任务每人每月至少 3000 元——从每月几百元到上万元不等，取 3000 元是稳健估计；服务器是每月固定支出，一台 A10 GPU 约 3200 元/月，8C16G 云主机约 500 到 1000 元/月，按我们的规模一年 4 万元。整体融资诉求 20 万元，用途很清晰：token 和 API 10 万、服务器 4 万、测试 1 万，出版、文献和知识产权 2 万，会议差旅和路演 2 万，其他 1 万。

里程碑：9 月内测，10 月正式推出，10 月底目标 GitHub star 达到 1000、用户积累到 1000。

**页面提示**
- 预算结构图【数据已到位，可直接生成】：20 万 = token/API 10 万 + 服务器 4 万 + 测试 1 万 + 出版/文献/知产 2 万 + 会议差旅路演 2 万 + 其他 1 万（对应申请书科目：测试化验加工费 15 万 = token 10 + 服务器 4 + 测试 1；出版知产 2 万；会议差旅路演 2 万；其他 1 万，业务费合计 20 万）
- 服务器行情备注：A10 GPU ≈ 3,200 元/月、8C16G ≈ 500-1,000 元/月（阿里云 2026 公开活动价），与申请书「服务器 4 万/年」（≈3,300 元/月）口径吻合
- 里程碑时间轴：9 月内测 → 10 月正式推出 → 10 月底 star 1000 / 用户 1000
