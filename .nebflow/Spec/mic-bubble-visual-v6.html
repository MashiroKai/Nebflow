v6.0 重做（用户 08-25 23:58「麦克风 · 液态光球 重做，用kimi」）：不基于 v5 修补。① 结构收敛：v4/v5 的 11 层 additive 叠加（壳层/背光/核心/光斑层层相加）是层次互糊与浅色浑浊的结构性根因 → 重写为 8 个克制组件，每个组件职责单一、强度收敛。② Siri 液态感：内部着色从「角向渐变转圈」改为域扭曲 simplex 流体（p=uv+0.30·vec2(snoise,snoise)，双层频率 1.5/3.2）→ 蓝紫大理石纹自然流动。③ 晶莹感：pow(f2,5) 细亮丝（浅色 0.22/深色 0.30）+ 紧致高光 pow(N·H, 90深/140浅)（白心 ~2px@48px，比 v4 的 4px 再收一半）+ 小型底部焦散（0.30r0 范围、0.20/0.14 强度）。④ 浅色独立分支：显式 isLight uniform（JS 从 data-theme 直读，不再用 bgLuminance 启发式）——浅色=饱和度 ×1.28 + 暗部下压 0.50 + fresnel 向 c3·1.1 混 0.42（玻璃弹珠在白底上的全反射深边=定义感来源）+ 高光更小更亮（140/0.85）；全程零灰白稀释。⑤ halo 深色专属：浅色 shader 内 halo=0 且 CSS box-shadow 发光也关闭。⑥ 混合修正：输出改非预乘 alpha（v2-v5 的 rgb·a 预乘输出 + SRC_ALPHA 混合 = 边缘双重变暗 bug，一并修复）。
视觉闭环（本轮流程修复）：前 5 轮 design-engineer 从未真正看到渲染结果（v5 连 Read 图都被拒）= 盲调。本轮 vision preset = kimi/k3-256k，渲染 → 截图（深/浅）→ 亲自看图自评 → 调参 → 再看，迭代至观感达标再交付。自评记录见交付回报与 spec §11。
技术路线（v2 裁定保持）：WebGL shader 为生产主路径——~110 行 GLSL，48px 单球渲染 < 0.3ms/帧，RAF 常驻成本可忽略；同时可见最多 2 球 = 2 个 WebGL context（浏览器上限 8-16，安全）。CSS 液态分层作为 WebGL 不可用 / prefers-reduced-motion 降级。
状态叠加层（busy 绿光晕 / bg-agents 蓝轨道 / processing / error / offline）本轮不动，基础气泡本体质感确认后下一轮叠加——9 态枚举用户已认可，数据源全部现成（spec §9 保留）。frozen 材质（去饱和+霜环+「跳过本次」按钮）实现按 spec §3.1 保持。
动效可达性：prefers-reduced-motion: reduce 下降级为静止帧（RAF 停 + timeScale=0）。URL 参数 ?theme=light|dark 可指定初始主题（截图验收用）。
