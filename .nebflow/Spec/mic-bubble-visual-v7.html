v7.0 透明感修复（用户 08-26 打回 v6「还是缺少了透明感。参考我们第一版的obs，那多好看啊」）：不推翻 v6 结构，只把 v1 obs（jarvis orb）的透明机制重新融合进 v6 已收敛的 8 组件。① extractAlpha 透明感：alpha 由材质亮度导出（jarvis L1618 a=max(r,g,b)），v7 用 a=pow(max(rgb)·1.10,1.45)·shape——亮处实（高光/细丝/中心 α≈1）、暗处虚（暗部 α 低 → 背景透出 = 液态玻璃）。② 背景混合（jarvis L1662）：透明 canvas + 非预乘 SRC_ALPHA 混合，浏览器按 (1-a) 把背景色自动混入暗部——球是半透明液体不是自发光实心塑料。③ 背景亮度感知（jarvis L1640/1657/1664）：沿用 v6 显式 isLight 分支——深色少透（Siri 发光体量）+ 弱 halo 0.16；浅色更透明（a×0.90，多混背景）且保持 v6 提饱和宝石色 + 深边定义（不向白/灰稀释=不浑浊）。④ 预乘输出判定（jarvis L1682）：保持 v6 非预乘输出——v2-v5 的 rgb·a 预乘 + SRC_ALPHA = 边缘双重变暗 bug，v7 不回归；透明感全靠「暗部 α 低 + 背景透出」达成，不再靠预乘。⑤ 防空心：与 v3 空心剖面（中心 α→0）不同，v6 中心材质本就明亮（核心透光+流体）→ 亮度→α 中心实；另加轮廓膜 shape=1-smoothstep(r0·0.98,r0·1.14,len) 保证球是有边界的液体（不散成雾、边缘干净）。结构仍 8 组件（未回退 11 层）/ 域扭曲流体 / isLight 分支，全保留。
