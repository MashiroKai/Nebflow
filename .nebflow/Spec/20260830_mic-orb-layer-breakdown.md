## 0 · 一张图看懂「气泡由几层构成」

气泡表面看是「一个发光圆球」，实际由三类东西叠加而成：

```
┌─────────────────────────────────────────────────────────────┐
│ ③ JS 驱动层（J0 状态参数 / M 运动变换）——给每层喂参数、叠运动  │
│   ┌───────────────────────────────────────────────────────┐ │
│   │ ① WebGL shader 逐像素层（S1–S10）——真正画出气泡的层      │ │
│   │   ┌─────────────────────────────────────────────────┐ │ │
│   │   │ ② DOM/CSS 容器层（D1–D5）——气泡挂在哪、用什么容器   │ │ │
│   │   └─────────────────────────────────────────────────┘ │ │
│   └───────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

- **① S 层**：在 fragment shader 里逐像素算出来的亮度/颜色/alpha，是「可改的视觉层」主体。
- **② D 层**：DOM 容器，管命中区/大小/状态 class/点击波纹，跟「画得漂不漂亮」基本无关。
- **③ J/M 层**：决定「某状态下气泡长什么样 / 动不动」，改状态观感通常改这里。

**关键前提**：`v8.2.8` 已把 **C8 外圈光晕整段删除**（无代码）。若作者仍看到外圈荧光，说明**没跑 v8.2.8 或删得不彻底**，不是「该调光晕」——本文把这点单独标红（§5）。

## 2 · WebGL 逐像素层详解（每一层单独一节）

> 阅读方式：若某一层有「历次打回」标记，说明作者曾针对它反复改，**改它时务必先用真实渲染截图给自己看**（历史教训：design-engineer 曾 5 轮盲调，v6.0 起强制视觉闭环）。

### S1 · 液态轮廓（body radius）——决定气泡大小与有机摆动

- **是什么**：用 simplex 噪声调制半径，让球缘不是完美圆而是轻微有机摆动（液态感）。
- **代码**：`micOrb.js` L164（`nEdge`）、L170（`r0`）。
- **参数**：
  - `r0 = mix(0.56, 0.66, nEdge)`（uv 空间，r0≈0.61uv = 39px@64px canvas）
  - `nEdge = snoise3(vec3(uv*0.9, t*0.4))*0.5+0.5`；噪声频率 `0.9`，时间演化 `t*0.4`
- **可调旋钮**：
  - 半径区间 `0.56–0.66`（改小 = 球在 64px canvas 里变小，留更多空边）
  - 噪声频率 `0.9`（改大 = 边缘更碎/摆动更快；改小 = 更圆更静止）
  - 摆动时间速率 `t*0.4`
- **影响**：整体大小、边缘摆动幅度、以及 canvas 内留白。
- **历次关联**：v8.2.6 把 canvas 从 48→64px 并缩 `r0` 到 0.56–0.66（给 bloom 留场，虽然后来 bloom 删了，`r0` 保持 0.56–0.66）。**改 `r0` 会连带改变 S6 rim 环、S10 羽化带的绝对位置**（它们都以 r0 为参照）。

### S2 · 域扭曲流体（domain-warped fluid）——蓝紫大理石水流（核心「液态感」）

- **是什么**：双层 simplex 噪声做 domain warp，生成流动的蓝紫大理石纹——Siri 液态感的来源。
- **代码**：`micOrb.js` L171–177。
- **参数**：
  - warp：`w = (snoise3(uv*1.3+…), snoise3(uv*1.3+…))`，`p = uv + 0.30*w`（warp 系数 `0.30`）
  - `f1 = snoise3(p*1.5, t*0.40)*0.5+0.5`（频率 `1.5`，时间 `t*0.40`）
  - `f2 = snoise3(p*3.2+vec2(2.7), t*0.55)*0.5+0.5`（频率 `3.2`，时间 `t*0.55`）
  - 主色：`col = mix(c3*1.22, c1*1.04, smoothstep(0.20,0.80,f1))`
  - 二次混：`col = mix(col, c2, smoothstep(0.35,0.85, f1*0.5+f2*0.5)*0.55)`
- **可调旋钮**：
  - warp `0.30`（0–0.5，越大纹越扭曲）
  - 主色阈值 `smoothstep(0.20, 0.80, f1)`
  - c2 权重 `0.55`（0–1，越大越偏紫）
  - 频率 `1.5` 与 `3.2`（改大 = 纹理更密更细）
  - 时间推进 `t*0.40` / `t*0.55`
- **影响**：大理石纹理的**浓度/对比/流动感**——这是「液态感」最重的一层。改坏会让球像色块或糊成一片。
- **历次关联**：v4/v5 的角向渐变转圈曾经是「层次互糊、浅色浑浊」的结构性根因之一，v6 改域扭曲流体后解决。**别再退回角向渐变**。

### S3 · 晶莹细丝（ice filaments）——细亮纹

- **是什么**：`pow5` 锐化噪声 → 一条条细亮丝，模拟光在球内折射的晶莹感（**细纹，不是面状亮斑**）。
- **代码**：`micOrb.js` L178。
- **参数**：
  - `col += C_ICE * pow(f2, 5.0) * mix(0.38, 0.30, isLight)`
  - 幂次 `5.0`；幅度深色 `0.38` / 浅色 `0.30`；颜色 `C_ICE=(0.845,0.905,0.985)`
- **可调旋钮**：
  - 幂次 `5.0`（3–8，越大越细越锐亮丝越少；越小越粗越面状）
  - 幅度深 `0.38` / 浅 `0.30`
- **影响**：清透感 / 内部细亮丝数量与强度。**它依赖 S2 的 f2**（同一条噪声），改 S2 频率会连带改变细丝位置。
- **历次关联**：v6 用 `pow5` 细丝取代 v4 面状光斑（用户「光斑过大」打回点）。

### S4 · 体积明暗（volume shading）——3D 球感

- **是什么**：取球面法线 × 左上光源，中心受光、边缘转暗，让平面圆看起来是立体球。
- **代码**：`micOrb.js` L179–185。
- **参数**：
  - `R = r0*0.985`；`z = sqrt(R²-len²)`；`N = normalize(vec3(uv,z))`
  - `Ld = normalize(vec3(-0.42, 0.50, 0.66))`（光源在左上，uv.y 上正）
  - `diff = clamp(dot(N,Ld),0,1)`
  - `shade = mix(mix(0.65,0.65,isLight), 1.12, pow(diff,0.9))`
- **可调旋钮**：
  - 暗部下限 `0.65`（0.4–0.8，越低越立体/越暗，但别降太低否则暗部死黑）
  - 亮部 `1.12`
  - 幂次 `0.9`
  - 光方向 `Ld`（改左上 → 右上/左下，会移动明暗与高光、焦散位置）
- **影响**：3D 球感、暗部是否死黑（`0.65` = 保持明度的体积感）。**注意**：S7 高光和 S8 焦散都用同一个 `N` 和 `Ld`，改 `Ld` 会连带它们。

### S5 · 内核透光（core glow）——中心发光

- **是什么**：克制的发光芯，用「发射光」（不被表面明暗调制）模拟光从内部透出。
- **代码**：`micOrb.js` L186–188。
- **参数**：
  - `core = 1.0 - smoothstep(0.0, r0*0.58, len)`（核心半径 `0.58r0`）
  - `pulse = 0.88 + 0.12*snoise3(uv*2.2, t*0.8)`（缓动脉冲）
  - `col += mix(c1, C_ICE, 0.4) * core * pulse * mix(0.28, 0.20, isLight)`
- **可调旋钮**：
  - 核半径 `0.58r0`（0.3–0.7，越大中心发光越扩散）
  - 幅度深 `0.28` / 浅 `0.20`
  - 脉冲 `0.88±0.12`（噪声幅度）
- **影响**：「中心发光」强度——太小=空心感（v3 被裁定的「空心」），太大=过曝白心。
- **历次关联**：v3「实心」裁定后，中心亮度直接决定 alpha 是否实心（亮度→alpha 由 S10 导出）；v7 extractAlpha 让中心亮→中心实。

### S6 · 分主题边缘 rim（fresnel）——深色发光边 / 浅色宝石深边

- **是什么**：fresnel（掠射角亮边）。深色=发光边（Siri luminous）；浅色=朝深色混的宝石深边（白底定义感，不向白冲）。
- **代码**：`micOrb.js` L193–202。
- **参数**：
  - rim 在**收缩球** `Rf = r0*0.90` 上求值（`zf`/`Nf`），`fres = pow(1-clamp(Nf.z,0,1), 2.4) * (1.0-smoothstep(r0*0.92, r0*1.00, len))`
  - `rimBright = mix(c1, C_ICE, 0.5)`
  - 深色：`col += rimBright * fres * (1.0-isLight) * 0.50`
  - 浅色：`col = mix(col, c3*1.10, fres*isLight*0.50)` + `col += rimBright*fres*isLight*0.10`
- **可调旋钮**：
  - fres 幂 `2.4`
  - 收缩球 `0.90r0`（改为接近 1.0 会让 rim 骑跨 alpha 裙边 = 描边回归）
  - 衰减窗 `0.92–1.00r0`（**这是 v8.2.4 修「边缘抠图感」的关键窗**，改大=rim 露出轮廓外=半透明白描边）
  - 深边幅度 `0.50` / 浅暗边 `0.50` + 浅亮边 `0.10`
- **影响**：「发光边」亮暗边缘、以及**是否出现抠图白描边**。
- **历次关联**：**v8.2.4 边缘抠图感修复**（用户「边缘像抠图不干净」）——旧实现 rim 峰值 0.985r0 正落在 alpha 裙边带 0.96–1.05r0 上，亮边被 alpha 裁成半透明白描边。**改 S6 时别把 rim 放回轮廓外**。

### S7 · 收敛高光（tight specular）——左上小亮点

- **是什么**：紧致镜面小亮点（白心 ~2px@48px），是「光斑」但被收敛成小点而非大块亮斑。
- **代码**：`micOrb.js` L203–206。
- **参数**：
  - `H = normalize(Ld + vec3(0,0,1))`；`ndh = clamp(dot(N,H),0,1)`
  - `specHi = vec3(1.0,0.99,0.97) * pow(ndh, mix(90.0,140.0,isLight)) * mix(0.75,0.85,isLight) + C_ICE*pow(ndh,8.0)*0.10`
- **可调旋钮**：
  - 高光幂 `90`（深）/ `140`（浅）——**越大高光越小越紧**
  - 幅度 `0.75`（深）/ `0.85`（浅）
  - 次幂 `8.0`·`0.10`（加一圈微弱晕）
- **影响**：「光斑大小」。**这是用户三次打回的点**（v4 软斑 784px² → v6 收紧到 51px² 以下）。
- **历次关联**：**光斑过大打回**（v3/v4）——缩小幂让白心变小；改大幂=更小而紧。

### S8 · 底部焦散（caustic）——光透过球底聚焦

- **是什么**：光透过球底折射聚焦的柔和光斑（下中、弱光），是「玻璃签名」。
- **代码**：`micOrb.js` L207–209。
- **参数**：
  - `ca = 1.0 - smoothstep(0.0, r0*0.30, distance(uv, vec2(0.10,-0.42)*r0))`（位置 `(0.10,-0.42)`，半径 `0.30r0`）
  - `col += mix(c1, C_ICE, 0.3) * ca*ca * mix(0.20, 0.14, isLight)`（平方衰减）
- **可调旋钮**：
  - 焦散半径 `0.30r0`（0.2–0.45）
  - 位置 `(0.10,-0.42)`（uv.y 上正 → -0.42 是屏幕下方，略偏右）
  - 幅度深 `0.20` / 浅 `0.14`（平方）
- **影响**：底部「玻璃聚光」签名——太亮=光斑，太弱=丢清透。
- **历次关联**：v4 的「双轨道细碎光点」被 v6 收敛为「单枚底部焦散」，配合 v6「非面状光斑」裁定。

### S9 · 后处理校色（post-process color）——叠加全层之上

- **是什么**：对最终 `outCol`（以及供 alpha 用的 `colNoRim`）做整体提亮/提饱和 + `sat/lum` 链——这是「浅色浑浊 / 颜色浅一档」的全局开关。
- **代码**：`micOrb.js` L210–216（`col` 提亮/提饱和）、L224–230（`outCol` = `col`，然后 `sat*lum` 链）。
- **参数**：
  - `col *= mix(1.03, 1.12, isLight)`（整体亮度，深 `1.03` / 浅 `1.12`）
  - 浅色提饱和：`col = mix(col, mix(vec3(g0), col, 1.42), isLight)`（`1.42`）
  - `outCol = mix(vec3(gg), outCol, sat) * lum`（`sat`/`lum` 来自状态表 J0）
- **可调旋钮**：
  - 整体亮度 `1.03`/`1.12`
  - 浅色提饱和 `1.42`（1.0–1.6，越大越饱和越不「浑浊」）
  - 状态 `sat` / `lum`（来自 J0 状态表）
- **影响**：整体明暗/饱和。**这是「浅色浑浊」历次打回的核心层**（v5/v6 反复）。
- **历次关联**：**浅色浑浊打回**（用户「浅色模式下看起来很浑浊」）——v5 曾用 bgLuminance 灰白稀释导致浑浊，v6 改显式 `isLight` + 提饱和。**别再向背景灰白稀释**。

### S10 · 透明度 / 边缘羽化（alpha + shape skirt）——透明液态感 + 收边

- **是什么**：alpha 由体色亮度导出（extractAlpha），配合轮廓膜 `shape` 让暗部透出背景（液态玻璃）、边缘平滑羽化。
- **代码**：`micOrb.js` L231、L237–245。
- **参数**：
  - `glassA = pow(clamp(max(colNoRim.r, colNoRim.g, colNoRim.b)*1.06, 0.0, 1.0), 1.58)`（**extractAlpha**：亮实暗虚）
  - `skirtEnd = r0`（**v8.2.9 起随主体轮廓 rEdge**，原 1.06r0）；`shape = 1.0 - smoothstep(r0*0.90, skirtEnd, len)`（轮廓膜，0.90–1.0r0 羽化，止于主体视觉边缘）
  - `a = clamp(glassA*shape, 0, 1)`
  - `a = mix(a, a*0.94, isLight)`（浅色更透明）
  - `a = clamp(a + smoothstep(r0*0.80, r0*0.96, len)*shape*isLight*0.12, 0, 1)`（浅色边缘抬升 `0.12`，**gate by shape**）
- **可调旋钮**：
  - extractAlpha 幂 `1.58`（1–2，越小中段越透）
  - `colNoRim` 峰值乘子 `1.06`
  - `skirtEnd = r0`——直接收在主体视觉边缘（**v8.2.9，原 1.06r0**），任何层不超主体轮廓；放大 = 外圈（白底座/荧光/背景泄漏）回归
  - 浅色透明度 `0.94`（0.8–0.98）
  - 浅色边缘抬升 `0.12`（0–0.3，改大=浅色边缘更白更实）
- **影响**：透明液态感、边缘羽化宽度、以及**外圈会不会出现白底座 / 荧光环 / 方形抠图**。
- **历次关联**（整个 §10.8–10.11 都在这一层 + S6 上修）：
  - **v8.2.3 白底座**（skirt 0.98–1.14r0 收窄到 0.96–1.05r0）
  - **v8.2.4 边缘抠图**（alpha 从 colNoRim 导出 + 浅色抬升 gate by shape + rim 收进轮廓）
  - **v8.2.6 硬边**（canvas 48→64 + r0 缩 + 宽 bloom skirt，bloom 后被删）
  - **v8.2.8 外圈光晕移除**（skirt 收到 1.06r0 + 删 halo bloom）

## 3 · DOM / CSS 容器层详解

> 这是气泡「挂载」的层，管命中区/大小/状态 class/点击波纹。**WebGL 正常时 D4（css-orb）是 `display:none`**，只在 WebGL 失败/静止帧兜底。

### D1 · `.mic-orb-wrap`（index.html L245 / input.css L608–616）
- **作用**：状态 class 的挂载点（`s-idle`/`s-listening`…），以及 CSS 变量定义处（`--orb-base`、`--orb-gl0w`、`--orb-dot`）。
- **要改状态颜色**：改这里（9 态 class 在 input.css L703–711 各自设 `--orb-filter/--orb-glow/--orb-dot`，浅色在 L746–762）。**但这些变量只给 CSS 降级层 D4 和波纹用**；WebGL 主路径的颜色由 J0 状态表 + S2 调色板决定。

### D2 · `button.micbubble`（index.html L246 / input.css L617–630）
- **作用**：64×64 圆形命中区（触摸目标 ≥44px）。`aria-label` = 状态 · voice input（读屏）。`:focus-visible` 轮廓。
- **要改命中/焦点**：改这里。**要改气泡视觉，不改这里**（canvas 是 D3）。

### D3 · `canvas.orb-canvas`（index.html L247 / input.css L635–641）
- **作用**：**WebGL 主渲染**（`#mic-canvas`）。`aria-hidden`。
- **要改气泡外观**：改 S1–S10（shader）。canvas 大小在 `micOrb.js` L283 设置 `canvas.width = size*dpr`（size=64，dpr 2–3 超采样），CSS 尺寸 64×64。
- **缓存/黑球**：如果 canvas 渲染黑屏，多半是 shader 编译失败（`console.error` 会打 `[micOrb] shader compile error`）或 context lost（L585 切 CSS 降级）。

### D4 · `div.css-orb.orb`（index.html L248 / input.css L661–694）
- **作用**：CSS 液态降级球（WebGL 不可用 / 静止帧兜底）。`::before`（高光 L672–678）+ `::after`（细丝/焦散 `mix-blend-mode:screen` L679–689）。
- **注意**：这是**独立的 CSS 实现**，跟 S 层无直接绑定。作者若只改 shader 不看它，降级时样式会不一致。**改它 ≠ 改 S 层**。

### D5 · `span.orb-ripple`（input.css L645–654）
- **作用**：点击时瞬态生成的波纹（2px 描边 · 语义色 · scale 0.8→1.5 · 0.8s ease-out · reduced-motion 禁用）。动画毕移除（micOrb.js `spawnRipple` L659–670）。

## 4 · JS 驱动层详解（改「某状态的样子」主要改这里）

### J0 · 9 状态参数表（micOrb.js L62–72）
每个状态一个 `hue/sat/lum/rot/ts/scale`，`ts`=内部流体演化速率，`rot`=旋转 rad/s，`scale`=canvas 缩放。**这就是「某状态长什么样 / 动不动」的总开关。** 例如：
- idle：`0 / 1.00 / 1.00 / rot 0.05 / ts 0.5`（几乎静止 + 呼吸）
- listening：`-18 / 1.08 / 1.05 / rot 0.3 / ts 1.6 / vol`（偏青 + 音量震动）
- processing：`22 / 1.06 / 0.94 / rot 1.0 / ts 1.3`（旋转明显）
- frozen：`0 / 0.40 / 0.74 / rot 0 / ts 0`（去饱和置灰静止）

### J1 · 调色板（L83 / L69–71）
- `PAL_DEFAULT`：`a=(0.471,0.627,0.863)`（orb-blue）`b=(0.549,0.490,0.839)`（orb-violet）`c=(0.200,0.251,0.502)`（orb-deep）。
- 错误态（mic-error 红 / frozen-error 琥珀）用独立板，以 uniform `palA/palB/palC` 注入（v8.2.2 起），走同一晶莹结构。

### J2 · lerp 速率（L465–496）
- `hue 0.035`、`sat/lum/ts/pal 0.04`/帧（≈0.7s 颜色过渡，v8.1 裁定不突兀）
- `scale 0.08`、`hover 0.1`（jarvis 原值）
- `transitionPulse` 软启动（rise `0.3` → decay `×0.92`）

### M1–M4 · 运动变换
- **M1 音量震动**（L468/L434/L256–257）：listening 时 `hover` 由 RMS 驱动（`0.10+v·0.90`），`hoverIntensity` 1.4(listening)/1.0(其他)，在 `draw()` 前的 `mainImage` 里做 UV 双向正弦扰动。
- **M2 旋转**（L470/L252–254）：按状态 `rotSpeed` 旋转 uv（processing 1.0 / nebula 0.6 / listening 0.3 / bg 0.15 / idle 0.05 / L0 态 0）。
- **M3 stateScale + 呼吸**（L484/L519–526）：`listening 1.08 / processing 1.05 / nebula 1.03 / idle 1.0`，加 idle 专属呼吸 ±2%（7.9s），作用在 `canvas.style.transform`（**屏幕空间缩放**，会放大 S10 羽化带，V17 断言的 stateScale 修正即为此）。
- **M4 亮度脉动 + 切换脉冲**（L493–496/L474–482）：工作态亮度脉动（listening ±6%/1.6s · nebula ±5%/2.2s · bg ±3%/3.0s）；切换瞬间 `transitionPulse` 软启动脉冲。

## 6 · 关键红线 & 历史教训（改层前必读）

1. **C8 外圈光晕已无代码**（v8.2.8，`vec3 outCol=col;` L224）。若作者仍看到外圈荧光，**先确认跑的是 v8.2.8 且删干净**，而不是去「调光晕」。发光语义现由 **S6 fresnel** 承担。
2. **S10 skirt 端 = r0（主体轮廓）**（v8.2.9：原 ≤1.06-1.10r0 收紧到 r0，所有层不超主体视觉边缘）。v8.2.3 白底座 / v8.2.6 荧光环 / #17 背景泄漏的反复根因——skirt 超出主体轮廓就会出问题。
3. **S6 rim 收在轮廓内**（收缩球 `Rf=0.90r0` + 窗 `0.92–1.00r0`）。放宽窗/放回球面 = v8.2.4 抠图白描边回归。
4. **浅色走 S9 提饱和，禁止向背景灰白稀释**。v5 用 bgLuminance 混灰导致「浑浊」，v6 弃用后解决。
5. **改动后必须真实渲染截图 + 视觉自评**。v2–v5 五轮盲调是结构性教训，v6.0 起强制「渲染 → 截图 → 亲自看图 → 调参 → 再看」。**视觉评审需与 qa-frontend 的 DOM 断言交叉验证，绝不裸看图下 PASS/FAIL**。
6. **只读约束**：本文档为分析快照，**未改任何代码**。实施改动交 nebflow-project / nebflow-rust Frontend，设计评审归 design-engineer。
