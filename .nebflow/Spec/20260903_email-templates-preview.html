  • 中度字重（visual-style 裁定映射）：标题/验证码 600、署名 500、正文 400——突出靠字号与字距，不靠黑体。
  • preheader 隐藏首行「Your nebflow verification code is {{code}}…」优化收件箱列表预览。
  • 移动端无 media query（内联样式的现实）：600px 卡 width:100% 流式缩放 + 32px 内边距，375px 实测不破版；logo 28px 定宽在窄档不参与缩放，安全。
  • 字体栈英文优先（-apple-system / Segoe UI / Helvetica Neue / Arial）；纯英文文案不再依赖中文字体声明，Windows 客户端渲染更可控。

    { "usageType": "SignIn",         "contentType": "text/html", "subject": "nebflow sign-in code: {{code}}",        "content": "<Sign-in template source (§2 源码块)>" },
    { "usageType": "Register",       "contentType": "text/html", "subject": "nebflow sign-up code: {{code}}",        "content": "<Register template source (§3 源码块)>" },
    { "usageType": "ForgotPassword", "contentType": "text/html", "subject": "nebflow password reset code: {{code}}", "content": "<Forgot-password template source (§4 源码块)>" },
    { "usageType": "Generic",        "contentType": "text/html", "subject": "nebflow sign-in code: {{code}}",        "content": "<Sign-in template source, reused verbatim>" }
  ]
}
  • From 头最终渲染：nebflow <noreply@mail.nebflow.space>——发信别名 nebflow、发信地址为 DirectMail 实际发信域（作者 09-03 拍板）；mail.nebflow.space 需在 DirectMail 完成 SPF/DKIM 验证（建议加 DMARC）。
  • Logto connector-smtp 校验器强制 templates 必须含 SignIn / Register / ForgotPassword / Generic 四类；Generic 无独立场景，原样复用登录模板源码与 subject（D4 已确认）。
  • content 为完整 HTML 文档字符串，内含 {{code}} 占位符由 Logto 注入；粘进 JSON 时需转义为单行字符串（换行 → \n、引号 → \"）。
