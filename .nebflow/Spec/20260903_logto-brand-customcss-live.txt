     (docs 建议用 Live Preview + DevTools 复核 hash 类名)

   ⚠️ 版本前提: 以 svhd/logto 部署镜像实测为准
      确认项回填 (2026-08-27 部署实测):
      - S2 已解: Logto 前端把主题挂在 <body> 的 CSS Modules hash class 上,
        形态如 `eAa6M_light` (亮色观测实例) —— 即尾缀 `_light` / `_dark`。
        故暗色变量采用双层钩子: 首选 body[class$='_dark'] (跟随 Logto 自己的
        主题态, 含 isDarkModeEnabled 行为), @media (prefers-color-scheme)
        仅作无 class 场景兜底; body 层定义天然遮蔽 :root 继承, 无冲突。
      ========================================================================== */

   body 层定义天然遮蔽上面的 :root/media 兜底, 集合保持全量镜像。 */

  --nf-border: rgba(255, 255, 255, 0.08);
}
