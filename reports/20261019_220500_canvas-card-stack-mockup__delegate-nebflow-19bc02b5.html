设计规格

常态头（浏览器式标签行退役）

  • 当前文件名绝对居中（不随左右按钮组宽度浮动），配类型图标；有未保存编辑时名称前显绿点（沿用现状脏标记语义 .canvas-tab-label.dirty，色 = --color-primary）。
  • 右侧按钮组：叠卡圆钮（新）+ 既有面板收起钮。叠卡钮复用 markdown 浮动面钮（.canvas-source-toggle）同款语言：白底玻璃 + 细描边，图标线重 1.8，图标 = 三层叠卡隐喻；deck 打开时钮呈 sapphire 激活态（aria-pressed）。
  • 单文件 / 空态：叠卡钮置灰（无卡可翻）；空态标题显示「画板」。

叠卡选择模式

  • 进入：点右侧圆钮。卡组像食谱卡盒/rolodex 叠放：透视 1150px、消失点在上沿——前卡全显，后卡向上露边渐退、渐暗、渐小。
  • 滚轮：向下 = 下一张「翻上来」，向上 = 回翻；rAF 对卡组位置做指数趋近（惯性/液态过渡），翻动中卡片带 rotateX 弧线（翻上 / 翻落两个方向）。触控板小步滚动按阈值合并步进。
  • 选中：点击前卡 = 选中——该卡向常态头标题位收拢飞入并淡出，其余卡向后翻回，标题交叉淡入新文件名。
  • 退出：ESC / 点击卡组外空白 = 不选中直接退回常态。
  • 卡面内容：类型图标 + 文件名 + 脏标记点 + 预览缩略暗示（CSS mock：文条 / 网格 / 图片渐变 / 页面 / 流程图）；当前文件卡带 sapphire 描边环 + 「当前」徽标。
  • 键盘：↑/↓ 翻动、Enter 选中、Esc 退出（与滚轮同通路）。

关闭文件的安放（方案）

  • 主案 · 卡上关闭钮：悬停前卡浮现右上角玻璃圆钮（同面钮语言），点击关闭该文件（带收拢退出动画），卡组即时重排；关闭当前文件时自动激活相邻文件（与现状 closeTab 邻位切换语义一致）。
  • 扩展案 · 卡片右键菜单：玻璃菜单 =「引用当前页/选区 / 关闭 / 关闭其他」，承接现状 showCanvasRefMenu 能力面；面板类页签无可引用内容时 toast 提示（同现状 canvas.noRef）。demo 中两案均可试。

边界情况

  • 文件很多：卡组位置环形取模（最短路径绕回），首尾无缝循环，深处卡片淡出至不可见——demo 9 张卡可直接滚一圈验证。
  • 当前文件回归：进入叠卡时前卡即当前文件（sapphire 环 + 「当前」徽标）；选中即回归常态头。
  • 窄面板：宽度切到 340 档看退化形态——卡宽 88%、高度收窄、副信息与提示行隐藏、标题截断；叠卡交互（滚轮/点击/ESC）不变。
  • 单卡 / 空态：单卡时滚轮空转、点击仍可选中；全部关闭则退出叠卡并收起面板（demo 中把卡全关即可看到）。
  • 动效降级：prefers-reduced-motion 下惯性插值系数置 1（无过渡、位置直达），进出场仅留淡入淡出。

实现提示（已同步写入本页控制台）

  • 滚轮驱动 = wheel 事件（preventDefault + deltaMode 归一 + 阈值步进）+ 卡组浮点位置 rAF 指数趋近；卡片按「相对位置」逐帧映射 translate3d / rotateX / scale / opacity——纯 transform 透视栈，不需要任何 3D 库。
  • 落点映射（实施批参考）：#canvas-tab-bar → 常态头 .canvas-title；叠卡钮挂 .canvas-header 右侧按钮组；deck 层挂 #canvas-content 内（absolute inset 0，不遮头部）；数据源 = 既有 tabs Map（顺序即卡序），dirty 读 isTabDirty() 同源。
  • 既有能力面保留：preview/pinned 语义、右键「引用当前页」（收进卡片菜单）、面板开合 / overlay 形态、canvas-tab-closed/switched 事件、Ctrl+F 路由（activeCanvasPane 不受影响）。
  • 注意点：deck 层 overscroll-behavior: contain 防滚链；「OS 文件拖到标签条即开新签」（canvasdrop R6④）需要把 header 整条注册为替代落区；预览缩略为 CSS mock，实施时文本文件可用首行内容、图片用 objectUrl 真缩略。
