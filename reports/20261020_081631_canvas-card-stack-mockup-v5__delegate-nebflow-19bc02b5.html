v4 → v5 修订对照（作者两条修正）

作者：「①前景位要轮换（参考 v2 的动画）——v4 里第一张卡（当前 canvas）永远钉死在最前，滚轮只动背后的卡组，等于前景不参与擦洗。改成 v2 的环形轮换：滚轮 scrub 时卡片循环穿过前景位。②层叠按钮固定不动——堆叠按钮钉在固定位置（不随前景卡/卡组移动），永远是那个悬浮浮钮。」——源码内修订点带 [v5①][v5②] 标签。

#修正v4（旧模型）v5（新模型）
①前景位要轮换（参考 v2 的动画）第一张卡（当前 canvas）永远钉死在最前（d=0），滚轮只翻背后的环流——前景不参与擦洗v2 式环形轮换：环流含全部页签（active 在环首=前景位）；滚轮 scrub 时卡片循环穿过前景位——下一张从背后阶梯翻到最前，原前景卡（含 canvas 本尊）向下翻落、收进卡组，绕环一周后从背后回归。连续滚动=卡组像食谱盒一样整体轮转。整区缩放入场保留（点浮钮=canvas 缩成 85% 变成环的前卡）；进入之后擦洗即前景轮换；点前景卡=放大回满幅切成那个文件（canvas 在前景时点击=收回）
②层叠按钮固定不动浮钮挂 canvas 根（面板）子树内，随整区缩放一起缩成 85%浮钮移出 canvas 根子树、钉在 canvas 区固定位置（top 10 / right 12 不变）：不随前景卡/卡组/缩放移动，永远是那个 40px 悬浮浮钮（z-70 恒在卡组与面板之上）；点它=进入/退出堆叠态（DOM 可断言 panel.contains(fab) === false）

设计规格（v5 整区缩放 × 前景轮换模型）

常态（无卡组）

  • canvas 满幅显示当前文件，与现状逐像素一致；canvas 子树内不存在任何卡组节点，也不存在层叠浮钮（v5②：浮钮挂 canvas 区层，不属 canvas 根）。
  • 常态全 UI 无叉（v2①）；唯一入口 = 右上 40px 层叠浮钮，钉在固定位置。

整区缩放 + 露出卡组（点浮钮）

  • canvas 根缩放：0.3s 一次连续变换 translateY(8px) scale(0.85)——整个 canvas（头行名称条 + 内容）一起缩成堆叠前景位的卡（= 环的当前一张，初始即当前 canvas）；内容原样活着，只是被切小。
  • 后卡露出：其余卡与缩放后 canvas 同尺寸（85%），从其后上方错位升起：d=1 露出名称条上缘 ~22px，其后每级再上露 ~6px 成错位阶梯（食谱盒纵深）；配合 rotateX 微后仰（−1.6°/级）与逐级减淡压暗；无 translateZ、无逐级缩放通道（v4③ 同尺寸铁律不动）。
  • 浮钮不缩放（v5②）：浮钮在 canvas 区层，整区缩放/前景轮换全程保持 40px 原位，卡组态照常可点（再点=收回）。
  • 层级保证：canvas 在前景位时卡组层 z-5 恒在 canvas 根 z-10 之下（后卡垫在 canvas 背后）；环卡翻到前景位时卡组层瞬时抬 z-60（前卡盖过 canvas——此时 canvas 已翻落隐没）。

滚轮连续擦洗 = 前景轮换（v5①，照 v2 动画）

  • wheel 增量（deltaMode 归一）× 1/240 累进环形浮点位置 pos，rAF 指数趋近；滚多少动多少、向上滚回滚。键盘 ↑↓ 同通路 ±1。
  • 前景位 = 环里当前这一张（d=wrapDelta(r−pos, M)，d=0 即前景）：scrub 时下一张从背后阶梯翻到最前，原前景卡向下翻落、收进卡组（v2 翻落曲线：下坠 + 前倾 + 淡出），连续滚动 = 卡组像食谱盒一样整体轮转；绕环一周后从背后阶梯回归，首尾无缝。
  • canvas 本尊参与轮换：canvas 面板与它的环卡按同一位姿曲线交叉淡换——面板翻落时环卡接管翻落（face 交叉处位姿恒等，无跳变），环卡从背后回归前景位时面板接管。擦洗全程只浏览不换签，canvas 内容保持不动（藏在前景卡之下）。
  • 底部计数行实时显示「前景 n/N · 名 · 下一张 名」——前景位随擦洗易主，一眼可断言轮换生效。

点前景卡 = 放大回满幅换入（v4④ 编排原样）

  • 点击前景卡（|d|<0.5，或 Enter）：该卡从前景位放大回满幅（×1/0.85 恰铺 canvas 区）盖住 canvas，落位即换内容 + 标题交叉淡入 + canvas 根瞬时回满幅 + 原 canvas 以 ghost 缩回卡组深处（0.3s），卡组收回。全程 ~0.65s。
  • 点深处的卡（|d|≥0.5）= 翻到该卡（滚轮语义把它转到前景位，v1「点后卡翻到该卡」回归）；不直接换入。
  • canvas 在前景位时点击 canvas = 收回卡组（内容不变）。

关闭（划走 / ×，语义照 v2⑥/v4⑥）

  • 划走作用在前景面：canvas 前景 = 按住缩放态 canvas 拖（关当前页签，v4⑥ 原样）；环卡前景 = 按住该卡拖（关那个文件，v2⑥ 回归）。位移 ≥ 区宽 20% 或速度 ≥ 0.55px/ms 甩出，不足弹回。
  • 非前景卡被关（右键菜单）= 环流就地收敛：从环中摘除该卡、其余卡按环形序就地补位（相位保持，不整环重置）。
  • canvas（前卡）被关 = 邻位接管成新 canvas（同 closeTab），环流重置为新 canvas 前景。
  • × 在 canvas 头行右端（仅 canvas 前景位时可达）；右键菜单（引用/关闭/关闭其他）保留；全关收面板（右下重开）。

收回（v4⑤ + 轮换态衔接）

  • ESC / 点空白 / 点 canvas / 再点浮钮 = 卡组收回 canvas 背后 + canvas 根 scale→1 回满幅常态，内容不变。
  • 从轮换态收回（前景位非 canvas）：前卡与 canvas 面交叉淡化衔接（位姿瞬时归位 + 卡组 0.18s 淡出），无 face 跳变。

边界情况

  • 文件很多：环形取模（最短路径绕回），首尾无缝循环——翻过的卡沉到前景下方淡出，绕环一周后从背后阶梯回归；9 张卡可连滚一圈再滚回来（连续擦洗可逆）。
  • canvas 回归：canvas 本尊翻落后在环中随队轮转，scrub 回到环首（或绕环一整圈）即回到前景位；擦洗全程不换签，换入只由点前景卡触发。
  • 前景=canvas 的点击 = 收回卡组（内容不变）；前景=环卡的点击 = 放大换入该文件；深处卡点击 = 翻到该卡。
  • 窄面板：缩放态与后卡恒为 canvas 区 85%，切 340 天然自适应；只收排版（提示行隐藏、标题截断）；浮钮仍固定 40px 原位。
  • 单卡 / 空态：单卡时环只有 canvas 一张（擦洗无位移，计数行提示「仅此一张」），划走 / × 仍可关；全部关闭则收起面板。
  • 拖划与点击的界分：位移 <6px 判为点击（canvas 前景=收回、环卡前景=换入），≥6px 进入拖划且该次松手不触发点击；面板与前景卡两套拖划同参数。
  • 动效降级：prefers-reduced-motion 下惯性插值系数置 1、进出场仅留淡入淡出、交接交叉瞬时完成。
  • 浮钮恒定（v5②）：常态/卡组态/擦洗中/换入飞行中位置尺寸恒定（仅 aria-pressed 与禁用态变化），换入飞行中忽略点击防半程误触。

实现提示（已同步写入本页控制台）

  • [v4①②·沿用] 结构 = canvas 区（#canvas-panel 的 docked 容器）内两层兄弟：#deck-layer（背后卡组，透视容器）+ #canvas-panel（canvas 根）。canvas 子树内只有头行 + 内容，无任何卡组节点；deck-layer 非 panel 子节点可 DOM 断言。
  • [v5②] 浮钮移出 canvas 根子树：挂 canvas 区层（panel.contains(fab) === false 可断言），z-70 恒高于 deck-layer（z-5/.over z-60）与面板（z-10）；top/right 坐标与 v4 常态逐像素同位，全程不缩放不移位。实施落点：浮钮从面板层改挂面板的 docked 父级（canvas 区容器）。
  • [v4②] 整区缩放基姿常量单一来源：JS 注入 --stack-scale: 0.85 / --stack-shift: 8px，CSS .stacked、飞行落点（×1/0.85）、ghost 起点、面板驱动位姿全部同源。
  • [v5①] 环含全部页签：buildRing() 产出 ring[0]=active, ring[r]=TABS[(ai+r)%N]（v4 环不含 active → v5 含）；pos 浮点，d=wrapDelta(r−pos, M)，d=0 即前景位（初始 pos=0=canvas 前景）。
  • [v5①] 位姿双支：poseOf(d) d≥0 = v4 露边阶梯（peek 22·a₁+6·a₂、微后仰 −1.6°/级、无缩放通道、同尺寸铁律）；d<0 = v2 翻落（y 下坠 30a+40·sin(πa)、前倾 6a+30·sin(πa)、op 0.42/级衰减）——翻过的卡向下收进卡组，绕环从 d>0 回归。z 序按 |d|（500−ad·100），前景卡恒最高。
  • [v5①] canvas 面板驱动：面板位姿/透明度由 d₀=wrapDelta(−pos, M) 驱动——transform = 缩放基姿 ∘ poseOf(d₀) 相对量，alpha 交接窗：d₀∈(0.15,0.45) 渐入（环卡回归→面板接管）、d₀∈(−0.30,−0.10) 渐出（面板翻落→环卡接管），两表面位姿恒等、只有 face 交叉；驱动期间面板加 no-trans（逐帧直写不吃过渡），回前景位即清 inline 交还 CSS。deck-layer 的 .over（z-60）随 panelAlpha<0.995 自动抬/落。
  • [v5①] 环流就地收敛：非前景卡被关 = 从 ring 摘除 + 环形旋转把 active 转回环首（pos 同步减位移，全部卡位姿不变）+ 重挂 data-r——保相位不整环重置；canvas 被关才整环重置（pos=0，新 canvas 前景）。
  • [v4④·沿用] 换入 = 前景卡位姿 lerp → 满幅落点（scale ×1/0.85、y→0），期间 #deck-layer.over 抬 z-60；落位即换内容 + 标题交叉淡入 + canvas 根瞬时回满幅（no-trans）+ ghost 旧 canvas 缩回卡组深处。
  • [v4⑥·沿用] 划走 = 缩放态 canvas pointer 拖划（速度采样同 v3）；越阈甩出（外抛+13° 侧旋+淡出）→ settleClose 邻位接管 → canvas 带 .restore 弹性复位；[v5①] 环卡前景时同参数拖划作用于该卡（v2⑥ 回归），× = canvas 收拢淡出。
  • [v5①] 收回衔接：轮换态收回时面板位姿 no-trans 瞬时归位 + #deck-layer.collapse 0.18s 淡出 + 面板 alpha→1 交叉，然后解除缩放。
  • 实施落点（canvas.js）：常态头 = .canvas-title；浮钮挂 canvas 区容器（面板 docked 父级，不在面板子树）；整区缩放类（.stacked）加在 #canvas-panel 上；deck-layer 挂同容器内、面板之前；数据源 = tabs Map（环 = active 起环形序，含 active）；dirty 读 isTabDirty()；引用复用 refForTab()；关闭接管同 closeTab()。
  • 注意点：overscroll-behavior: contain 防滚链；canvas 区 overflow:hidden = 卡组舞台边界（翻落卡被区缘裁切是预期形态）；「OS 文件拖入开新签」落区 = 整个 canvas 区（含卡组态）；预览缩略为 CSS mock，实施时文本用首行内容、图片用 objectUrl 真缩略。
