设计规格（v2 修订后）

常态头（v2①）

  • 头行 只有居中文件名（类型图标 + 名称 + 脏标记绿点，沿用 --color-primary 语义）；无关闭叉——常态全 UI 不出现叉号。
  • 层叠浮钮：40px 玻璃圆钮，absolute 悬浮于面板右上（跨压头线，原叉的位置域），语言逐字对齐产品 .canvas-source-toggle（rest 0.6 透明度 / hover 全显）；deck 打开时呈 sapphire 激活态（aria-pressed），浮钮层级高于叠卡层、叠卡态仍可点（再点收起）。
  • 单文件 / 空态：浮钮置灰（无卡可翻）；空态标题显示「画板」。

叠卡模式（v2②③④⑤）

  • 进入：点浮钮。常态视图淡出，当前展示的卡原地成为堆叠前卡（环 + 「当前」徽标），其余卡从它背后展开成食谱卡盒（透视 1150px、消失点上沿，级联位移随卡高缩放）——当前卡是卡组一员且置顶在前。
  • 滚轮 = 连续擦洗：wheel 增量（deltaMode 归一）× 增益直接累进卡组浮点位置，滚多少动多少、可回滚；rAF 指数趋近做平滑跟随，无步进阈值。键盘 ↑↓ 同通路 ±1。
  • 卡面：顶部名称横条（徽标 / 图标 / 脏点 / 文件名 / 面板标 / ×）+ 下方预览缩略暗示；尺寸按 canvas 可用面积自适应占满。
  • 选中：点击前卡 = 选中——该卡向常态头标题位收拢飞入，其余卡向后收拢，标题交叉淡入。
  • 退出：ESC / 点空白 / 再点浮钮 = 其余卡收回当前卡背后，回到常态。

堆叠态关卡双路（v2⑥）

  • 划走：按住前卡左右拖，卡片跟手（带 rotateZ 侧倾）；松手时位移超过卡宽 ~20% 或甩动速度足够 → 沿拖行方向甩出淡出并关闭，不足则弹回原位。触屏 / 触控板同样可用（pointer events）。
  • 点 ×：前卡顶条右端 × 常显，点击收拢淡出关闭。两路关闭后均邻位接管（右邻优先，同现状 closeTab），卡组即时重排。
  • 右键菜单（引用当前页/选区 / 关闭 / 关闭其他）保留，能力面承接 showCanvasRefMenu。
  • 关掉全部卡 = 退出叠卡并收起面板（demo 里全关即可看到，右下角重开）。

边界情况

  • 文件很多：卡组位置环形取模（最短路径绕回），首尾无缝循环，深处卡片淡出至不可见——demo 9 张卡可连滚一圈再滚回来（连续擦洗可逆）。
  • 当前文件回归：进入叠卡时前卡即当前文件；选中 / 关闭当前卡后按邻位接管切换。
  • 窄面板：宽度切 340——卡自适应占满后自然收窄（v2④），仅提示行隐藏、标题截断；交互不变。
  • 单卡 / 空态：单卡仍可划走 / 点 ×；全部关闭则退出叠卡并收起面板。
  • 拖划与点击的界分：位移 <6px 判为点击（选中 / 翻到该卡），≥6px 进入拖划；拖划中不触发选中。
  • 动效降级：prefers-reduced-motion 下惯性插值系数置 1（位置直达）、进出场仅留淡入淡出，擦洗退化为直给。

实现提示（已同步写入本页控制台）

  • 擦洗驱动 = wheel（preventDefault + deltaMode 归一 + target += dy × 1/240 连续累加）+ rAF 指数趋近 pos += (target-pos)*(1-exp(-dt*10))；卡片按相对位置 d（环形取模）逐帧映射 translate3d / rotateX / scale / opacity——纯 transform 透视栈，不需要 3D 库。
  • [v2④] 尺寸自适应 = layoutCards() 量 deck-stage 可用面积写 --card-w/--card-h（宽留 36px、高留 34px 边），sizeK = cardH/252 缩放级联位移；宽度切换 / resize 触发重算。
  • [v2⑥] 划走关闭 = 前卡 pointerdown/move/up + 速度采样；越阈（位移 ≥ 卡宽 20% 或速度 ≥ 0.55px/ms）进甩出曲线（位移外抛 + rotateZ + 淡出），否则指数弹回；完成后走 closeTab 邻位接管。
  • 实施落点（canvas.js）不变：常态头 = .canvas-title；浮钮挂面板层（原叉位）；deck 层挂 #canvas-content 内（absolute inset 0，不遮头部）；数据源 = tabs Map；dirty 读 isTabDirty()；引用复用 refForTab()；关闭接管同 closeTab()。
  • 注意点：deck 层 overscroll-behavior: contain 防滚链；「OS 文件拖到标签条即开新签」（canvasdrop R6④）需把 header 整条 + 常态视图注册为替代落区；预览缩略为 CSS mock，实施时文本文件用首行内容、图片用 objectUrl 真缩略。
