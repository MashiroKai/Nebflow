# 映射规则推荐表（AskUser 社交腿答案回注 · 设计批）

原则：编号域不推翻既有拍板（B-1/B-2/B-3），批名是**标签不是寻址键**；新增解析臂一律白名单形（防误路由优先于便利）；推荐项标 ★，候拍项进开放问题清单。

## 表4 · 防误路由判据（点⑤）——推荐默认

| 判据 | 推荐 | 理由 |
|---|---|---|
| 拦截域 | ★ **白名单形**：编号形/`问.编`/短号/标签精确匹配/`0·他` 前缀/`取消问题`/`全文`，其余一律聊天透传 | B-2 既有拍板；「存在 pending 时任意文本都算答案」是误路由放大器（作者在问题未清时聊别事会被吞成答案），明确不做 |
| 身份 | ★ 作答资格 = 台账键命中 ∧ 渠道 allowlist 通过（二者与） | §7；点对点天然闸 |
| 拒收反馈 | 超界/单选违规/secret → 单条可读拒绝线，不钳制不猜 | 既有（`WeixinAskLeg.scala:93`、`:106`、`:100`） |
| 可撤销重答 | P0：不支持（已答槽位已消费，墓碑拒绝重复作答）；逃生门＝答错后 `取消问题` 对未答问仍有效 | 开放问题 #1 列「重答 N」机制候选 |
| 幂等 | 双通道先到先得；后到 hub 层 `unknown-request-id`、桥层墓碑、桌面翻面幂等跳过——三层面已有，零新增 | 设计文档 §6 |
