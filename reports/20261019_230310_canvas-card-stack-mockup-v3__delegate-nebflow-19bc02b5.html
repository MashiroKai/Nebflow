v2 → v3 修订对照（作者形变模型澄清）

作者：「交互全对，但我需要的是底部这个背景卡片，通过动画变成堆叠效果。而不是堆叠效果放在这个背景卡片之上。」——源码内修订点带 [v3①]…[v3⑥] 标签。

#澄清v2（旧模型）v3（新模型）
①画布本体=前卡.deck-layer 容器整体盖住内容（遮罩+模糊），卡组放在这层「背景卡」之上——两个分离的层次容器整个删除。常态视图本身就是堆叠前卡（face）；点浮钮 = 面板面「物化」（细描边+卡底+投影+圆角）并微后退让位（scale 0.89 / 下移 8px）——全程只有一张持续形变的画布面
②卡组从背后长出卡组在覆盖层内的 deck-stage 里展开，观感是「浮在背景卡上方」背后卡组层（z-10）恒在面板面（z-20）之下；展开 = 其余卡从面板上缘背后依次错位露边（食谱盒语言沿用 v2：消失点上沿、越深越往上往后退），不是在面板上方再浮一层
③scrub 驱动「面板+背后卡组」滚轮驱动覆盖层内卡组环流，前卡随擦洗易主滚轮增益/指数趋近照 v2 不变；驱动对象 = 面板前卡 + 背后环流整体——面板面恒居前不动，后卡在背后连续可逆环流
④选中 = 换面点击前卡选中，选中卡飞向标题位、覆盖层整体淡出点击后卡 = 该卡放大飞入面板位变成新内容面（内容随之切换）；旧内容卡以 ghost 缩回卡组；卡组收回面板背后回常态
⑤划走 / 卡顶 × 照 v2拖前卡甩出关闭；叉在前卡顶条右端划走对象 = 面板前卡（甩出=关当前页签，邻位接管后面板面回弹复位）；「卡顶 ×」落在前卡顶缘右上角（仅 deck 态；常态全 UI 仍无叉）
⑥收回路径ESC / 点空白 / 再点浮钮 = 覆盖层淡出回常态同三路语义不变，几何重锚：卡组收回面板背后、面板面解除物化回无缝常态（无容器淡出感）

设计规格（v3 形变模型）

常态（无卡组）

  • 面板 = 头行居中标题 + 内容面。内容面就是前卡：无描边、无投影、无圆角、scale 1——与现状面板内容逐像素一致（face 无 chrome）。
  • 常态全 UI 无叉（v2①）；唯一入口 = 右上 40px 层叠浮钮。DOM 里不存在任何覆盖容器（v2 的 .deck-layer 已删）。

物化 + 长出卡组（点浮钮）

  • 面板面物化：0.3s 连续形变——浮现细描边 / 卡底（比面板玻璃更实一档）/ 投影 / 14px 圆角，同时微后退让位（scale 0.89、下移 8px），上缘腾出露边带。
  • 卡组长出：其余 N−1 张卡从面板正背后（op 0）沿上缘错位升起：d=1 露出名称条上缘 ~33px，其后每级再上露 ~7px 成错位阶梯，越深越往后（translateZ 负深度 + rotateX 后仰，消失点上沿）且逐级减淡；spread 0→1 双轴独立于擦洗位置。
  • 层级保证：卡组层 z-10 恒在面板面 z-20 之下——任何时刻卡组都「长在面板背后」，绝无浮于面板之上的观感。

滚轮连续擦洗（v3④）

  • wheel 增量（deltaMode 归一）× 1/240 累进背后环流浮点位置，rAF 指数趋近；滚多少动多少、向上滚回滚。键盘 ↑↓ 同通路 ±1。
  • 面板前卡不随擦洗易主；底部计数行显示「当前 n/N · 下一张 名」——被翻的是背后那摞。

选中换面（v3③）

  • 点击后卡（或 Enter 选最上后卡）：该卡从露边位放大飞入面板位（0.32s，渲染层级瞬时抬升盖过面板面），旧内容面同步减淡。
  • 落位瞬间：面板内容与标题切换为该卡；飞入卡卸除；旧内容卡以 ghost 从面板位缩回卡组深处（0.3s）；卡组收回面板背后，面板面解除物化回无缝常态。全程 ~0.65s，一气呵成。

关闭（v3⑤，语义照 v2）

  • 划走：按住面板前卡左右拖（跟手 + rotateZ 侧倾）；位移 ≥ 卡宽 20% 或速度 ≥ 0.55px/ms → 沿拖行方向甩出淡出并关闭当前页签，不足则弹回。邻位接管（右邻优先，同 closeTab）后面板面从甩出位姿回弹复位。
  • 卡顶 ×：前卡顶缘右上角 ×（仅 deck 态显示），点击收拢淡出关闭当前页签。后卡关闭走右键菜单「关闭」。
  • 右键菜单（引用当前页/选区 / 关闭 / 关闭其他）保留；关掉全部卡 = 收起面板（右下重开）。

收回（v3⑥）

  • ESC / 点空白 / 点面板面 / 再点浮钮 = spread→0 卡组收回面板背后，面板面解除物化回常态，内容不变。

边界情况

  • 文件很多：背后环流环形取模（最短路径绕回），首尾无缝循环，深处卡片淡出至不可见——9 张卡可连滚一圈再滚回来（连续擦洗可逆）。
  • 当前文件回归：旧内容卡缩回卡组后固定落在最上露边位（下一张），再开卡组它就在手边。
  • 窄面板：前卡与卡组 = 内容区本身，切 340 天然自适应；只收排版（提示行隐藏、标题截断）。
  • 单卡 / 空态：单卡时卡组为空（计数行提示「仅此一张」），划走 / × 仍可关；全部关闭则收起面板。
  • 拖划与点击的界分：面板面位移 <6px 判为点击（= 收回卡组），≥6px 进入拖划；后卡点击即换面。
  • 动效降级：prefers-reduced-motion 下惯性插值系数置 1、进出场仅留淡入淡出。

实现提示（已同步写入本页控制台）

  • [v3①] 结构 = #canvas-content 内两层：#deck-stage（z-10 背后卡组，透视容器）+ .face（z-20 面板前卡）。常态 face 无 chrome；deck 态加 .as-card（CSS transition 0.3s 完成物化+让位）。v2 的 .deck-layer 容器整个不存在。
  • [v3②] 卡位姿 poseOf(d)：y = −(24·a₁+9·a₂)·sizeK（a₁=min(d,1)、a₂=max(0,min(d,4)−1)，y 步进须压过半高收缩才有错位阶梯），z = −90·min(d,4)·sizeK，rotateX 后仰，scale 0.886 起 −0.016/级，op 自 d>0.5 线性衰减——v2 食谱盒曲线改锚面板上缘；spread 只缩放位姿轴（前卡不参与）。
  • [v3③] 换面 = 选中卡位姿 lerp→面板基姿（translateY 8 / scale 0.89，与 .as-card 逐值对齐），期间 #deck-stage.over 抬 z-30；落位即 renderFace() 换内容 + 标题交叉淡入 + ghost 旧卡缩回；结束清场回常态。
  • [v3⑤] 划走 = 面板面 pointer 拖划（速度采样同 v2）；越阈甩出（外抛+13° 侧旋+淡出）→ settleClose 邻位接管 → 面板面带 .restore 弹性复位；不足阈弹回。× = 面板面收拢淡出。
  • 实施落点（canvas.js）：常态头 = .canvas-title；浮钮挂面板层（原叉位）；face 即现 #canvas-content 内容容器加形态类；deck-stage 挂其内 z 更低；数据源 = tabs Map（卡序 = active 起的环形序）；dirty 读 isTabDirty()；引用复用 refForTab()；关闭接管同 closeTab()。
  • 注意点：overscroll-behavior: contain 防滚链；「OS 文件拖入开新签」落区 = 整个面板（含卡组态）；预览缩略为 CSS mock，实施时文本用首行内容、图片用 objectUrl 真缩略。
