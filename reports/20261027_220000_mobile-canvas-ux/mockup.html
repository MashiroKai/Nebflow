会议纪要.txt

10-27 例会：手机端 Canvas 关闭/切换/滑动交互重做。横滑语义统一为「切卡」，关闭单卡收敛到显性 X，整叠收起走抓手/底部收起钮。

操作条‹ › 页点 收起
热区全部 ≥44px

别扭点 → 新交互

  • 关闭入口不明 → 底部操作区常驻「收起」钮（⌄）+ 抓手下滑（阻尼跟手，≥120px/快甩收起）+ 卡头下滑，三条显性通路；X 只管关单卡，语义不再混淆。
  • 切换要几步/方向怪 → 横滑任意处=切上一/下一张（轴锁 10px、阈 56px 或快甩，跟手位移 + 邻卡名边缘预览）；旧「卡头上滑换卡」退役。
  • 左右滑=关卡（破坏性误触） → 横滑语义统一为切卡；26px 隐形侧缘删带退役，关卡只走显性 X。
  • 页码不可见 → 底部条页点指示（当前点拉长胶囊高亮，tap 跳卡；卡多时退化为 n/N 计数）。
  • 热区 <44px → 卡头 X 28px→44px（视觉圆 30px 不变，热区放大），切换条四钮全 48px。
  • 双标题重复 → 手机层隐藏桌面 .canvas-title，卡头只留一份标题。
  • 单手可达 → 切换条坐落底部（拇指区），与桌面胶囊/卡片同一 frosted 玻璃族。

保留（已好，不动）

  • 底部抓手下滑收起（跟手+回弹）、卡头下滑收起、长按卡头浮引用钮、独立/合并钮、入场 spring。
  • 内容区纵向滚动零劫持；内部横向滚动器（代码块等）优先原生。

验收（spec 钉）

  • 横滑左/右 = 下一/上一张，页点同步；单卡不切。
  • 抓手/卡头下滑收起，状态保留可再开；底部「收起」钮同效。
  • X 关单卡落邻卡；末卡关后收层。横滑永不关卡。
  • X 与切换条按钮命中盒 ≥44px；桌面端胶囊行为零漂移。
