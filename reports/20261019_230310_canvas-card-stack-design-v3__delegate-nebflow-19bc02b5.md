## 一、v2 → v3 修订对照（作者形变模型澄清）

作者澄清（附截图）：「交互全对，但我需要的是底部这个背景卡片，通过动画变成堆叠效果。而不是堆叠效果放在这个背景卡片之上。」——v2 的模型是「一层覆盖容器（遮罩+模糊）盖住内容、卡组放在容器里」，作者要的是「内容面板本身就是堆叠前卡，卡组从它背后长出来」。与移动端 v3「万物从圆钮里长出来」同语言：**万物从画布长出来**。

| # | 澄清 | v2（旧模型） | v3（新模型） |
| --- | --- | --- | --- |
| ① | 画布本体=前卡 | `.deck-layer` 容器整体盖住内容（遮罩+模糊），卡组放在「背景卡」之上——两个分离层次 | **容器整个删除**（DOM 中不存在）。常态视图本身就是前卡（face，无 chrome、scale 1，与 v2 常态逐像素一致）；点浮钮 = 面板面「物化」（细描边+卡底+投影+14px 圆角）并微后退让位（scale 0.89 / 下移 8px）。全程只有一张持续形变的画布面 |
| ② | 卡组从背后长出 | 卡组在覆盖层的 stage 里展开，观感是「浮在背景卡上方」 | 背后卡组层（z-10）恒在面板面（z-20）之下；展开 = 其余卡从面板上缘背后依次错位露边（食谱盒语言沿用 v2：消失点上沿、translateZ 负深度、rotateX 后仰、逐级减淡）——不是在面板上方再浮一层 |
| ③ | scrub 驱动「面板+背后卡组」 | 滚轮驱动覆盖层内卡组环流，前卡随擦洗易主 | 增益（1/240）/ 指数趋近照 v2 不变；驱动对象 = 面板前卡 + 背后环流——**面板面恒居前不动**，后卡连续可逆环流；计数行改「当前 n/N · 下一张 名」 |
| ④ | 选中 = 换面 | 点前卡选中，选中卡飞向标题位、覆盖层整体淡出 | 点后卡 = 该卡**放大飞入面板位变成新内容面**（内容随之切换、渲染层级瞬时抬升盖过面板面）；旧内容卡以 ghost **缩回卡组**；卡组收回面板背后回常态（全程 ~0.65s） |
| ⑤ | 划走 / 卡顶 × 照 v2 | 拖前卡甩出关闭；叉在前卡顶条右端 | 划走对象 = 面板前卡（甩出=关当前页签，邻位接管同 `closeTab`，面板面 `.restore` 弹性复位）；「卡顶 ×」落在前卡顶缘右上角（仅 deck 态；常态全 UI 仍无叉，v2① 不变） |
| ⑥ | 收回路径 | ESC / 点空白 / 再点浮钮 = 覆盖层淡出 | 三路语义不变，几何重锚：spread→0 卡组收回面板背后、面板面解除物化回无缝常态（点面板面亦收回） |

## 二、v3 形变模型细节裁定（实施批注意）

- **结构**：`#canvas-content` 内两层——`#deck-stage`（z-10，背后卡组，透视容器）+ `.face`（z-20，面板前卡）。常态 face 无 chrome；deck 态加 `.as-card`（CSS transition 0.3s 完成物化+让位）。z 关系是硬保证：任何时刻卡组都在面板面之下，绝无「浮于面板之上」的观感。
- **换面飞行的层级技巧**：飞行/ghost 期间 `#deck-stage.over` 瞬时抬 z-30（无过渡、瞬时切换），让飞入的卡盖过面板面；此时其余卡 op≈0（spread→0 已收回）不受影响，落位后移除。
- **ghost 旧内容卡**：落位瞬间 `renderFace()` 换内容 + 标题交叉淡入，旧 tab 以卡实体从面板位缩向卡组深处（y −30 / z −110 / 减淡，0.3s）后清场——「旧内容卡缩回卡组」的可见落点；环流重建时旧 tab 固定置于最上露边位（d=1），再开卡组它就在手边。
- **露边阶梯的几何铁律**：卡级联的 y 步进必须**压过半高收缩**（scale −0.016/级 ⇒ 半高收 ~3.3px/级），否则深处卡的顶缘永远藏在上一张背后、级联塌成单条露边（v3 初版 5·sizeK 步进即踩此坑，截图验收拦下后改 9·sizeK，每级净露 ~7px）。上限由 op 衰减（d>0.5 线性衰减）兜底：露边带最深 ~50px，不侵头行标题带（46px 头行，卡顶最深探入其透明下缘且 op 已 <0.4，断言 A2 覆盖）。
- **前卡基姿常量单一来源**：`FACE_BASE = 'translateY(8px) scale(0.89)'` 与 CSS `.face.as-card` 逐值一致，飞行落点 `FACE_LAND` 同源——三处（CSS 类、飞行 lerp 终点、拖划/FX 内联基姿）必须同步改，实施批建议由 CSS 变量承载。
- **互斥与守卫**（v2 §二全量继承）：`finalizing`（换面/关闭进行中）+ `selFly/ghostFx/faceFx/drag` 任一活跃时，滚轮 / 键盘 / 浮钮 / 二次关闭全部忽略；`prefers-reduced-motion` 下双轴插值系数置 1、FX 时长 0.05s、过渡 0.01s。
- **实施批落点更新（canvas.js）**：常态头 = `.canvas-title`；浮钮挂面板层（原叉位）；**face = 现 `#canvas-content` 内容容器加形态类**（`.as-card`）；`deck-stage` 挂其内 z 更低；数据源 = `tabs` Map（卡序 = active 起的环形序，不含前卡）；dirty 复用 `isTabDirty()`；右键「引用当前页」复用 `refForTab()`；关闭接管同 `closeTab()`。`overscroll-behavior: contain` 防滚链；「OS 文件拖入开新签」落区 = 整个面板（含卡组态）。

**过程中被验收拦下的两处实施问题（已修）**：
1. **CSS 改名遗留**：常态内容容器由 `.viewer-mock` 改 `.face-inner` 后，`.v-head` 图标尺寸选择器未随改 → 图标以自然尺寸渲染撑满整个面板（截图 01/02/08 直接可见）。教训：容器改名时同前缀的选择器组要整组迁移，截图验收必须覆盖「常态」这个最朴素的状态。
2. **级联塌陷**：初版 y 步进 5·sizeK/级 ≈ 半高收缩量，深处卡顶缘完全藏进上一张 → 露边只剩单条，「错位露边」消失（截图 02 可见）。改 9·sizeK 后每级净露 ~7px 呈阶梯。见 §二「几何铁律」。

**环境注**（继承 v2）：无头 chromium rAF 实测 ~36fps，指数趋近收敛时间按比例拉长，自动化等待 ≥2.4s；真实浏览器 60fps 无此现象。
