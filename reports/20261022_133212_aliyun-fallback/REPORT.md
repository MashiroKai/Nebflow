# 阿里云 fallback 调研报告（mystand.space 托管备选）

调研日期：2026-10-22 ｜ 性质：纯桌面调研（无服务器操作、无购买）｜ 所有价格为检索时点数据，以购买页实时价为准。

## 结论先行

**mystand.space（auth/link 服务，面向全球 GitHub 安装用户，国际可达是硬需求）若留在阿里云体系：国内节点不可行（ICP 备案强制 + 国际链路差"双杀"），唯一可行档位是中国香港节点。**

- **备案**：对外 Web 服务落在内地节点必须 ICP 备案，管局审核约 20 个工作日；mystand.space 后缀 `.SPACE` 已获工信部批复（信管函〔2018〕489号）且 NS 实测指向阿里云（万网）DNS，**备案大概率可行**（唯一残留不确定点：域名注册商身份因 whois 限流未能在线确认）。而官方帮助明确：「若域名仅解析至非中国内地的服务器，则无需进行备案」——香港/海外节点免备案。
- **国际可达**：官方社区文章与官方 Well-Architected 文档均承认内地节点面向海外用户延迟高、跨境公网拥塞丢包，阿里云特约文章原话建议海外用户「不要选中国大陆节点」，首选香港（国内海外兼顾）或新加坡、美西。
- **价格落点（阿里云体系内）**：
  - 学生侧最优：**99元/年 ECS 学生机（e 实例 2核2G/3M 固定带宽，续费同价，官方写明活动截止 2027-03-31）+ 云工开物 300元/年代金券**——但学生机是内地节点，同样撞备案+国际可达墙，只适合纯学习/内网实验。
  - 对外服务：**香港轻量应用服务器 2核2G（50M 峰值、1TB/月流量）45元/月 / 539元/年**（第三方代理商标价，购买页为准），免备案。
  - 临时/按量：ECS 按量 e 实例 2核2G ≈0.10元/时（内地），香港约为内地 1.5–2 倍。

## ④ 备案结论（决定国内节点可行性）

**结论：内地节点对外 Web 服务必须 ICP 备案；mystand.space 备案大概率可行**——证据链如下，唯一残留不确定点是注册商身份未能在线确认。

证据链：

1. **NS 实测**：`dig NS mystand.space`（走代理实测）= `dns29.hichina.com` / `dns30.hichina.com` —— hichina.com 为阿里云/万网官方 DNS，域名大概率注册或托管于阿里云。
2. **后缀已获批**：`.SPACE` 顶级域获工信部批复——**工信部信管函〔2018〕489号**（2018-12-25，北京然迪克思科技有限公司为 .HOST/.SPACE/.PRESS/.WEBSITE 注册管理机构）：https://www.miit.gov.cn/zwgk/zcwj/wjfb/pf/art/2018/art_5b258d4c1fce44269ea9bab871559270.html
3. **阿里云备案支持该后缀**：`.SPACE` 出现在阿里云备案帮助页附录现行后缀列表中（curl 抓取命中 `<p id="0fb8bc8d71csn">.SPACE</p>`）。
4. **备案核验三要求**（官方：https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/prepare-and-check-the-domain-name ）：
   - ① 后缀获批复 ✓（见上）
   - ② **注册商须为工信部批复的内地注册商**——境外/国际站注册商需先转入内地注册商（阿里云国际站注册的域名也需转入）⇠ **此环节未确认**
   - ③ 域名持有人与备案主体一致、距到期 > 45 天
5. **免备案边界（原文）**：「**若域名仅解析至非中国内地的服务器，则无需进行备案**」⇒ 香港/海外节点免备案。
6. 时效：管局审核约 20 个工作日（第三方口径，各省市有差异）。

> **风险提示**：whois/rdap 对 mystand.space 三次尝试（限流/超时）均失败，已到重试上限，注册商身份未在线确认。若注册商确为万网/阿里云（与 NS 同栈，概率高），个人主体可直接在阿里云提交备案；若为境外注册商，需先办理域名转入（约 5–7 天 + 1 年续费），再提交备案。

## ⑤ 国际可达性定性（不编数，只引可查结论）

**定性结论：内地节点默认线路面向全球用户无延迟/丢包保障（晚高峰国际出口拥塞），阿里云官方自身都不推荐内地节点服务海外用户；本任务场景（mystand.space auth/link 面向全球 GitHub 安装用户，国际可达硬需求）下内地节点不可行；香港节点是阿里云体系内唯一同时满足免备案 + 国际可达较好 + 国内访问尚可的档位。**

可查证据（均为官方或官方社区）：

- **官方社区特约实测文**（https://developer.aliyun.com/article/1744724 ，curl 原文命中）：内地节点国内访问延迟 5–50ms；原话「面向海外用户请不要选中国大陆节点（需要备案且海外访问慢），建议选中国香港（国内海外兼顾）或新加坡、美西」。
- **官方承认跨境链路差**：官方问答「中国境外 ECS 跨地域互访容易受国际链路影响网络质量」（https://developer.aliyun.com/ask/471700 ）；官方 Well-Architected 网络优化：「海外流量公网回中国内地的场景，跨境公网质量差导致拥塞丢包、无直连回国公网线路导致延迟高」（https://help.aliyun.com/zh/well-architected/network-optimization ）；精品 EIP 文档（BGP 多线精品优化海外↔内地；注意 BGP 多线仅覆盖香港本地/香港↔海外）：https://help.aliyun.com/zh/eip/use-boutique-eip-to-optimize-access-to-international-business-in-mainland-china 、https://developer.aliyun.com/article/1758403
- **边界澄清**：官方网络 FAQ 的「跨地域公网丢包 P99<0.0001%」指阿里云骨干内部，**非**公网出口到境外终端的承诺；流量计费带宽峰值不作承诺，仅固定带宽保障（https://www.alibabacloud.com/help/zh/ecs/network-performance-faqs ）。
- 自测工具：NIS 互联网访问延迟大盘 https://help.aliyun.com/zh/nis/user-guide/work-with-network-performance-observation

## 信息时效与局限

- **whois 未确认注册商**（限流/超时 ×3，达重试上限）：备案可行性中「注册商须为内地批复机构」一条未闭环，是结论中唯一的"大概率"而非"确定"。
- **价格非官方牌价**：轻量服务器价格表为第三方代理商标价（已标注），ECS 按量价为社区特约文章口径；一切以购买页/官方计价器实时价为准。
- **99 计划锁价年限两口径**：学生权益页「截止 2027-03-31」 vs 99 计划页「锁至 2029」，两活动主体不同，未做裁决、并列呈现。
- **飞天加速计划现状**：官方页未见该活动新入口，老活动仍可领取的说法来自 2026-03 第三方攻略，非官方确认。
- 备案审核时长（约 20 个工作日）为第三方口径；所有网络"口碑"结论均为定性引用，未做实测打点。
- 本报告为纯桌面调研，未登录任何阿里云控制台，未操作任何服务器。
