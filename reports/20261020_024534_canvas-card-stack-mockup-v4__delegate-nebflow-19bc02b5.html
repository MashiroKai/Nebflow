常态 = canvas 满幅显示当前文件（现状不变）；点浮钮 = 整个 canvas 连同内容缩放为 ~85% 的最前卡，背后露出同尺寸的其他文件卡（食谱盒纵深，当前卡在最前）；点后卡 = 它放大回满幅成为当前 canvas，原当前卡缩回堆叠。

v3 → v4 修订对照（作者二次澄清）

作者：「把整个 canvas 当作卡片，点堆叠按钮的时候，整个 canvas 放缩为堆叠视角，等于是在切 canvas，而不是现在在 canvas 上进行堆叠。」——源码内修订点带 [v4①]…[v4⑥] 标签。

#澄清v3（旧模型）v4（新模型）
①缩放的是整个 canvas 区面板内容内的 face 物化为前卡（scale 0.89、下移 8px）——缩放发生在 canvas 内部，观感仍是「canvas 上做了堆叠」整区缩放：transform scale 只作用于 canvas 根（实施 = #canvas-panel），整个 canvas 连同其内容一起缩成一张卡（~85%），等于把 canvas 切小——全程只有这一次整区缩放变换
②卡组在 canvas 外#deck-stage 是 #canvas-content 的子层（z-10），卡「长在面板面上缘背后」——卡组仍在 canvas 里卡组层（#deck-layer）= canvas 区内 canvas 根的兄弟层（z 更低）；canvas 子树内不存在任何卡片容器/浮层（DOM 可断言）。缩小态下 canvas 区外露出的边缘/背景就是卡组的后卡
③后卡同尺寸堆叠后卡 translateZ 负深度 + rotateX 后仰 + 逐级缩放（0.886 起 −0.016/级）后卡与缩放后 canvas 同尺寸（85%，无 translateZ、无逐级缩放通道）；食谱盒纵深改由「translateY 露边阶梯 + rotateX 微后仰 + 逐级减淡压暗」表达，卡顶名称条照旧（v2③）
④点后卡 = 放大回满幅后卡飞入面板基姿（translateY 8 / scale 0.89）落位换面点后卡 = 该卡从露边位放大回满幅（×1/0.85）盖住 canvas 区，即成为当前 canvas（内容随之切换）；原当前卡缩回堆叠深处（ghost）；全程 ~0.65s
⑤收回 = 解除缩放面板面解除物化（去 .as-card）、卡组收回面板背后ESC / 点空白 / 点 canvas / 再点浮钮 = 卡组收回背后 + canvas 根 scale→1 回满幅常态（同一次整区变换的逆，内容不变）
⑥关闭照旧，重锚划走 / 卡顶 × 作用于 face（前卡）划走 / × 重锚到缩放态 canvas 根（语义不变：甩出/点关 = 关当前页签，邻位接管同 closeTab）；× 落头行右端（浮钮左侧）

设计规格（v4 整区缩放模型）

常态（无卡组）

  • canvas 满幅显示当前文件，与现状逐像素一致；canvas 子树内不存在任何卡组节点（v2 的 .deck-layer 覆盖层、v3 的 #deck-stage 均不存在于 canvas 内）。
  • 常态全 UI 无叉（v2①）；唯一入口 = 右上 40px 层叠浮钮。

整区缩放 + 露出卡组（点浮钮）

  • canvas 根缩放：0.3s 一次连续变换 translateY(8px) scale(0.85)——整个 canvas（头行名称条 + 内容 + 悬浮钮）一起缩成堆叠最前卡；内容原样活着，只是被切小。同时浮现卡投影强化「卡」的实体感（无新容器、无遮罩）。
  • 后卡露出：其余 N−1 张卡与缩放后 canvas 同尺寸（85%），从其后上方错位升起：d=1 露出名称条上缘 ~22px，其后每级再上露 ~6px 成错位阶梯（食谱盒纵深）；配合 rotateX 微后仰（−1.6°/级）与逐级减淡压暗；无 translateZ、无逐级缩放通道（透视深度通道会让投影随深度逐级缩水，违背同尺寸判据）；深处卡顶到 canvas 区缘被裁（区边界 = 卡组舞台边界）。
  • 层级保证：卡组层 z-5 恒在 canvas 根 z-10 之下——任何时刻后卡都「垫在 canvas 背后」，绝无浮于 canvas 之上的观感。
  • 视觉判据（可断言）：全程只有一次整区缩放变换（scale 作用于 canvas 根）；后卡静止位姿无 scale 通道；canvas 子树内无卡片容器（DOM 断言）。

滚轮连续擦洗（照 v2⑤/v3④）

  • wheel 增量（deltaMode 归一）× 1/240 累进背后环流浮点位置，rAF 指数趋近；滚多少动多少、向上滚回滚。键盘 ↑↓ 同通路 ±1。
  • canvas（最前卡）不随擦洗易主；底部计数行（canvas 区下缘外露带）显示「当前 n/N · 下一张 名」——被翻的是背后那摞。

点后卡 = 放大回满幅（v4④）

  • 点击后卡（或 Enter 选最上后卡）：该卡从露边位放大回满幅（0.32s，位姿 lerp → ×1/0.85 满幅），渲染层级瞬时抬升盖过 canvas 根；旧内容面同步减淡。
  • 落位瞬间：canvas 内容与标题切换为该卡、canvas 根瞬时回满幅（被落位的卡严丝合缝盖住，无跳变）；飞入卡卸除；原当前卡以 ghost 从满幅位缩回堆叠深处（0.3s）；卡组收回背后。全程 ~0.65s，一气呵成。

关闭（v4⑥，语义照 v2⑥/v3⑤）

  • 划走：按住缩放态 canvas 左右拖（跟手 + rotateZ 侧倾）；位移 ≥ 区宽 20% 或速度 ≥ 0.55px/ms → 沿拖行方向甩出淡出并关闭当前页签，不足则弹回。邻位接管（右邻优先，同 closeTab）后 canvas 从甩出位姿弹性复位回堆叠基姿。
  • × 点关：头行右端 ×（仅 deck 态显示），点击收拢淡出关闭当前页签。后卡关闭走右键菜单「关闭」。
  • 右键菜单（引用当前页/选区 / 关闭 / 关闭其他）保留；关掉全部卡 = 收起面板（右下重开）。

收回（v4⑤）

  • ESC / 点空白 / 点 canvas / 再点浮钮 = spread→0 后卡收回 canvas 背后，canvas 根 scale→1 回满幅常态，内容不变。

边界情况

  • 文件很多：背后环流环形取模（最短路径绕回），首尾无缝循环，深处卡片淡出至不可见——9 张卡可连滚一圈再滚回来（连续擦洗可逆）。
  • 当前文件回归：原当前卡缩回堆叠后按页签环形序落在 canvas 正背后一位（擦洗一格即到最上露边位），再开卡组它在手边。
  • 窄面板：缩放态与后卡恒为 canvas 区 85%，切 340 天然自适应；只收排版（提示行隐藏、标题截断）。
  • 单卡 / 空态：单卡时卡组为空（计数行提示「仅此一张」），划走 / × 仍可关；全部关闭则收起面板。
  • 拖划与点击的界分：canvas 位移 <6px 判为点击（= 收回卡组），≥6px 进入拖划；后卡点击即放大换入。
  • 动效降级：prefers-reduced-motion 下惯性插值系数置 1、进出场仅留淡入淡出。

实现提示（已同步写入本页控制台）

  • [v4①②] 结构 = canvas 区（#canvas-panel 的 docked 容器）内两层兄弟：#deck-layer（z-5 背后卡组，透视容器）+ #canvas-panel（z-10 canvas 根）。canvas 子树内只有头行 + 内容 + 悬浮钮，无任何卡组节点。
  • [v4②] 整区缩放基姿常量单一来源：JS 注入 --stack-scale: 0.85 / --stack-shift: 8px，CSS .stacked、飞行落点（×1/0.85）、ghost 起点（canvas 基姿）全部同源——实施批改一处即全局一致。
  • [v4③] 卡位姿 poseOf(d)：peek = 22·a₁ + 6·a₂（a₁=min(d,1)、a₂=min(d,4.5)−1，×sizeK，sizeK=min(1, 卡高/300)）；无 translateZ、无逐级缩放通道（同尺寸铁律）；rotateX 微后仰 −1.6°/级；op 自 d>1.2 线性衰减；压暗 0.11·d 封顶 0.30。露边阶梯 y 步进因此无收缩项可对抗（v3 级联塌陷坑在 v4 模型下不存在）。
  • [v4④] 换入 = 选中卡位姿 lerp → 满幅落点（scale ×1/0.85、y→0，与 canvas 满幅矩形重合），期间 #deck-layer.over 抬 z-60；落位即换内容 + 标题交叉淡入 + canvas 根瞬时回满幅（no-trans，被落位卡遮住无跳变）+ ghost 旧卡缩回堆叠深处。
  • [v4⑥] 划走 = 缩放态 canvas pointer 拖划（速度采样同 v3）；越阈甩出（外抛+13° 侧旋+淡出）→ settleClose 邻位接管 → canvas 带 .restore 弹性复位；不足阈弹回。× = canvas 收拢淡出。常态全 UI 无叉（v2①）。
  • 实施落点（canvas.js）：常态头 = .canvas-title；浮钮挂面板层（原叉位）；整区缩放类（.stacked）加在 #canvas-panel 上；deck-layer 挂 canvas 区容器（面板的 docked 父级）内、面板之前；数据源 = tabs Map（卡序 = active 起的环形序，不含前卡）；dirty 读 isTabDirty()；引用复用 refForTab()；关闭接管同 closeTab()。
  • 注意点：overscroll-behavior: contain 防滚链；canvas 区 overflow:hidden = 卡组舞台边界（深处卡被区缘裁切是预期形态）；「OS 文件拖入开新签」落区 = 整个 canvas 区（含卡组态）；预览缩略为 CSS mock，实施时文本用首行内容、图片用 objectUrl 真缩略。
