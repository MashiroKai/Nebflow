# 决策卡 MVP（实施中）

## 范围与验收

- 只读投影 `ScheduledTask(kind="todo")`，以 `completedAt` 判定完成；不迁移、不双写、不切换或删除入口。Ask 请求不可用镜像代替真源。
- 统一卡视图预留无详情和有详情两类及 Ask 来源；字段表待含 §零 原稿核对，不锁定。
- 手机单卡左右浏览，滑动不回应；桌面列表直接回应并可阅读详情。入口按可见、未决的唯一 ID 计数；入口布局由 ui-unify-panels 批负责。
- 摘要 40–100 字、内容至多 300 字；历史待办不截断。封面两端同一比例，具体比例待定。计数算法和文档内容计入范围待定，不以临时实现冒充裁定。
- 验收须覆盖只读映射、完成态与唯一计数、两端交互和真实运行态截图；尚未接通的能力不得标记通过。

## 暂行创建映射

新卡只写 ScheduledTask todo，project 标记 `__decision_card_mvp__`，name 是标题，detail 为含 summary/content 字符串的 JSON；列表与详情从同一列表读取。旧待办收件箱会显示这些行及其编码内容；这不是正式字段契约。迁移前置条件：§零 字段表定案、一次性迁移、幂等回读映射。

## 本次边界

待办是实例级收件箱，scope=all 跨会话读取是设计行为；决策卡预览入口及角标暂取原始列表中 sessionId 明确等于当前会话的行，此为来源匹配兜底，不是权限模型。渠道可由其他发送者驱动 agent，主体身份及共享收件箱例外尚无权威定义，主体级过滤未实现。项目匹配角标本批不做：当前全局入口没有权威当前项目上下文，project 是可空自由文本标签而非项目 ID；待项目入口传入明确项目上下文并裁定标签匹配规则后再实施。跨会话可见性、会话切换同步及正式入口需后续核验和与布局所有者协调。回应未接线，不能标记已确认。内容校验暂用 Unicode 码点计数，§零 原稿到手后须核对；校验函数尚无新卡提交表单。预览封面占位比例仅属临时视觉，不是产品裁定。投影结果不构成一次性复制或迁移。
