## Design

Repair source where the behavior violates an existing contract. Update textual guards only where current production code and history establish a different authoritative implementation; negative mutation fixtures must still reject removal of the safety behavior. Preserve baseline counts and do not mark failures advisory.

Search batch-open state retains its owned button reference and reuses the existing results container. Presentation uses shared glass/input tokens. Local-coupling precision operates on matched spans so an allowed font or numeric token cannot hide a personal path on the same line. Executable examples resolve temporary/configuration and output paths without machine-specific usernames.

Layer registration is based on actual dependencies. Removing unused imports is safe; real lower-to-upper dependencies require deliberate implementation changes and remain failing until then. Prompt and plugin prose changes are review-gated, and external repository endpoints are not silently replaced or broadly allowlisted.
