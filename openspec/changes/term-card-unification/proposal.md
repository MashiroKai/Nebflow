# 词条预览复用文档卡

## 变更与理由
作者批准词条弹窗按文档预览卡样张统一，消除两套独立卡片与不一致动作。

## 要求与验收
- 词条使用 `showDocumentTermCard`，显示名称、完整释义、类型、出处与通栏原词条动作；长内容整卡滚动。
- 与文档卡共享锚定与外点、Esc、切换页签关闭行为，不显示独立关闭按钮。
- 来源可导航时携带词条锚；缺锚和目标未找到应提示。失败可重试，无来源应说明；选区自定义预览不丢失。
- 320、390 和桌面视口覆盖，文档预览与词条读侧回归保持通过；结构与动作具备负控。

## 范围
前端卡片、词条适配及 Markdown 锚点反馈；不更改数据服务、发布或部署。
