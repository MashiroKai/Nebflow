# Design

词条预览由 `src/main/resources/web/js/termTip.js` 适配，调用 `documentTermCard.js` 的 `showDocumentTermCard`，与文档引用共享卡壳、标题、正文、元信息、动作、视口定位和关闭行为。文档查看器、聊天消息、human 卡和选区自定义预览复用词条预览；文档卡仍处理文档元数据与打开原文档，词条卡处理释义、来源、打开原词条与重试。

Markdown 查看器在词条来源缺少锚点或锚点未找到时分别提示。词条仍保留现有图谱载荷及词条接口回退，文档仍使用文档元数据接口；选区自定义内容不请求词条。导航回调、数据解析和两种卡的动作仍各自独立。

兼容方面保留 `termTip.js` 导出入口与既有数据回退；共享卡在文档模式沿用原有打开路径。需要回滚时应一并回退词条适配、共享卡扩展、样式及 Markdown 提示，避免新旧接口不匹配；不涉及服务端数据迁移。
