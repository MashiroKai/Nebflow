# Design

The browser reports its device time zone with authenticated identity frames. Message provenance is carried into the tool context; an ambiguous merged turn does not fall back. For an explicitly sourceless turn, the latest authenticated device report can supply the zone, with its provenance recorded. Explicit input region takes precedence over the device region; no valid source means clarification rather than a server-zone guess.

The four write-port input contracts are: a todo with no due retains its existing behavior; a WebSocket todo with a nonzero numeric trigger uses its valid device region or asks for clarification; a Schedule todo uses an explicit region ahead of the device region; and local or relative Schedule input requires a region before resolving its calendar time. Explicit offsets select the instant without inventing a region. Weekly rules use local calendar recurrence in the creation region; invalid rules and unsupported sub-minute weekly WebSocket inputs are rejected. DST gaps advance to the first valid instant and overlaps choose the earlier instant with its offset.

Due rules, creation zone, wall clock and optional offset are persisted alongside rule versions and occurrence bindings. An explicit zone correction holds the store lock, retains occurrence identity and triggered history, and recalculates unconsumed occurrences and the future cursor. Elapsed recalculated occurrences are marked missed, not delivered as catch-up; the cursor details remain a Spider ruling pending author confirmation. Desktop presentation shows the creation zone and, where different, device-local time; correction is explicit, not automatic on travel. Store settlement does not claim external exactly-once delivery.

Rollback policy is no migration and no dual-write. The old reader ignores new task fields, but old-version writes drop them; retain a complete data snapshot before rollback and prohibit old-version writes to these task data throughout rollback. Mock browser tests cover display and correction separately from isolated real-gateway write, persistence and read-back evidence.
