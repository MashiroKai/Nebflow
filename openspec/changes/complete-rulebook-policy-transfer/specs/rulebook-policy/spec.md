## ADDED Requirements

### Requirement: [RP-REQ-001] Preserve effective policy while simplifying instructions

The rulebook SHALL preserve effective safety, authorization, execution and acceptance constraints in task-routed references. AGENTS.md SHALL contain concise project boundaries and navigation, and agents SHALL modify it only under a specific explicit user request for that file. Migration SHALL distinguish preserved rules, verified obsolete descriptions and unresolved external contracts.

#### Scenario: [RP-SCN-001] Review the policy transfer

- **WHEN** the author reviews the compact AGENTS.md and updated rulebook source
- **THEN** the migration map identifies the destination of each former section
- **AND** conditional background admission, all-web-file checks, explicit Git permissions and source-versus-runtime boundaries are preserved
- **AND** verified prompt ownership replaces obsolete seed descriptions, and legacy clause checks use a verified source snapshot rather than missing current headings
- **AND** unavailable or conflicting external contracts are reported without inventing semantics
