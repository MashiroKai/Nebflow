# Canvas Ask 显示方式变更

## 范围与意图
Canvas Ask 处理中沿用主会话工作线，单行展示思考和工具；终态不留可展开过程。正文仍使用现有 textDelta 传输，但仅在工具调用、round 或终态边界整条落列，按序分条，不逐字展示。选区 Ask 和主会话行为不变。

## 验收
- 思考和工具更新为单行，文本增量期间工作线保持。
- 未收口正文不可见；工具及 round 边界各收口一次，后续增量形成新消息。
- 完成、中止、错误及断连收尾不残留流式正文或可展开过程；现有 Markdown 渲染及卡片维持可用。Ask root 正常回答的快照以落盘 flush 分条，GitViz 快照保持原有合并。旧历史无消息身份，按 flush 分条，可能拆开原消息，不迁移历史。
- 桌面/手机、亮/暗样张及定点红绿、负控覆盖。
