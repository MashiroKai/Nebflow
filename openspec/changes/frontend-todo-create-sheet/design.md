# Design

Proposed: keep the Apple tasks and list pages mounted and open an out-of-flow `.nf-glass` bottom sheet with transparent outside region; cancel/outside/Escape discard, navigation removes it. The draft sheet is deliberately not wired to either entry: the existing create path can delete same-name records, and a client-side existence check cannot prevent concurrent conflicts. Prior create entries remain in their original full-page state, including their existing risk. Before wiring the sheet, independently review and implement a server-side non-destructive create protocol with failure recovery and tests. Do not add or repurpose deadline. Mobile geometry, keyboard behavior, reduced motion, lifecycle and theme interactions require browser testing; source inspection is not acceptance.
