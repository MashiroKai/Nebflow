# 第三层 · 圆角与间距例外值（具名例外槽优先于硬归并）

口径与第二层一致：会改像素 ⇒ 判据是「每个原值有明文去向 + 改后例外清零（机械断言）+ 双档截图」。
任务书对这类改动的特别要求：**不要硬归并**，形态会被弄坏的细件要留**具名例外槽并写明理由**。

改点合计 **614**（间距 518 原子 + 圆角 96 处）。

## 1. 间距（518 原子）

| 原值（原子数） | 去向 | 依据 |
|---|---|---|
| 3px（128） | 缝→`2px`(space-half)；内距→`4px`(space-1) | **缝往小收、内距往大收**：一条缝两侧都要吃视觉重量（`gap: 3px` 用两倍），内距只吃一侧。3px 与 2/4 都差 1px，这个取舍让"密集控件不膨胀、留白不缩水"同时成立 |
| 5px（124） | 缝→`4px`；内距→`6px`(space-1h) | 同上 |
| 7px（70） | 缝→`6px`(space-1h)；内距→`8px`(space-2) | 同上 |
| **1px（99）** | **`--ds-space-hair` 1px（具名例外槽，新立）** | 1px 是**形态值**不是"差一点的 2px"：发丝分隔线/指示条偏移/发光描边 inset。收回 2px 会让每条发丝缝视觉加倍（99 处），密度直接退化。**值不变 ⇒ 这 99 处像素零变化**；槽契约：只许发丝缝/发丝偏移，禁作内距 |
| 9px（37） | `8px`(space-2) | 距 8 差 1、距 12 差 3 ⇒ 8 |
| 11px（13） | `12px`(space-3) | 距 12 差 1 ⇒ 12 |
| 13px（6） | `12px`(space-3) | 距 12 差 1 ⇒ 12 |
| 18px（32） | 缝→`16px`(space-4)；内距→`20px`(space-5) | 18 与 16/20 各差 2 ⇒ 回到同一条「缝小、内距大」 |
| 1.5 / 2.5 / 6.5px（10） | `2` / `2` / `6px` | 亚像素档外值，就近归半步档 |

**跳过（有理由，不是漏）234 个原子**：
- 负值（`-1px / -4px / -20px / -27px` 等）：写不进 `var()`（需 `calc(-1 * …)`），属形态偏移，另批处理；
- `14px`（109 处）：定版明载**不是档**（气泡内距的组成部分，气泡横 14 与 16px 圆角外沿是一组）；
- ≥20px 的组件几何（22/26/28/30/34/36/38/40/42/56/58/72px）：那是卡片宽/头像/容器高，不是间距档。

## 2. 圆角（96 处，单值口径）

| 原值（处数） | 去向 | 依据 |
|---|---|---|
| 7px（25） | `8px` input | 差 1px，在 20–40px 小件上不可辨（定版 §4-①） |
| 3px（21） | `4px` badge | 差 1px ⇒ 语义最近正档 |
| 5px（16） | `6px` chip | 差 1px ⇒ chip |
| 9999px（14） | `999px` pill | 胶囊的第二种写法，统一到 pill（值上等价） |
| 9px（8） | `10px` button | 差 1px |
| 11px（4） | `12px` xl | 差 1px |
| 13px（1） | `14px` card-md | 差 1px |
| 3.5px（1） | `4px` badge | 差 0.5px |
| 17px（1） | `18px` 2xl | 差 1px |
| **1px（4）** | **`2px --ds-radius-thin`（既有细件例外槽）** | 四处全是 **2px 高/宽的指示条、进度条、拖动条**（`width:7px;height:2px`、`height:2px`、`width:2px`）。归 badge 4 会把细件当小卡片处理；`--ds-radius-thin` 正是为这一族出生的槽（「8px 宽滚动条拇指归 4px 会变药丸」同一条判据）。另：CSS 重叠约束会把 2px 高条上的半径钳到同一渲染 ⇒ 像素实际不变 |

**跳过 12 处组合四值**（`0 12px 12px 0` / `24px 24px 19px 19px` / `var(--ds-radius-shell) var(--ds-radius-shell) 0 0` …）：
逐角值编码的是**单侧形态**（一侧圆角的卡、贴着胶囊的边、镜像读法），把它当"四个档值"逐个归并会直接改掉形态语义。本批不动，清单留给下一次需要人眼评审的单侧形态批。
