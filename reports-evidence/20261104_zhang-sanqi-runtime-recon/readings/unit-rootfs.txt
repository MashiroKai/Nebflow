## 结论
  镜像 = 1 个 Rust 多调用二进制 capd + 12~14 份 unit json + 一份 onion.json。
  没有 /bin/sh、没有 glibc 发行版、没有 JDK、没有 python、没有 sbt。
  ⇒ "同一个 Linux 环境"**不是**由镜像提供的；镜像只提供"应用 payload"。
     Linux 环境本身来自 star-core / star-host（同一 Linux 用户态构建，三种载体各装一份）。
  对照：docs/design/platform-distribution.md:32「Runtime 层（Linux 用户态）：
        star-core / star-host；同一 Linux 构建跨三种载体」。
        体积：star-core 3.1MB、star-host 48MB、star-device ~2.2-2.3GB
        （docs/design/platform-distribution.md:45-47）。
