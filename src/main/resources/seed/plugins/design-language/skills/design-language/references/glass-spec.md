# 毛玻璃规范（glass spec）—— 全站唯一术语 · 唯一标准

> 作者令（2026-11-05 16:46，逐字）：

> 是怎么回事，你看图1，我它这个是半透明的，能看见底色的。然后图二这种就是不透明的
> 毛玻璃效果。我说了很多次但是还是没有统一到图2这种。……把毛玻璃效果作为一个唯一的

## 0. 词条（术语表条目）

| 词条 | 别名 | 唯一落点 |
|---|---|---|
| **毛玻璃**（glass） | 玻璃、玻璃质感、frosted、glassmorphism | ① 令牌 `--nf-glass-*`（`css/stand-tokens.css`）② 类 `.nf-glass`（`css/glass.css`）③ 机检 `scripts/check-glass-unify.mjs` ④ 本文件 |

一句话标准：**不透明，但承接背景色** —— 看不到背景的内容（文字/图形），
但看得到背景的颜色（色调/冷暖）。全站只此一档。

**这一句的两个分句要一起读**：只满足前一半 = 死白（本次被否掉的形态）；
只满足后一半 = 内容透底的「脏」。两半都由同一组参数同时供给，不是折中。

## 1. 唯一形态（参照物 = 主会话输入框）

| 维度 | 值（亮 / 暗） | 作用 |
|---|---|---|
| 底 `--nf-glass-bg` | `#ffffff8C`（α .549）/ `#181c26AD`（α .678） | **决定透多少色**：C_out ≈ (1−α)·saturate·C_bg |
| 模糊 `--nf-glass-blur` | `40px` | **决定剩多少内容**：blur 是低通，高频（字/图形）被洗掉、低频（颜色）留下 |
| 饱和 `--nf-glass-saturate` | `1.4` | 补回 α 混合与模糊造成的降饱和，把背景色**放大**出来 |
| 合成配方 `--nf-glass-filter` | `blur(var(--nf-glass-blur)) saturate(var(--nf-glass-saturate))` | 全站唯一值，别处不许自写 |
| 细边 `--nf-glass-border-color` | `#ffffff59`（α .35）/ `#ffffff0F`（α .06） | 玻璃的那道白光边（参照物同值） |
| 内高光 + 投影 `--nf-glass-shadow` | 顶缘 1px inset + 两档外投影 | 面「浮」起来 |
| 顶缘折射线（可选） | `--nf-glass-refraction` 1px 渐变 | 有横向上缘的面可加；圆钮等小面不加（1px 线在 40px 圆上不可读） |
| hover `--nf-glass-bg-hover` | α .620 / α .722 | 只提不透，不改形态 |

**为什么 α 与参照物逐值相同、blur/saturate 却比参照物更严**：参照物实测是
`rgba(255,255,255,.55)` + `blur(24px) saturate(1.15)`。参数网格（α × blur × saturate，
真像素读数）给出两条**互相独立**的定律：

- **色彩承接** `C_out ≈ (1 − α) · saturate · C_bg` —— 只由 α 与 saturate 决定；
  **blur 半径对它零影响**（α .55 时红底色度在 blur 24/40/64 下恒为 90.4）。
- **内容残留** `sd_out ≈ (1 − α) · g(blur)` —— 只由 blur 压得下来：α .55 时正文墙的
  亮度标准差 blur 24→40 从 2.81 落到 1.43（腰斩），色彩承接一格不掉。

⇒ 分工清楚：**α 决定透多少色，blur 决定剩多少内容**。想更"不透明"就加 blur（不花
色彩），不该加 α（花色彩）。故 α 照收参照物，blur 24→40 与 saturate 1.15→1.4 是在
作者要的两个方向上同时加码 —— 这是收紧参照物，不是偏离。

## 2. 已判死刑的形态

| 死因 | 症状 | 旧值（已退役） |
|---|---|---|
| **死白**（本批新增死刑） | 背景色调一点透不上来：红底上的色度只剩 6.9 = 作者说的「不是我想的那种」 | `#ffffffF7`（α .973）/ `#181c26F0`（α .941） |
| 内容透底（且 blur 小） | 底下的正文大字看得出来 = 作者说的「脏」 | α < .45 且 blur ≤ 24px |
| 各面另立一档 | 同一屏里按钮比面板更透 / ask 面单开 α=1 的「不透明档」 | `--glass-control-bg` .60；`--glass-bg-opaque` 压平档 |
| 各面手调白度 | 同一个毛玻璃在四处有四种白度 | .72（权限提示）/ .88（搜索日期浮层）/ .92（暗档浮层）/ .55（兜底字面量） |
| 按龄渐隐 | 「只有最新一条清楚，前面的半透明」 | `.ask-bub[data-age]{opacity:var(--ask-age-alpha)}` + JS 写 α |
| 模糊值各处自拟 | 8/10/12/14/16/20/24/26px、saturate 1.1–1.8 共 30 种写法 | 全部收敛到 `--nf-glass-filter` |
| 只钉 α 不钉半径 | 「α 对、半径退回 24px」看起来合规、实际内容残留翻倍 | 上一版判据只查 α 单边下限，本版加 G6 |

## 3. 怎么用（两条路径，第三条不存在）

| 场景 | 写法 |
|---|---|
| 能改标记 | 元素挂 `class="nf-glass"`（唯一工具类）。`.glass` / `.glass-control` 是它的**历史别名**，同一份配方、零自有值，新代码一律用 `.nf-glass` |
| 不能改标记（纯 CSS 面） | 把选择器加进 `css/glass.css` 的「成员登记表」，配方由该表统一供给 |
| ~~自己写 backdrop-filter~~ | **禁止**。`scripts/check-glass-unify.mjs` G1 判红 |
| ~~另开一个 α 档「因为这一面背后是正文」~~ | **禁止**。内容隐身由 blur 负责；`--glass-bg-opaque` / `--cv-bg-opaque` 已与 `--glass-bg` 同值 |

幕布（takeover 遮罩/灯箱底）**不是**毛玻璃面：它没有玻璃底与描边，只借模糊
把背景压下去，走 `.nf-glass-scrim` + `--nf-glass-scrim*`，不参与 `.nf-glass`。

## 4. 判据（机检六条，`scripts/check-glass-unify.mjs`）

| 编号 | 判据 | 命中形态 |
|---|---|---|
| G1 | `css/glass.css` 之外出现非 `none` 的 `backdrop-filter` ⇒ 红 | 第二套配方 |
| G2 | `glass.css` 内的非 `none` 值不是 `var(--nf-glass-filter)` ⇒ 红 | 配方走样（数值重新长回文件） |
| G3 | `--nf-glass-bg` / `-hover` 的 **α 跑出 [0.45, 0.75] 区间** ⇒ 红（双边闸） | 高了 = 死白；低了 = 内容透底 |
| G4 | `--nf-glass-*` 在 `stand-tokens.css` 之外被**定义**（非别名） ⇒ 红 | 令牌双源 |
| G5 | canvas ask 的气泡/输入条缺 `.nf-glass` ⇒ 红 | 绕过唯一工具类 |
| G6 | `--nf-glass-blur` < 32px 或 `--nf-glass-saturate` < 1.3，或 `--nf-glass-filter` 缺 blur/saturate 任一件 ⇒ 红 | 配方被降档（α 看着合规、内容/色彩实际退化） |

`backdrop-filter: none` 全网放行：那不是第二套毛玻璃，是**摘除**毛玻璃
（`@supports` 降级档 / 无 backdrop 引擎回落实底），性质相反。

判据**只表达区间与下限，不钉死单个数**：把 blur 提到 48px、saturate 提到 1.5 是
允许的（同一标准内更严）；把 blur 调回 24px、α 调回 .973 必然判红。

## 5. 验收读数（怎么证明「不是靠嘴」）

`scripts/capture-glass-ab.mjs` 是这一条的装置：同一块玻璃压在①纯灰底 ②纯红底
③纯蓝底 ④星云彩图 ⑤正文墙 上，各拍一张并读玻璃区域的平均 RGB 与亮度标准差。

| 判据 | 绿的条件 | 本批实测（亮档，玻璃区域平均色） |
|---|---|---|
| 背景色透上来 | 同一块玻璃在灰/红/蓝三底上的平均色明显不同 | 灰 `(198,198,198)` / 红 `(255,153,153)` / 蓝 `(151,182,255)`：红底比灰底 R +57、B −45，蓝底反向；死白档（α .973）在同样三底上只差 ±6 |
| 背景内容看不到 | 正文墙上的边缘能量与结构标准差贴近平底 | 正文墙原始边缘能量 3.91 → 玻璃面 0.06（衰减 **65 倍**），结构标准差 2.34（满量程 0.9%）；死白档 0.03 / 0.13 |
