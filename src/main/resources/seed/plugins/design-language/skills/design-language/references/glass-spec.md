## 0. 词条（术语表条目）

| 词条 | 别名 | 唯一落点 |
|---|---|---|
| **毛玻璃**（glass） | 玻璃、玻璃质感、frosted、glassmorphism | ① 令牌 `--nf-glass-*`（`css/stand-tokens.css`）② 类 `.nf-glass`（`css/glass.css`）③ 机检 `scripts/check-glass-unify.mjs` ④ 本文件 |

一句话标准：**不透明，但承接背景色** —— 看不到背景的内容（文字/图形），
但看得到背景的颜色（色调/冷暖）。全站只此一档，且**逐值等于主会话输入框**
（2026-11-15 终裁：只准使用这一种）。

**这一句的两个分句要一起读**：不透字、透色；高 alpha 底压低对比度，blur 洗去字形高频，非实底则允许低频色彩通过。α=1 的实底即使有模糊也不透色；低 alpha 或弱模糊可能透字。具体可用区间与模糊下限须由像素实验确认；当前门禁下限 .90 只是既有静态检查，不是实测可用带。

## 1. 唯一形态（= 主会话输入框配方，逐值）

| 维度 | 值（亮 / 暗） | 作用 |
|---|---|---|
| 底 `--nf-glass-input-bg` | `#ffffffF7`（α .968）/ `#181c26F0`（α .941） | 近实底：内容不透底，色相仍随背景翻面 |
| 模糊 | `blur(24px)`（`--nf-glass-input-filter` 内） | **决定剩多少内容**：blur 是低通，高频（字/图形）被洗掉、低频（颜色）留下 |
| 饱和 | `saturate(1.15)`（同上） | 把背景色留在线条洗掉之后的底色里 |
| 合成配方 `--nf-glass-input-filter` | `blur(24px) saturate(1.15)` | 全站唯一值（G6 逐值钉死），别处不许自写 |
| 细边 | `1px solid var(--glass-border)` | 玻璃的那道白光边（参照物同值） |
| 面影 | `var(--cv-shadow)` | 面「浮」起来（基准件同值） |
| 顶缘折射线（可选） | `--nf-glass-refraction` 1px 渐变 | 有横向上缘的面可加；圆钮等小面不加 |
| hover | `--nf-glass-bg-hover` = `var(--nf-glass-input-bg)` | 只提不透：唯一材质下 hover 同底 |

**为什么逐值照收参照物**：参数网格（α × blur × saturate，真像素读数）给出两条
**互相独立**的定律，本标准在两点上都落在参照物自身：

- **色彩承接** `C_out ≈ (1 − α) · saturate · C_bg` —— 近实底下承接量小而稳定，
  色相随亮暗主题翻面（.968/.941 即参照物原值）。
- **内容残留** `sd_out ≈ (1 − α) · g(blur)` —— 近实底 × blur 24px 的残留 ≈ 3%，
  正文墙的字形不再可读；11-11 作者令「毛玻璃一律不透底」把这一端钉成死刑。

⇒ 旧 40px/1.4 通透档（α .549/.678）**整档退役**：它正是在「哪一种」上偏离参照物
的那一版（11-05 recalibrate 的产物）；2026-11-15 起旧档令牌
（`--nf-glass-bg` / `-bg-hover` / `-filter` / `-blur` / `-saturate`）只准作为指向
唯一值的**别名**存在（存量消费链 `--glass-*` / `--cv-*` 不改名即换材质），
出现第二份字面值 = 第二种材质，判红。

## 2. 已判死刑的形态

| 死因 | 症状 | 旧值（已退役） |
|---|---|---|
| **通透档**（2026-11-15 退役） | 半透明能看见底色图形 = 作者 16:46 点名的图1 形态 | α .549/.678 + blur 40px/1.4（旧「全局标准」） |
| **死白实底** | α = 1 时即使有模糊，底色也无法透入；不能仅以有无模糊判断透色 | `background: #ffffff; backdrop-filter: blur(24px)` |
| 内容透底 | 底下的正文大字看得出来 = 作者说的「脏」（11-11 令「一律不透底」） | α < .90（G3 下限 [0.90, 1.0]） |
| 各面另立一档 | 同一屏里按钮比面板更透 / ask 面单开 α=1 的「不透明档」 | `--glass-control-bg` .60；`--glass-bg-opaque` 压平档 |

| 按龄渐隐 | 「只有最新一条清楚，前面的半透明」 | `.ask-bub[data-age]{opacity:var(--ask-age-alpha)}` + JS 写 α |

| 只钉 α 不钉半径 | 「α 对、半径退回去」看起来合规、实际换了一种质感 | 唯一配方逐值钉死（G6），别名出生地同步钉死（G3） |

## 3. 怎么用（两条路径，第三条不存在）

| 场景 | 写法 |
|---|---|
| 能改标记 | 元素挂 `class="nf-glass"`（唯一工具类）。`.glass` / `.glass-control` 是它的**历史别名**，同一份配方、零自有值，新代码一律用 `.nf-glass` |
| 不能改标记（纯 CSS 面） | 把选择器加进 `css/glass.css` 的「成员登记表」，配方由该表统一供给 |
| ~~自己写 backdrop-filter~~ | **禁止**。`scripts/check-glass-unify.mjs` G1 判红 |
| ~~另开一个 α 档「因为这一面背后是正文」~~ | **禁止**。内容隐身由 blur 负责；`--glass-bg-opaque` / `--cv-bg-opaque` 已与 `--glass-bg` 同值 |

幕布（takeover 遮罩/灯箱底）**不是**毛玻璃面：它没有玻璃底与描边，只借模糊
把背景压下去，走 `.nf-glass-scrim` + `--nf-glass-scrim*`，不参与 `.nf-glass`。

**顶部悬浮面没有第三条路**：浮在顶部、底下内容看得见的面，必须走上面两条路径之一
（挂类 / 进成员表），或者在 §6 有具名例外。这条由 G7 机检（§7），不靠自觉。

## 7. 顶部悬浮面 = 毛玻璃（G7）

> 作者令（2026-11-06，逐字）：
> 「所有悬浮在顶部 可以透出背景的 都用毛玻璃效果 比如消息和联系人的手机端的
>  搜索框 这个要成为标准」

### 7.1 什么算「顶部悬浮可透出面」

| 条件 | 判据形态 |
|---|---|
| **顶部悬浮** | ① `position: sticky` 且带 `top`（钉在滚动容器顶缘，内容从它底下滚过）；② 顶带 = `fixed`/`absolute` + `top ≤ 160px`（或 `var()/calc()/env()`）+ 左右贴边 `0`；③ 顶带的子件（选择器链里含顶带复合选择器） |
| **可透出背景** | 底色的 α ∈ (0, 0.90)：α = 0 是**零画**（带本体不画东西，不承接背景也就无所谓透出，见 §7.3）；α ≥ .90 是不透底实底（背景进不来，标准管不到它） |
| **必须毛玻璃** | 该面必须①挂 `.nf-glass`，或②进 `css/glass.css` 的成员登记表，或③在 §6 有具名例外 |

这条标准管的是**面的位置语义**，不是面的类型：搜索条、胶囊、吸顶头、浮层工具条、
钉在气泡流上方的等待条，只要「浮在顶部 + 底下的东西看得见」，就吃同一份毛玻璃。
它与 G1–G6 正交：G1–G6 说「毛玻璃只有一份配方」，G7 说「这些面不许没有毛玻璃」。

**两端都不许走**：把浮面做成「半透明洗色底 + 零模糊」（内容直接穿上来 = 作者
2026-11-06 点名的形态），和把它做成「不透明实底」（背景颜色进不来 = 死白端），
都不是标准。

### 7.2 登记面清单

本表 = 「哪些面是顶部悬浮面、各自应该是什么材质」的**唯一账本**，G7b 逐行机检。
`期望材质` 三档：

- `毛玻璃` —— 面自己供（CSS 成员 / `.nf-glass` 规则命中）；
- `毛玻璃@<类>` —— 材质来自 DOM 上挂的那个类（该类必须能在 `glass.css` 里供 blur）；
- `零画` —— 带本体**不画任何东西**（α = 0），只有子件各自是玻璃；
- `毛玻璃/零画` —— 同一元素在另一个输入能力档让位成纯手势面（底 α = 0、玻璃
  交给替代件），两种形态都合法（例：粗指针横排档的 `#canvas-panel .canvas-header`
  让位给 `.cr-capsule`）；
- `例外` —— 见 §6，必须两边都在（登记 + 例外行）。

### 7.3 零画带（为什么 α = 0 不算违规）

手机层的顶栏带是**结构性不存在**的：`.ds-chrome-band` 一族（`#mobile-fab-layer`
/ `.mobile-page-header` / `.mf-cv-toolbar` / `.mf-strip`）本体零底色零描边
`pointer-events: none`，只做控件的定位上下文与手势落穿。带本身不承接背景，
所以它没有「透出背景」的问题 —— **该是毛玻璃的是带里的控件**（圆钮 / 签 / 名字
胶囊），它们各自挂玻璃。把带做成玻璃会把「内容从带下穿过」这条作者原令
（2026-11-03 实拍 IMG_1718/1719）直接毁掉。

判别法：**带画不画东西**。画东西（有底 / 有描边 / 有关闭手势）⇒ 按 §7.1 判；
不画东西 ⇒ 零画，登记为 `零画` 并由 G7b 盯着它别偷偷长出底来。
