# RC 低通滤波器 —— 概念讲解讲义小样

> 本文件是 `../../../education/SKILL.md` 的配套示例，演示五段骨架（直觉引入 → 形式化 → 图解 → 常见误区 → 练习）、类比失效边界标注与 ≤3 图预算（本文 2 图）。公共规范见 `../../../core/SKILL.md`。

## 直觉引入

把电容想成一只水塔，电阻是接在水塔进水口上的细水管：

- 水管越细（R 越大）、水塔越大（C 越大），水位升得越慢——这就是「充得慢」；
- 输入电压是泵压：泵压一开（输入跳升），水位不会立刻到位，而是先快后慢地逼近泵压对应的水位线；泵压一关，水位又经同一根细水管慢慢退回。

**类比失效边界**：

1. 水塔类比只给出「慢」的直觉，推不出截止频率公式 $f_c = \frac{1}{2\pi RC}$——水塔系统没有天然的频率轴，凡涉及频域的问题必须回到公式；
2. 电路放电时电荷经同一只电阻流回电源（双向），水塔放水是单向流走，两者路径不同；
3. 「细水管限制流量」容易被读成「水位正比于流量」——实际水位对应流量的累积（积分），对应电路关系 $i = C\frac{du_C}{dt}$，线性直觉在这里失效。

## 形式化

一阶 RC 低通：输入 $u_{in}$ 经电阻 R 接电容 C，输出取电容电压 $u_C$。时间常数与截止频率：

$\tau = RC$

$f_c = \frac{1}{2\pi RC}$

充放电（一阶指数响应，目标值 $U$，初值 $U_0$）：

充电：$u_C(t) = U(1 - e^{-t/\tau})$

放电：$u_C(t) = U_0\,e^{-t/\tau}$

幅频特性：

$|H(f)| = \frac{1}{\sqrt{1 + (f/f_c)^2}}$

本例取 R = 1 kΩ、C = 1 µF，故 τ = 1 ms，$f_c = \frac{1}{2\pi \times 1\,\mathrm{k\Omega} \times 1\,\mathrm{\mu F}}$ = 159.15 Hz。充电进度表（数值由充电公式算出）：

| 时间 | 达到目标值的比例 | 剩余缺口 |
|---|---|---|
| 1τ（1 ms） | 63.2% | 36.8% |
| 2τ（2 ms） | 86.5% | 13.5% |
| 3τ（3 ms） | 95.0% | 5.0% |
| 4τ（4 ms） | 98.2% | 1.8% |

截止频率处的增益：$20\log_{10}|H(f_c)| = -3.01$ dB，即幅度降为 0.7071（功率减半）。

4. ④ 放电同样按 τ 收敛：4τ 后只剩初始值的 1.8%。

## 常见误区

| 常见误区 | 实际情况 |
|---|---|
| 「一个 τ 后电容就充满了」 | 1τ 只到 63.2%；工程上以 3τ～5τ（95.0%～99.3%）视为基本充满 |
| 「f_c 处信号被完全挡住」 | f_c 处增益 −3.01 dB，幅度 0.7071、功率减半；衰减是渐变的，没有悬崖 |
| 「低通滤波器会改变各频率分量的频率」 | 只衰减高频分量的幅度，不改变分量自身的频率 |
| 「τ 和 f_c 是两个独立可调参数」 | 同一电路二者锁定：$f_c = \frac{1}{2\pi \tau}$，τ 大则 f_c 必然低 |
| 「放电走另一条路」 | 简单 RC 中充放电共用同一只 R，仅电流方向相反 |

## 练习

1. R 换为 10 kΩ、C 换为 10 nF，求 τ 与 f_c。
2. τ = 1 ms 时，充电到 95% 需要几个 τ？对应多少 ms？
3. f = 10f_c 处增益是多少 dB？幅度是输入的几分之几？

### 答案

1. τ = 10 kΩ × 10 nF = $10^4 \times 10^{-8}$ s = 0.1 ms；$f_c = \frac{1}{2\pi \times 10^{-4}}$ = 1591.5 Hz。比本例 R 大 10 倍、C 小 100 倍 ⇒ τ 小 10 倍、f_c 高 10 倍。
2. 由充电进度表：95.0% 对应 3τ = 3 ms。
3. $|H(10f_c)| = \frac{1}{\sqrt{101}}$ = 0.0995，增益 $20\log_{10}(0.0995) = -20.04$ dB，幅度约为输入的十分之一。
