# 30 节点小世界网络 —— 关系结构分析小样

> 本文件是 `../network/SKILL.md` 的配套示例，演示五段骨架（数据与建图 → 结构度量 → 静态布局图解 → 交互探索 → 结论与误区）。公共规范见 `../core/SKILL.md`。**本例全部数值由 networkx 3.7 真实计算**（脚本：同目录 `network_demo_gen.py`），非手填。

## 数据与建图

- **节点**：30 个（n=30），编号 0–29，无外部语义（演示拓扑本身）；
- **边**：Watts–Strogatz 小世界模型，`nx.connected_watts_strogatz_graph(n=30, k=4, p=0.3, seed=42)`——环形最近邻 4 条起步、每条边以 p=0.3 随机重连的保证连通变体；无向、无权；
- **规模**：n=30，m=60 条边，平均度 4.00，度范围 2–7；
- **可复现**：图生成与布局 seed 均固定 42，networkx 3.7 下重跑逐值一致。

## 结构度量

指标全部真实计算，对照基线为同边数 Erdős–Rényi 随机图（`gnm_random_graph(30, 60, seed=42)`）：

| 指标 | 本网络（WS，seed=42） | 对照：同边数 ER 随机图（seed=42） |
|---|---|---|
| 平均聚类系数 C | 0.1965 | 0.1033（ER 非连通，取最大连通片 29 节点计） |
| 平均最短路径 L | 2.6069 | 2.3645 |
| 直径 | 5 | — |

小世界商 σ = (C/C_rand) ÷ (L/L_rand) = (0.1965/0.1033) ÷ (2.6069/2.3645) ≈ **1.73 > 1**：聚类系数比随机图高约 1.9 倍，平均路径只多 1.10 倍——「高聚类 + 短路径」同时成立，即小世界特征。

社区发现（贪心模块度，确定性算法）：模块度 Q = 0.4154，划出 **3 个社区，规模 11 / 10 / 9 节点**；跨社区边 15/60（25%），社区内部边占 75%。

## 结论与误区

| 常见误读 | 实际 |
|---|---|
| 「两个节点画得近，关系一定更强」 | spring 布局坐标无绝对语义，只有「有边者趋于靠近」的倾向；定量结论一律以结构度量段数值为准 |
| 「社区着色证明节点硬性归属某群」 | 贪心模块度是启发式划分（此处 Q = 0.4154），节点可跨群连接（如节点 23 一半邻居在界外），着色是视角不是事实边界 |
| 「重跑脚本图变了，结果不可信」 | 图生成与布局 seed 固定 42，重跑逐值一致；交互版物理布局实时收敛、形态每次不同，是算法机制差异而非数据不确定 |
| 「度最高的节点 23 一定是『最重要』的」 | 度中心性只是中心性之一，中介/接近中心性可能给出不同排序；本例仅声明「度 = 7 为全网最大」，不外推「最重要」 |
