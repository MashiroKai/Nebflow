## 概念与算法

《溪山流霭》：暖纸底上的噪声流场长丝。三类元素全部由同一随机序列驱动：

1. **流场长丝（主层）**：240 条，每条从随机起点出发，按三维噪声决定的走向累计 300 步折线；噪声使长丝汇聚成涡——「流霭」即来自场的连续性；
2. **重墨（骨架层）**：18 条粗笔（3.2–5.8 px，高不透明度，仅取墨青/强调两色）压住画面结构；
3. **石（点景层）**：4 枚空心圆石 + 1 枚朱色实心石作视觉锚点。

随机源：`randomSeed(20261004)` 与 `noiseSeed(20261004)` 双双写死；`noLoop()` 单帧绘制；p5.js **1.11.10**（本地库内联进自包含 HTML，版本锁定）。核心逻辑：

```js
randomSeed(20261004); noiseSeed(20261004); noLoop();
for (let i = 0; i < 240; i++) {
  let x = random(-60, width + 60), y = random(-60, height + 60);
  const c = palette[floor(random(palette.length))];
  beginShape();
  for (let s = 0; s < 300; s++) {
    const a = noise(x * 0.0016, y * 0.0016, i * 0.011) * TWO_PI * 1.7;
    x += 3.1 * cos(a);  y += 3.1 * sin(a);
    vertex(x, y);
  }
  endShape();
}
```

## 解读与误区

参数—效果对照（改哪个参数，画面哪个性质会怎么变）：

| 参数 | 控制什么 | 改动方向的效果 |
|---|---|---|
| 噪声尺度 0.0016 | 涡的尺度 | 调大 → 涡多而碎；调小 → 流动更舒展 |
| 步数 × 步长（300 × 3.1） | 丝长 | 调小则丝断成「碎发」（本套件首版实测即此，已修正） |
| 线宽分布 `random()*random()*3.4` | 笔触层次 | 均匀分布则缺乏主次；平方偏细分布偶出粗笔 |
| 重墨数量 18 | 骨架强度 | 0 → 画面发飘；过多 → 糊死 |

| 常见误区 | 实际情况 |
|---|---|
| 「固定了 seed 就永远逐位一致」 | 只在同一库同一版本内成立；p5 升级或换实现（如 numpy）序列即不同——所以版本必须锁定并写进戳记 |
| 「p5 2.x 直接替换 1.x」 | 2.x 是不兼容大版本；本套件锁 1.11.10 |
| 「补色混合必然得灰」 | 在色料（RYB/颜料）语境成立；RGB 均值混合只是其近似演示（图 2 右列即此口径，见标注） |
| 「明度=亮度=明度阶随便混用」 | 本图 L 为 HSL 亮度（colorsys 的 l），与 HSV 的 V、感知亮度 Y 不是同一个数 |
