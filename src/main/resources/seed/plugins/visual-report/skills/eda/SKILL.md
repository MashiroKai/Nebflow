# visual-report-suite · eda — 电路 / EDA 场景

公共规范（铁律 / 嵌入路径 / 暗色 / 渲染器兼容 / 缺装降级总则 / 自检模板）一律见 `../core/SKILL.md`，本文件只写场景增量，不复制通用规则。工具链现状与全量链接验证见 `../README.md`。

## 1. 触发条件

- **原理图讲解**：放大器 / 滤波器 / 电源 / 接口电路等拓扑与工作原理说明，需配真实渲染的原理图。
- **电路分析类报告**：增益 / 带宽 / 噪声 / 静态工作点等由拓扑推导的定量分析，需原理图佐证推导链条。
- **版图 / 截面展示类报告**：PCB 叠层、芯片剖面、封装结构。schemdraw 不做版图——此类图用 EDA 工具（KiCad / 版图工具）原生导出后按 core §2 嵌入；无原生导出时降级为文字分层描述，不手画。

## 2. 报告骨架模板

四节顺序固定；首屏结论先行、≤3 图预算、目录阈值等通用体例按插件 skill 与 core §1：

```markdown
# <电路名称>——<一句话功能结论>

## 电路功能
（输入是什么物理量/信号、输出是什么、关键指标量级；第一段就给结论）

## 原理图
（schemdraw 渲染图 1 张 + 全部位号；图注给信号路径一句话）

## 逐级工作原理
（按信号流向逐级：输入级 → 中间级 → 输出级 → 反馈网络；每级一段，公式只用 $...$ 行内式）

## 关键参数表
| 参数 | 符号/位号 | 数值或表达式 | 来源口径 |
|---|---|---|---|
```

图预算：原理图 1 张为必画项；逐级分析配图（局部重画 / 波形 / 频响）合计 ≤2 张，超限降级表格并按 core §1.3 加「图预算超限」声明。

## 4. 质量红线

1. **元件参数与拓扑不得含歧义臆造值**：原理图必须有位号；元件值（阻容感 / 型号）只能来自用户给的图纸 / 网表 / BOM / 文献。推演或示例值必须显式标注「示例值 / 典型值」并给量级依据；拿不准就只标位号不标值。级间耦合方式（阻容 / 直接 / 变压器）按源材料，不得脑补。
2. **禁止手画 SVG**（core 铁律 1 场景化）：禁止线段 / 矩形拼运放三角形与晶体管符号，禁止 ASCII 电路；一切原理图必须 schemdraw（或 EDA 工具原生导出）真实渲染。
3. **先落盘后嵌入**：图必须 schemdraw 渲染成功写出 PNG/SVG 文件后再按 core §2 路径嵌入；渲染报错走第 3 节降级（文字网表 / 参数表），禁止占位图 / 失败截图充数。
4. **数值逐字**（core 铁律 2）：增益 / 带宽 / 时间常数等计算结果与公式、数据源口径逐字一致；手册或仿真数值标注来源口径。
