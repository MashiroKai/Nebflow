# Human Report — 人类可读汇报规范

给**人**看的文档与给机器看的取证件是两类东西，本 skill 管前者（后者见 `CONVENTIONS.md` §6 的落位表）。图表本身的生成与审美见**同插件**的 `visual-report` skill（本 skill 只管人读化的体例、预算与交付通道）。
规范取值 = 作者 2026-09-13 裁定 **R1–R10 全裁**；逐条真源 = `~/.nebflow/docs/Nebflow/visual-report-human-readable-spec.md` §B/§C/§D/§E/§F/§H（本文件是它的执行面，冲突时以 spec 原文为准）。

## 一、读者轴：路径优先 + 标记行（R2 = 不扩白名单）

两类文档的判定式（判定 < 1 秒；两处绕过已堵：相对路径先 `realpath` 绝对值化，人读区分支先于通配分支判）：

```bash
f=$(realpath "$f")
case "$f" in
  "$HOME"/.nebflow/docs/*) m=$(awk '/^# /{h=1;next} h&&NF{print;exit}' "$f"); [[ $m == '> 读者：人类'* ]] && echo "人类读" || echo "agent 读 · 未分类";;
  */.nebflow/*) echo "agent 读";;
  *) echo "agent 读 · 未分类";;
esac
```

| # | 条件 | 判定 |
|---|---|---|
| ① | 路径 ∈ 任意 `<ws>/.nebflow/**` 或 `~/.nebflow/**`（`~/.nebflow/docs/` 除外，见②） | **agent 读**（标记行在这些路径下**不生效**；出现标记行 = 违规件，须外移） |
| ② | 路径 ∈ `~/.nebflow/docs/<域>/**` 且 H1 后首个非空行 = 标记行 | **人类读**（human-readable） |
| ③ | 其余（含人读区无标记行者） | **agent 读 · 未分类**（fail-safe：人类读必须显式声明） |

- 要给人看，必须**外移**到 `~/.nebflow/docs/<域>/`——写在 `<ws>/.nebflow/**` 下再声明「人读」无效。
- 标记行格式（H1 后首个非空行，一行）：`> 读者：人类 ｜ 类：human-readable ｜ 场景：<§四受控词表> ｜ 自检：<复跑节点 + 日期>`。
- **标记行禁写读数**：自检读数只出现在复核件/附录，由**独立节点复跑**填写（产出者自评不算）。
- 读者轴**不新增元数据键**（不扩 `CONVENTIONS.md` 白名单、不动 `INDEX.md` 判据与生成器）；读者轴与 `doc-class`（stage/live，寿命轴）是两个维度，禁塞进同一键。
- 人读件落位：交付/汇报 → `~/.nebflow/docs/<域>/`（活文档 `<topic>.md`、阶段件 `<YYYYMMDD>_<HHMMSS>_<topic>.md`，尾段溯源按 `CONVENTIONS.md` 现文）；取证件/过程件 → `<ws>/.nebflow/{Spec,evidence,reports,tasks,results,tmp}/`（**禁止**标记行，不登记索引）。
- 索引登记由生成器 `index-backfill.py` 只读扫描产出——**禁手改 `INDEX.md`**；人读件的可发现性由此承接。

## 二、体量三级预算（R1 钉死 20,300 / R10 附录豁免）

| 级 | 范围 | 上限 |
|---|---|---|
| **首屏** | 第一个 `## ` 章节（到第二个 `## ` 之前） | **< 8 KB 且 < 80 行** |
| **正文** | 首字节 → `## 附录` 之前（含首屏） | 场景上限（§四），绝对硬顶 **20,300 字符** |
| **附录** | `## 附录` 之后 | ≤ 正文 **5×**；**不得载唯一结论**；**须有目录** |

- 硬顶**钉死 20,300 字符**（= 快照中位取整，可复现、可机械执行）：不浮动、不逐日重算——浮动口径每天在变、单向上漂（棘轮），且不可复现。
- 单位以**字符**为准：中文 1 字 = 3 字节，用字节卡中文 = 用编码惩罚写作语言；字节/行只作诊断读数。
- 超出即**先砍到上限再交付**，不得「先发后砍」；确需保留的长取证内容进附录（附录豁免见上表三分句）。

## 三、首屏四段骨架（R3，顺序固定）

1. `### 结论` —— ≤5 行，**第一句就是结论**（不是背景、不是「本次任务」、不是过程叙述）。
2. `### 要做什么 / 有什么影响` —— 两栏表；影响必须回答「要不要你决定」「有什么功能会变」。
3. `### 大白话` —— **≤150 字符**、零术语：不含反引号、不含 `file:line`、不含 `n-xxxxxxxx`/`chain-`/`TS-`、不含未翻译英文词（`agent`/`Canvas` 等）。
4. `### 术语对照` —— 每个非日常词一句人话（无则写「无」）；术语**只在此处第二次出现**（第一次在正文首用时就地解释）。

## 四、场景档位（正文上限，字符口径）

| 场景 | 识别信号 | 正文上限 | 必须有 | 可视化 | 语气 |
|---|---|---|---|---|---|
| **文献调研** | 查/对比/调研/评估 X vs Y | ≤ 12,764 | 结论（选了谁/为什么）→ 对比表（≤5 行×≤6 列）→ 不确定项 | 三方以上对比用表；有数值维度**必须**画横向条形图 | 中立，点明「哪一条会改变结论」 |
| **产品设计** | 设计/方案/规范/拍板 | ≤ 20,300（硬顶） | 结论 → 要做什么·影响 → 裁定项清单（每项含「不做」）→ 验收口径 | 状态机/数据流/分层**必须** graphviz；选项对比用表 | 直接给判断，不给「可能/也许」 |
| **改 bug·加功能** | 修/坏/不生效/加一个 X | ≤ 8,000 | 一句话结论（现象→根因→修法）→ 改动面（文件+行）→ 影响面 → 生效前提 | 调用链 ≥3 跳**必须**画（graphviz LR）；单点修复可不出图 | 用现象词，不用机制名 |
| **事故复盘** | 事故/被杀/丢了/回滚了 | ≤ 12,764 | 结论（不是谁的锅、触发条件有几种）→ 时间线 → 防复发 → 未堵的口子 | **必须**时间线（mermaid gantt / matplotlib 事件轴）+ 因果链流程 | 先回答「还会不会再来一次」 |
| **验收报告** | PASS/FAIL/验收/复核 | ≤ 4,000（半屏） | 结论（过/没过）→ 逐条判据表（判据｜读数｜判定）→ 唯一需注意的事 | 通常无图；判据含数值阈值时给一张阈值对比图 | 只给判定与读数，不给过程叙事 |

档位推导（可复现）：验收 4,000 = 改 bug 档 8,000 的半屏；改 bug 8,000 = 一屏放宽上界（快照字符/行中位 72.5 × 80 行 ≈ 5,800，上浮覆盖表格/代码块）；调研·复盘 12,764 = 字符中点 (20,300 + 5,225) ÷ 2；设计档 = 硬顶本身。

## 五、禁项（每条给二值判据，脚本见 §八）

| 禁项 | 判据 |
|---|---|
| 术语裸用 | 正文（附录除外）反引号字符占比 > **0.030**（= 语料中位） |
| 内部 id 裸奔 | 首屏 / 大白话段命中 **ID 正则 v2**（`.md:行号`、`.scala:210`、commit 哈希、`PID 12345`、`n-1a2b3c4d`、`chain-…`） |
| 无信息量的过程叙述 | 行含「已排查/已完成/已对齐/基本/若干」且该词不在「」内、且同行无数字 |
| agent 交接语言倒给人类 | **首屏**出现五要素骨架标记（①做了什么/②依据/③没做什么/④产出/⑤关键假设）——口径 = **首屏**，正文内引用条款原文不计 |
| 原文粘贴 | 正文内任一代码块 ≥8 行且含原始输出特征（`$ ` 提示 / INFO·WARN·ERROR 日志 / ISO 时间戳 / diff 的 `+`·`-` 行）；或正文单节 > 6,000 字符 |
| 指示人类去开路径 | 正文行同时含「请看/请查阅/打开」与路径 token |

- **条款文本豁免（R1 = D1）**：spec / 裁定件 / 逐条判据表以逐条引用为体，反引号是引用语法而非术语裸用 ⇒ 判**豁免**，但仍适用正文硬顶；判定人 = **独立复核节点**，须记两项读数（反引号字符数 + 占比）。
- 密度阈必须有基线：0.030 = 同快照语料中位（原「>5 处/100 行」对全库恒红，已作废）。

## 六、可视化：该画必须画 + ≤3 图预算（R6 = 硬性）

**必须画（任一命中即出图，图落在首屏或其紧随）**：

| 信号 | 判据（可机械识别） |
|---|---|
| 数据对比/趋势（≥2 组数值） | `数值+单位` 配对 ≥2；去单位不免疫：同段 ≥2 组数值 **且** 含比较词（vs/对比/相差/倍数/高于/低于） |
| 流程/调用链/状态机（≥3 节点） | **全文归一化计箭头**：`→`/`->` 总数 ≥3；或「分流/分支/状态机」≥2 |
| 结构/分层/拓扑 | 「分层/架构分层/层级/模块/拓扑/归属」≥3 |
| 时间线（≥4 事件） | 显式时刻（`\d{1,2}:\d{2}` 或 `\d{4}-\d{2}-\d{2}`）≥4；无时刻字面也命中：顺序词（第一步/然后/接着/随后/最后/首先）≥4 |
| 三方以上对比 | markdown 表数据行 ≥3 且列 ≥3 |

**禁止画**：无数据的装饰（图引用所在节内 `数值+单位` 配对 <2）；与结论无关的全景/总览图（图名含「全景/总览/overview」且该节无结论句）；手画 SVG/HTML 坐标（含 `<svg`/`<path d=` 且无工具来源标注）；PNG 替代矢量（引用 `.png` 且非截图类）。

**预算与冲突解（硬）**：单文档 **≤3 图**、单图 ≤1 个视觉故事。
① 权重：结论依赖的数据关系(5) > 时间线(4) > 流程/调用链(3) > 三方对比(2) > 结构/分层(1)。
② 处置：命中类别数 n ≤3 ⇒ 全画；n >3 ⇒ 只画权重前 3，其余降级为表/文字，并在**首屏**加一行「图预算超限：已按权重取前 3 类（省略：<类别>）」。
③ 例外：被省略的类别是结论的唯一载体 ⇒ **拆文档**，不得静默省略。
④ 硬要求（既有纪律）：输出 SVG + 专业工具生成、暗色自适应（亮/暗对比度 ≥4.5:1，禁硬编码前景色）、颜色走调色板常量（禁彩虹色编码分类）。
⑤ 条款文本类豁免：以列判据为体的 spec 免「必须画」与 §③ 的图预算声明，不判手画 SVG（判定人 = 独立复核节点）。

## 七、交付通道：不靠 Pop（展示权归 Nebula）

- **形态**：完整件**落盘**（人读件 → `~/.nebflow/docs/<域>/<name>.md`，标记行 + §二/§三全套；取证件 → `<ws>/.nebflow/<区>/`）；**result 文本 = 一屏摘要**（骨架同 §三，< 8 KB / 80 行）+ **一句**「完整交付物：`<绝对路径>`」，**禁**粘长正文。
- **投递**：沿 out 边以 `mode: result` 投给下游 / 链末端 / Nebula。
- **展示**：Nebula 收到 result 后若含人读件路径 ⇒ 读标记行 ⇒ 人类读件 **且** 过本规范自检 **且** 作者点名，才进 Canvas（作者点名是触发时机，不是判据）。
- 节点侧纪律：**禁止**在交付文本里指示人类打开某路径（无法保证展示发生）；**禁止**自造替代展示通道（写 HTML 到 `/tmp` 再请人打开无效）；不得要求插件授予展示权限——`Pop` 为 Nebula 专属，节点调用被拒（`POP_NEBULA_ONLY`）。

## 八、自检（产出后必跑，只警告不阻断）

```bash
node <repo>/scripts/verify-human-docs.mjs <文件> [<文件>…]      # 门：逐条判据 + 计数，只警告不阻断
python3 <repo>/scripts/human_doc_lint.py <文件> --scene 产品设计 --kind 条款   # 逐项读数（体量/首屏/骨架/禁项/图预算/附录）
```

- 门禁形态（R8 = A）：**只警告不阻断**——存量文档几乎全红，立即阻断会卡住所有合并；CI 阻断（R8 = B）待存量消化后另批开。
- 判据 = §五六条 + §二体量 + §三骨架 + §六图预算 + §R10 附录三分句；`--kind 条款` 走密度豁免分支。
- 产出者跑门 → 读数交**独立复核节点**；标准与判定不合并到同一处。
