# 合成 OHLC 演示 —— K线 + 成交量 + MA20 小样

> 本文件是 `../finance/SKILL.md` 的配套示例，演示五段骨架（数据口径声明 → 数据准备 → 主图 → 辅助图 → 读图要点与误区）。公共规范见 `../core/SKILL.md`。脚本：同目录 `finance_demo_gen.py`（mplfinance 0.12.10b0 真实渲染），全部读数可复算。

## 数据口径声明

**模拟数据，非真实行情。** 本例全部 OHLCV 为程序合成演示数据（固定种子 seed=42），不含任何真实标的、代码或名称，不构成任何投资参考。

合成模型（60 个交易日，工作日历 2026-06-01 ~ 2026-08-21；合成数据无复权概念、无停牌）：

- 对数收益 N(0.0008, 0.018)，收盘价几何随机游走（期初 100.00 起步）；
- 开盘跳空 N(0, 0.004)（今开 = 昨收 × e^跳空）；高低影线 |N(0, 0.008)|；
- 成交量 = 2,000,000 × e^{N(0, 0.35)} × (1 + 25×|日收益|)——放量与波动幅度正相关。

## 数据准备

- 字段：Open / High / Low / Close / Volume，DatetimeIndex 工作日频率；
- 合法性断言（脚本内 assert，已通过）：High ≥ max(Open, Close)、Low ≤ min(Open, Close)、Volume > 0；
- 关键读数（脚本真实计算）：期初收盘 100.63 → 期末收盘 112.58，区间 **+11.88%**；区间最高 115.47（2026-08-11）、区间最低 93.12（2026-06-15）；阳线 36 根 / 阴线 24 根；年化波动率 22.45%；日均量 2,752,900，峰值量 7,829,000（2026-06-05）。

## 读图要点与误区

| 常见误读 | 实际 |
|---|---|
| 「区间 +11.88%，MA20 向上，之后会继续涨」 | MA20 是滞后确认指标：末日 MA20 = 110.73 只确认已发生趋势，低于期末收盘 112.58 的偏离不含任何预测信息；模拟数据更无「走势」可延续 |
| 「6 月上旬那根放量长阳是资金进场信号」 | 峰值量 7,829,000（2026-06-05）只是模型中 \|ret\| 放大项的一次随机抽样；模拟数据不存在「资金」，真实行情此类解读需先核数据来源与口径 |
| 「影线代表盘中真实冲高回落」 | 本例影线是 \|N(0, 0.008)\| 合成的，仅满足 High ≥ max(O,C)、Low ≤ min(O,C) 的合法形态；真实行情影线解读还受成交时段、流动性影响 |
| 「红涨绿跌是通用惯例」 | 色约定随市场：A股/东亚红涨绿跌，美股语境通常绿涨红跌；跨市场交付必须像本文一样显式声明配色约定 |
