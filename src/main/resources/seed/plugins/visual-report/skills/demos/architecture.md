## 任务与数据声明

任务：演示 architecture 场景的「平面 → 轴测 → 体块交互」三件套表达，并实证 three.js 不可用时的静态降级通路。用途为场景方法演示，不承担真实设计结论。

数据：一组合成的米制方案数据（下表），平面图、轴测图、three.js 体块模型**三件共用同一份**——这是建筑表达「多图同源」红线的演示要点。

## 校核与误区

| 校核项 | 验算 | 结论 |
|---|---|---|
| 尺寸链闭合 | 3300+3000+3300 = 9600；4200+4200 = 8400 | 与总尺寸逐字相等 ✓ |
| 面积闭合 | 13.86+12.60+13.86+22.68+17.64 = 80.64；×2 = 161.28 | 与 9.6×8.4 = 80.64 一致 ✓ |
| 门窗洞口 | 各洞口起点+宽度均不越过所在墙段轴线区间（如入户门 4900+800=5700 ≤ 6300 所在开间界） | 无越界 ✓ |
| 屋面坡度换算 | 三件套同用一坡：平面数据 2400/4200，three.js 场景常数 RUN=4.6、RISE=2.629（含 400 挑檐），$\arctan(2.629/4.6) = 29.74°$ | 三处一致 ✓ |

| 常见误区 | 实际情况 |
|---|---|
| 「房间面积就是轴线乘出来的数」 | 本篇面积按轴线计（表内已注明口径）；净面积要扣墙脚，两者不等 |
| 「轴测图=透视图」 | 轴测无灭点、平行线保持平行（本篇为等轴测近似投影）；透视有灭点，二者不可混称 |
| 「体块模型可以当施工图用」 | 体块只表达体量与开洞位置，无墙身/构造/标注层级，深度表达止步于此 |
| 「1:100 是屏幕上量出来的」 | 1:100 是图示比例约定（图上 1 mm = 实际 100 mm），屏幕显示尺寸随窗口变化，以标注数值为准 |
