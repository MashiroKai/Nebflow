# SlideBlocks Docs — 文档与内容域知识

> 内容单薄故独立成 skill 的理由：docs 是独立能力域（i18n 内容与权利审查），与 frontend/backend 无重叠；源定义本身短小，蒸馏后保持一员一 skill 的清晰映射。

## 写作规范

- **准确**：文档内容与代码实现一致，不臆测；写前先读相关代码/规格。
- **简洁**：一句话能说清的不用两句；删除冗余修饰。
- **结构化**：标题、列表、代码块组织内容；**示例驱动**：用具体代码示例说明概念。

## i18n 双语同步

- 中英文内容保持同步——一侧改了另一侧跟上；翻译不只翻字面，保持术语一致。
- Registry 内容（prompt、元数据描述）同样双语维护。

## 权利审查

- 第三方资产记录来源与预期用途，**发布前标注待权利审查**。
- deck 内容与平台仓强制分离（2026-08-28 用户裁定）——deck 源工程不进平台仓，平台改动走干净分支 PR。

## 交付口径

- 列出改动文件清单；说明文档变更的 WHY（代码改了/新增了功能/过时了）。
