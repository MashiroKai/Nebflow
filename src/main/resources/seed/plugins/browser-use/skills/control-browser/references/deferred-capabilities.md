# 暂不可用能力登记（缺什么 + 补齐后即可用）

本文件是**诚实登记**，不是待办清单、也不是承诺。
凡本包未携带、或本平台暂无载体的能力，都在此列明**缺什么**与**补齐到什么程度即可用**。
**不要**在缺这些面时用别的手段凑结果。

命名约定：`源件` 一律用**相对标识**（不含绝对路径），逐项绝对路径与字节读数见交付台账。

---

## D-1 常驻浏览器服务（跨调用复用）

- **源件**：`dist/mcp/server.js`（浏览器 MCP server 构建产物）、`scripts/browser-client.mjs`（bootstrap 模块）
- **为何依赖（缺什么）**：本平台插件装载面只认 `plugin.json` / `mcp.json` / `skills` / `org.nebflow`
  四类顶层条目；常驻服务必须由 `mcp.json` 声明的 MCP server 承载。
  现有形态是**每次调用一个进程**的脚本驱动，页面/句柄不跨调用存活。
- **补齐后即可用的判定**：
  1. 存在一个可装载的 browser MCP server（`mcp.json` 可声明，stdio 或回环 streamable-http 均合法）；
  2. 该 server 在隔离实例里装载成功、工具以 `mcp__plugin_<plugin>_<server>__<tool>` 注册名可见；
  3. 一次工具调用能返回结构化的页面事实（而不是要求调用方自带脚本）。
  ⇒ 满足即「常驻服务可用」，本 skill 的载体判定表随之增加一行，纪律不变。

## D-2 浏览器容器级隔离（外域交互式操作的前置）

- **源件**：容器链相关件（镜像变体、容器生命周期、MCP server 接入）
- **为何依赖（缺什么）**：外域站点的**交互式**操作与页面内容需要**容器级隔离**
  （独立网络面、容器内 profile、销毁即清零）。本平台该链条尚未落地：
  per-task 容器生命周期与 MCP server 接入是它的两个前置件，二者均未实现。
- **补齐后即可用的判定**：
  1. per-task 容器生命周期可用（启动 / 执行 / 销毁三件齐备）；
  2. MCP server 由容器承载，回环发布端口可达；
  3. 容器内浏览器可访问被测目标，且宿主侧 `ps` 无宿主浏览器进程。
  ⇒ 满足即「外域交互式操作可用」，届时本 skill 的边界表把该行从「暂缺」改为「可用」，纪律不变。

## D-3 页内视频录制（WebM）

- **源件**：`docs/recording.md`
- **为何依赖（缺什么）**：源件语义是**录制宿主内的浏览器标签画面**（依赖宿主内建
  媒体录制能力与隐藏渲染面）；该渲染面属容器链/宿主运行时的组成部分，本平台无对应载体。
- **补齐后即可用的判定**：存在一个能对**受控页面**做定时录制、并产出可交付文件（含完成态与
  产物路径）的载体能力 ⇒ 满足即可用；在此之前不要把「截图序列」宣称为「录像」。

## D-4 应用内浏览器面板与标签认领

- **源件**：`docs/visibility.md`、`docs/tab-claiming-iab.md`、`docs/tab-cleanup-iab.md`、
  `docs/tab-cleanup-iab-internal.md`、`docs/all-tabs-cleanup.md`
- **为何依赖（缺什么）**：这些件描述的是「宿主侧有可见浏览器面板、可展示/隐藏面板、
  可认领用户已开标签、标签有交付/交接标记」这一整套**宿主 UI 面**。
  本平台没有可见浏览器面板（浏览器活在一次性脚本进程里），因此该套语义无载体。
- **本载体另有一条来源缺口（同属本项）**：源件的「**用户已开页列表**」（宿主侧「用户标签」查询一类能力）
  在本载体**没有任何通道可得**——自持脚本只能看到自己 `context` 内的页面。
  ⇒ 产物提示词里凡涉及「读用户页 / 认领用户标签 / 枚举别人的页面」的语义，一律按本载体改写
  （见 `page-lifecycle.md`：不存在「别人的页面」，`context.pages()` 即全部可见面），
  **整条标签认领/清理语义归入本项**，不留在产物里当硬指令。
- **补齐后即可用的判定**：存在「可见浏览器视图 + 用户标签列表 + 标签生命周期标记」三类载体能力
  ⇒ 满足即可把标签认领/清理纪律按原语义迁回（届时「用户已开页列表」来源一并恢复）。
  **本包已保留可迁移的部分**：页面/上下文的生命周期纪律见 `page-lifecycle.md`
  （列出现有页面 → 按已验证事实匹配 → 只关有意关的）。

## D-5 宿主浏览器对象图文档（`docs/api.json` / `docs/documents.json`）

- **源件**：`docs/api.json`、`docs/documents.json`
- **为何依赖（缺什么）**：二者描述的是**宿主内部对象图**的 API 面与文档装载清单，
  直接带入会指向本平台不存在的 API（比「没有」更坏——它会让节点去调用不存在的方法）。
- **补齐后即可用的判定**：若将来出现常驻浏览器服务（D-1/D-2），其**实际**能力面文档应重新生成、
  与真实工具面一一对应后再带入 ⇒ 满足即替换本项。在此之前**不带入**。
