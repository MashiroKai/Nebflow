# 载体现状与可用面（overview）

## 一、本平台里「浏览器」到底是什么

交互可由脚本驱动，也可使用 browser-session 的独立有头 Chrome、专用持久 profile 和 CDP attach；引擎九动词须以实际挂载为准。脚本载体示意：

```
节点会话
 ├─ Bash ──▶ node <脚本.mjs> ──▶ Playwright ──▶ chromium（真实浏览器）
 │                                  │
 │                                  ├─ 结构读取：DOM / 可访问树 / locator 查询
 │                                  ├─ 交互：click / fill / press / selectOption / scroll
 │                                  └─ 截图：page.screenshot({ path: <绝对路径> })
 └─ Read ──▶ 读回截图文件（唯一的视觉通道）
```

三个事实决定了纪律的形状：

1. **每次脚本调用是一个新进程**：变量和页面句柄不跨调用存活；CDP 会话的浏览器、页面与 profile 登录态可以存活，每轮重新连接并观测。
2. 一次性脚本可自行启动浏览器；持久会话则由 browser-session 启动独立浏览器。各自遵循载体进程与清理纪律。
3. **视觉只有一条通道**：截图落盘 → 用 `Read` 读该文件。
   **图不落盘不成证据；落了盘不读也不算看过。**

## 二、可用面 / 不可用面（硬边界）

| 面 | 状态 | 说明 |
|---|---|---|
| 打开/导航页面 | ✅ | `page.goto(url)` + 显式确认加载状态 |
| 结构化读页面 | ✅ | DOM / 可访问树 / locator 的 `textContent`、`getAttribute`、`isVisible` 等 |
| 交互（点击/输入/选择/滚动/键盘） | ✅ | locator 终态方法；坐标路径留给观测读不到的目标 |
| 截图取证 | ✅ | 落盘 + `Read` 读图 |
| 视口/响应式 | ✅ | `page.setViewportSize` |
| 控制台错误采集 | ✅ | `page.on('console')` / `page.on('pageerror')`（只读） |
| 只读取页面正文（不需要交互） | ✅（另一种载体） | 内置 `WebFetch`；比开浏览器便宜得多。**反爬 / JS 挑战页**靠它的**分层回退链**（第 1 层 HTTP 直取 → 第 2 层浏览器回退：Obscura → Playwright）；**回退层在本产品当前发行形态不可用** —— 浏览器回退层（Obscura→Playwright）不随发行包装载（运行期按 classpath 探测，未装载即不可用）⇒ 实际只剩第 1 层（HTTP 直取）可用；挑战页取不到正文 ⇒ 按 `SKILL.md` §五 如实记为**能力缺口**，不要改用别的手段凑结果 |
| 外域站点的**交互式**操作 | 条件可用 | 合法授权目标，专用 profile 与 CDP；先自检，见 `SKILL.md` §八 |
| 浏览器与页面内容的**容器隔离** | ⛔ 暂缺 | 增强项而非外域交互前置；见 `deferred-capabilities.md` |
| 浏览器跨调用复用 | 条件可用 | browser-session 的持久 Chrome 与 CDP；MCP server 形态未移植 |

## 三、判定顺序（每次开工先走一遍）

1. 这次要的是**正文**还是**交互/视觉**？只要正文 ⇒ `WebFetch`，别开浏览器。
2. 要交互或要图 ⇒ 走 Playwright 脚本，并先做开工前自检（`SKILL.md` §七）。
3. 外域目标须先确认用户有合法访问权与任务授权，再按 `SKILL.md` §八使用专用会话；明确要求容器隔离而未具备时停手。
4. 需要视觉证据 ⇒ 截图必须落盘并读回。

## 四、与相邻能力的分工

| 需求 | 归属 |
|---|---|
| 关键字检索线索 | 内置 `WebSearch` |
| 某 URL 的正文（只读） | 内置 `WebFetch` |
| 原始 HTTP 请求/响应（自定义头、方法） | 内置 `Curl` |
| 打开页面并与之交互、截图、验收 | 本 skill（Playwright 脚本） |
| 把浏览器流程**委派**给别的会话/子会话 | **不行**：委派体拿不到本 skill（注入面只到被挂载的会话）与你的脚本进程 ⇒ 证据链断裂，见 `SKILL.md` §二 |
| 出自图/图表/汇报件 | 另配可视化汇报类插件，不要在这里做 |
| 仓库内检索 | `Grep` / `Glob`，不联网 |

边界一句话：**交互归这里，检索归检索工具，只读正文归抓取工具，出图归出图插件。**
