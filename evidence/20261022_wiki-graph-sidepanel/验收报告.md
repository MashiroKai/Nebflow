## 承接与偏差申报

1. **移动层 panebar（批令外的承接项）**：手机壳没有左栏，若控件全部撤出 canvas 则移动端图谱零控件（回归）。落法 = `.wg-panebar`（搜索+chips+统计行）随 pane 收编进移动页，仅 `body.mobile-layer` 显示；桌面 canvas 保持零控件。断链清单移动层不给（计数仍在统计行）。e2e `[mobile]` 两条断言实证。
2. **本仓 docs 已零断链**：`check_wiki_docs.py` 基线 51 条既有断链是 `index.md` 指向不存在词条（基线既有，非本批引入）；图谱口径下 0 条未解析 → harness 注入 1 条合成 phantom stub（与前端口径一致：只计数、不立节点）保证「断链区块」四态可验收，注入行为打印 note 并登记于此。
3. **预览卡滑入动效退役**：详情卡常驻左栏，不再浮动滑入；`wiki.closePreview` 词条语义改为「关闭详情」。
4. **图例退役**：canvas 右下图例一行随控件撤出批令删除（`wiki.legendLine` 词条删除）；「这是什么图」的解释由悬停 tooltip + 左栏统计行承载。
5. **check-circular 门**：本批 wikiGraph→activityBar 为动态 import（许可路径）；该门在基线即红（SCC 与本批无关，stash 对照实证），未恶化。
6. **tests/mobile-p9-graph.spec.mjs 基线即红**：其断言对象是 2026-10-19 旧面板面（`.wiki-toolbar-status`/`.wx-zoom`），已随 10-21 极简化批退役——非本批引入，不在本批范围。
