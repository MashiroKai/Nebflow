## 一、A 胶囊化（split.css §⑨ + index.html + mobileLayer.css §⑨）

- `.canvas-header` 实条 → **浮层胶囊**：`position:absolute; top:10px; left:50%`（translateX(-50%)）+ `width:fit-content; max-width:min(76%, calc(100%-124px))`（右缘给 deck fab 留位）+ `border-radius:999px` + `--glass-control-*` 玻璃语言（blur+saturate backdrop、内嵌高光/下缘、双层投影）。原 46px 桌面实条规则整块退役（L611 §⑨ 单一来源）。
- **内容不再为 header 预留**：`#canvas-content` margin-top 4px→0，顶满 `#canvas-slide`（CC0-4 钉 content.top === slide.top）。
- **穿底渐隐**：`.scroll-under-glass` 挂上 header（index.html）——复用既有裙边机制（::after blur+tint+mask 渐隐），几何按胶囊放宽（左右各外延 18px 盖圆角端，裙高 24px；tint/暗色档沿用工具类缺省）。
- **手机通栏变体**（mobileLayer.css §⑨）：`left:10px; right:10px; width:auto; top:8px`，保留 `--head-*` 跟手位移变量链；长按触感类 `is-longpress`/`is-pressed`（scale .97 + brightness .9）与桌面同 CSS。
- **卡窗态（⑧）自然适用**：`body.card-window` 同一 `.canvas-header`，「合并」钮随行入胶囊。

## 二、B 桌面手势（canvas.js initCardHeadGestures，initCanvas 调）

- **按压触感**：pointerdown（非按钮）即 `.is-pressed`（scale .97 + brightness，CSS）；起拖换 `.is-dragging`（关过渡 1:1 跟手，`--head-dx/--head-dy` 变量，钳 ±18/±12px），松手回弹。
- **上下滑换卡 = deck 同语义**：同环（`deckBuildRing`，ring[0]=active）、同向（dy>0 下滑=+1 下一张）、同阈档（轴锁 8px = `DECK_AXIS_LOCK_PX` 档；释放 |dy|>48 换一张，平局取纵——非破坏优先，与 deck 同规）。deck 开着时经 `setActiveTab → deckRemountForActive` 自动收敛（外部换签既有通路）。
- **左右滑关卡 = closeTab 共核**（deck 划走关闭同语义），释放 |dx|>64。
- **右键 = 引用**：复用既有 `showCanvasRefMenu`（canvas-tab-context-menu 玻璃菜单形态）；deck 开时传同款 actions（关闭/关闭其他），`stopPropagation` 防面板级菜单双弹（CC4-4 单菜单三项实证）。
- 钮群（`#canvas-pop-btn`/`.canvas-merge-btn`/`#canvas-close-btn`）closest 直通永不吞点击；点击界内（未过轴锁）零动作。
- **手机层整腿让位**：`isMobileLayer()` 守卫 pointer/contextmenu —— 卡头手势归 navController（首轮实证双绑会互相覆盖激活页签：桌面腿把手机换卡改写成环邻位面板页签）。

## 三、C 手机端（navController initCardHeadTouch，ensureCardHead 建购后一次）

- **无按压前置**：pointerdown 即武装；轴锁 8px 后直滑生效——上下滑（释放 |dy|>48）= `switchDocCard(±1)`（环 = `docTabs()` 卡片层序，下滑=下一张）；左右滑（|dx|>64）= `closeCard()`（既有邻卡落位）。
- **长按 450ms**（未锁轴未抬起）= 触感（`is-longpress` → scale/brightness）+ `navigator.vibrate(8)` + 浮出 `.mobile-card-ref-btn`（玻璃胶囊钮，视口坐标落点钳屏内）→ 点击走 `quoteActiveCardRef()`（canvas.js 新导出，与桌面右键「引用当前页」同一 `appendRefToActiveView` 通路）→ 引用 chip 进 `#attachment-preview`；外部按下/滚动/换卡即收。
- **canvasGestures 三带划分修订**：卡头带整带移交胶囊手势（不收层、不切卡、不跟手位移）——「上滑收层」只剩底缘带（40px home-indicator 带）一条通路；⑨ 胶囊换卡取代旧「头上滑收层」语义。内容区 `touch-action:pan-y` 原样。

## 四、D 布局统筹与层关系（作者令 D 报告）

**布局小图（文字版）**：

```
桌面 canvas 面板（#canvas-panel → #canvas-slide）
├─ [胶囊 .canvas-header]  absolute top:10 水平居中, fit-content
│    = [t-icon][t-dot][t-name][#canvas-pop-btn(⑧独立/合并)]     ← tab-bar/close 桌面隐藏(既有)
├─ [#canvas-content]      顶满全高（顶=slide 顶），pane 文字全高滚动、从胶囊底下穿过
└─ (面板外) #deck-fab     body 级 fixed top:10 right:12（v5② 逐字不动，堆叠钮挂点不变）
   (面板外) #deck-layer    deck 开：环卡舞台（③④快照/翻动域）

手机卡片层（body.mobile-layer.mf-cards-live）
└─ [胶囊 .canvas-header]  通栏变体 left/right:10
     = [.mobile-card-head: title][count][pop(⑧)][close]
     + 长按浮出 .mobile-card-ref-btn（fixed 视口落点）
```

**层关系**：卡头胶囊 = canvas 面板**内**浮层（面板裁剪盒内 z-30），与 uifix ⑦ 消息区裁剪契约（main.js `syncTopReserve` 写 `#chat` margin-top = 主窗 header 盒底）分属不同列/不同层，零交集；与 deck 环卡层/fab（body 级 z-250）正交——deck 开时胶囊仍在面板顶带可见可右键（CC4-4 实证单菜单三项），③④快照/翻动手感作用于 deck-layer 环卡，互不触碰。**滚动分区契约**：胶囊手势只绑胶囊元素且 `touch-action:none`；内容滚动发生在 pane 内部滚动器——CC5 钉「次阈竖拖后 pane scrollTop 不变 + 滚轮正常滚」。
