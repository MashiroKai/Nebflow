## Coverage and open items

- Commit-range size: 2,501 commits, 3,734 approximate paths per supplied baseline count. Git reported exhaustive rename detection skipped due to scale; this is a targeted scan of changelog claims and config/schema/CLI/API/tool/install/update/storage hotspots, not a line-by-line history or full compatibility audit.
- The matrix uses baseline implementation and named tests as traceability, not test-run claims. No npm install, sbt build/test, browser E2E, installer rehearsal, live-user data migration, or external CI acceptance was performed.
- `node scripts/check-tag-format.mjs` only tests workflow/installer tag string shape; it cannot validate changelog wording, artifact health, all release gates, or compatibility.
- Do not use the October 29 remote CI run as candidate evidence. Re-check final source tip for excluded/unmerged T1/T2/T3, lifecycle production fixes, Task query/passive reminders, and any late merge before final release approval.
- Version/date remain unset here by design. Current VERSION is not a final release number. No tag, publish, or version edit is part of this task.
