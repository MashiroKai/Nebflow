# 本地文件大传输触发重连 · 诊断修复批（loopback-nearpath）

时间：2026-10-22 17:30 – 18:40 · 执行：诊断修复批 delegate（worktree delegate-nebflow-59f171d8）· 纪律：生产隧道零触碰（只读）；relay.rs / 门户页（独立仓）零改动，全部落在本仓。

## 结论（一句话）

**根因 = Mac 本机控制台默认经 portal→relay 隧道链加载（`PortalUrl` 缺省开门户，仅 `NEBFLOW_OPEN_UI=local` 回落本地），本机文件字节（WS `readFile` 大 content 帧 / `/api/nf-file` 隧道流）与 WS 应用层心跳 pong 共用同一条单帧串行隧道流——bulk 帧占头 ⇒ pong 迟到 ⇒ 前端 `HB_MAX_MISSES=3` 自我逐出（`state.ws.close()` → `scheduleReconnect`）＝作者看到的「点开大文件就重连」。修复 = 控制台页自检同机近路（本机回路短路）：relay 源页面按「portal/status → loopback-info 拿端口 → 环回 /api/health 核对 deviceId → relay 铸一次性票 → 环回兑换」四步判定跳回 `http://127.0.0.1:<port>`，本地文件从此零隧道；外加心跳传输遮蔽兜底（传输在途不逐出、12 窗硬上限），远端设备场景同受益。**

## ② 修复（本仓三面，生产隧道只读）

### 修复 A · 本机回路短路（主修，诊断方向①+③）

引擎侧（`gateway/HealthRoutes.scala`）：
- **新增 `GET /api/health/loopback-info`**（withAuth 会话门）→ `{"port": <gatewayPort>}`——控制台页（经隧道加载）拿本机端口锚；端口非身份面，身份核对锚仍由环回 `/api/health` 的 deviceId 键承担，两键合起来才构成「同机确认」。
- **CORS 白名单并入中继 origin**（`allowedProbeOrigins` = 门户 origin + `Branding.serverUrl` origin）：控制台页本身托管在中继 origin（link.mystand.space）下，它发起的环回探测与中继 consoleUrl 同族（同为我们控制的 origin）；非环回腿 / 其他一切 origin 照旧零 CORS 头。

前端侧（`web/js/ws.js` 新增 `attemptLoopbackNearPath`，首次 connect 触发、全程不阻塞）：
1. `GET /api/portal/status` 可达且带 `boundHost.deviceId` ——只有 relay 源才有此面；本地/LAN 直连源 404 ⇒ 停留（判别源 = 加载路径，非 hostname）；
2. `GET /api/health/loopback-info` 拿端口；
3. 探 `http://127.0.0.1:<port>/api/health`，`deviceId` 必须与第 1 步一致（跨设备/无本机网关/PNA 拒答 ⇒ 停留）；
4. `POST /api/portal/console-ticket`（复用 remint 同一端点）铸一次性票，把票挪到环回兑换面：跳 `http://127.0.0.1:<port>/?ticket=<t>` → 网关 `ConsoleTicketRoutes` 兑换（#522 已保证 http 环回腿 cookie 不挂 Secure）→ 会话落本地直连接口，**文件/WS/REST 全部零隧道**。

防摆：module 一次闸 + sessionStorage 30s（与 remint 同纪律）。安全面：relay-mint 会话**腿无关**（`GatewaySessionStore` 仅 local-ticket 绑环回，`GatewayAuth.scala:103`），环回兑换合法；binding revoked 时 mint 被拒 ⇒ 客户端静默停留现状。

### 修复 B · 心跳×传输解耦（兜底，诊断方向②）

`web/js/ws.js`：`window.fetch` 单点包装计 `/api/nf-file` 在途传输数（计数挂到**体消费完成**——blob/text/arrayBuffer/json——或 5min 泄漏保险，头部到达不落幕）；`hbProbe` 判死前先看计数：传输在途 ⇒ 本窗 miss 转入遮蔽计数（`shelteredMisses`，**硬上限 12 窗**，超限照常判死），收到 pong / 新连接即清零。效果：大文件传输期 pong 迟到不再触发重连；真死连接在传输掩护下最多赖活 12 窗（≤6min @30s 宽限上界）。媒体标签腿（`<img>/<video> src`）走独立浏览器连接不阻塞 WS，不计数、不遮蔽。

### 未做（边界）

- relay.rs（Rust）与门户页（网站仓）零改动——「同机近路探测的门户消费侧」仍归门户仓；本批让**控制台页**自己完成同一判定，不依赖门户探测命中。
- `readFile` 2MB 单帧 WS content 未改分块协议（隧道层已有 256KiB 帧切分 + 公平发送锁；近路命中后本机腿 2MB 直发无碍）。
