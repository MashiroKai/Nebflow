## 1. 根因（网关日志 + 代码走查双证）

**现状判定（原任务问题①的答案）**：`canvas.js popoutCardWindow` 以相对 URL
开窗 ⇒ 弹窗 origin **跟随会话入口 origin**（无硬编码）。作者从官网入口进
（link.mystand.space，已认证 relay-mint 会话）⇒ **弹窗全程走隧道**——
页面、模块图、WS、文件字节全在隧道腿；弹窗内自己的近路自跳链
（ws.js attemptLoopbackNearPath）因防摆闸/探测/mint 失败而静默停留。

日志取证（/Users/kaiyu/.stand/logs/stand.log，2026-10-29）：

  page probing local port anchor)` —— 报障前 1 分钟内父页与弹窗**两页都在
  relay 腿**探测（该端点只有 relay 腿页面会调）；若任一页已跳本机，不会再有
  第二次调用。
- 10:44:44–10:45:01 `portal uplink inbox full … depth=64/64` 连续刷屏 ——
  隧道单上行（FIFO 64 槽）被挤满（多设备轮询 + SW 对账波 + 大文件传输）。
- `tunnel-per-ip-cap` 429 风暴：全天 6094 连拒；11:03:55 单窗 238 条
  （tunnel guard per-envelope-IP 1024 req/60s，作者全部设备共享
  envelopeIp=5.34.216.70 一个桶，基线轮询已 ~850-1170 req/min 贴线）。
- 11:06 弹窗空白形态 = 模块图在拥塞管道上挂起/失败：index 静态壳的
  `.canvas-header` 空玻璃胶囊可见（截图一致），main.js 永不启动，
  canvas.js 引导态面自己也在模块图里 ⇒ 无人报错。

## 3. 测试与耗时对比

- tests/cardwin-local-direct.spec.mjs：16/16 绿（spec-run.log 全文）。
  - T1 直连主链：弹窗落 http://127.0.0.1:<local>/；深链保真（兑换 303 后
    card-window=1&path 在、ticket 剥离、cwdir=1）；**LIVE 网络面：弹窗 226 个
    请求全部落本机 origin，off-origin = 0**；经 relay 铸票恰一发；PM 桥双向
    （跨源卡窗 3.5s 仍活 + 合并→bye→独立标记解除）。
  - T2 回落腿：无验证基址 ⇒ 弹窗跟入口 origin（隧道现状零变化），零铸票。
  - T3 首开耗时（同 harness，relay 每请求 60ms 时延注入，无 SW 冷缓存口径）：
    - 直连首开（弹窗落本机）：**244ms**
    - 隧道首开（弹窗跟入口 origin）：**2330ms**（≈9.5×；60ms/req 是拥塞管道
      的温和注入，作者实况 10:45-11:06 远差于此）
  - T4 本机父页回归：已在直连腿 ⇒ 相对开窗同源（现状零回归）。
  - T5 看门狗：main.js 挂 ⇒ 15s 注入可见失败卡 + 重试带 ?nfsw=0。
- ConsoleTicketRoutesSpec：12/12 绿（含 2 条新深链钉：303 保留非票参数、
  ticket 永不回显、无参腿 Location: / 不变；http4s query 渲染 %2F→/ 为
  canonical 口径，URLSearchParams 解码等值）。
- 既有回归全绿：cardwin-session-scenarios 11、canvas-card-window 22、
  cardwin-content-only 23、loopback-nearpath、nearpath-dualhost。
