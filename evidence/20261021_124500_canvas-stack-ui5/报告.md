## 三、⑧ canvas 单卡独立窗口

- **独立**：卡头 toggle（三面同源：桌面标题头 `#canvas-pop-btn`、环卡卡头 `.deck-card-pop`、手机卡片头 `.mobile-card-pop`）→ `window.open('/index.html?card-window=1&path=…')` 同源最小查看器路由——卡窗自身经既有 `readFile → fileContent → workspace-open-item → renderFile` 通路渲染真容（md/monaco/html/img/pdf 全家桶零新渲染代码），卡窗只读镜像（编辑回主窗，杜绝双写者）。
- **合并逻辑**：toggle 同位换形（未独立「独立」⧉ / 已独立「合并」⇲ 高亮）；卡窗 ×（独立窗卡头「合并」钮 / ESC / pagehide）→ BroadcastChannel `bye` → 主窗同一条 `mergeCardWindow`（**关窗等价**）；主窗 WindowProxy `win.closed` 600ms 轮询兜底（Cmd-W/崩溃也收敛）；主窗心跳 3s + 卡窗 20s 静默自守卫（绝无僵尸镜像）；主窗刷新后由卡窗 `hello/welcom` 再收养。
- **状态同步**：内容更新 = 主窗 renderFile 后 `notifyCardUpdate` 广播 → 卡窗 `cardWindowReread`（清冷却走 `scheduleFileRefresh` 专用通道重读，防抖 300ms 保留）；合并/关闭后主窗卡片恢复原位原态（页签从未离场，占位不消失）；重复点击幂等（Map 判重直返）；独立中主窗卡面 `data-independent`「独立中」轻态浮标 + 环卡同名条 chip。
- **动画双向**：独立 = 主窗卡面 `nf-card-pop` 脉冲 + 卡窗 `nf-card-win-in` 放大淡入；合并 = 卡窗 `nf-card-win-out` 收缩淡出 + 主窗卡面 `nf-card-restore` 回弹展开；`prefers-reduced-motion` 直切（类不加、窗即关）。
- **手机端设计注记**：选**新标签页**姿态（`window.open` 不带 features、直切无动画）——同窗全屏路由会卸载主窗状态/丢画板面板，新标签与桌面共用同一 BroadcastChannel 协议链路，合并回笼等价；入口 = 移动卡片头 `.mobile-card-pop`（navController 腿，文件卡才显示）。
- 隔离：卡窗 `persistTabs/restoreTabs` 零存档副作用（绝不把主窗整组标签覆盖成一张卡）。
- spec：`tests/canvas-card-window.spec.mjs` **22 PASS / 0 FAIL**——CW1 独立链（真容/标记/两形态换形/占位不消失）、CW2 内容同步（主窗 v2 → 卡窗跟随）、CW3 合并链+幂等（终态=弹出前快照、无窗泄漏）、CW4 关窗等价（外部 close ≤5s 回笼、终态全等）、CW5 reduced-motion 直切、CW6 手机 375 新标签页姿态。
