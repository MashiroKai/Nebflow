# 独立窗口空白页 · 诊断修复批（2026-10-22）

作者实测：控制台卡片「独立窗口打开」⇒ link.mystand.space 独立窗整页空白
（标题栏 S logo + 域名，内容纯白）。

## 根因结论

**打开链 404，与会话无关。**

1. 独立卡窗（UI 批⑧，933e8b742）的打开 URL 是
   `/index.html?card-window=1&path=…`（canvas.js `popoutCardWindow`）。
2. 网关静态路由**只把 `/` 派给 index**（WebSocketRoutes `GET -> Root` →
   `StaticRoutes.indexResponse`）；`/index.html` 不在任何路由里，落根文件
   白名单（sw.js/favicon 族，WebSocketRoutes `GET -> Root / fileName`）之外
   ⇒ **HTTP 404 + `Content-Length: 0` 空体**（本机网关 curl 实证：
   `GET /index.html` → 404，空体；`GET /` → 200）。
3. 弹窗渲染的就是这个空 404 体 ⇒ 整页纯白、`<title>` 为空 ⇒ 标题栏只显示
   S favicon（独立请求，200）+ 域名 —— 与作者截图逐项吻合。
4. 旧批 spec（canvas-card-window 22/0）没拦住：其静态服把 `/` 映射到
   `/index.html`，掩盖了网关路由差异；且断言全在 DOM 层，不涉及「服务端
   是否真有这条路由」。

**会话平面（诊断方向 1 的答案）**：同源 `window.open` 自带 cookie 会话，
无凭据注入面，会话从来不是这次白屏的挡板。死会话形态由 ws.js 既有自愈链
收口：WS 握手被拒 ⇒ `remintHostSessionAndReload`（relay 会话在 ⇒ 静默重铸；
relay ingress 拒 ⇒ 引去 `/api/auth/login?return_to=<原地址>`；直连 LAN ⇒
账号登录模态）。

**SW 平面（诊断方向 2 的答案）**：审计 sw.js 无罪——导航腿网络优先、404
体从不入缓存、断网才有索引兜底副本、/api 零接触。若 SW 已在位，404 导航
反而会被索引兜底副本救活；作者生产窗拿到的裸 404 说明当时该 origin 尚无
活跃 SW（console-load-perf 批当日才落，boot jar 口径未重启），不构成修复面。

## 修复面（三件）

| # | 文件 | 内容 |
|---|---|---|
| 1 | `web/js/canvas.js` | 打开链改口 `/?card-window=1&path=…&title=…`（`popoutCardWindow`，桌面+手机同源）；新增卡窗引导态面 `cardWindowBootFace`：开窗即「正在打开…」，真容挂载即撤；超时（12s）或 WS 握手被拒（`nebflow-ws-rejected` + 2s 宽限）⇒ 错误态卡片（WS 未连过 ⇒ 「登录状态可能已过期」文案 + [重试]，reload 重走 remint/登录链）——未认证/加载失败态永不白屏 |
| 2 | `web/js/ws.js` | 握手拒绝分支派发 `nebflow-ws-rejected`（卡窗引导面快失败钩子） |
| 3 | `WebSocketRoutes.scala` | `GET/HEAD /index.html` 别名 → 同一 brand 注入 index（query 原样保留）；历史/深链兜底，根文件白名单不扩权 |

 locales：`canvas.cardwinFailHint` / `canvas.cardwinAuthHint`（zh/en 双语）。

## 验证

- `tests/cardwin-session-scenarios.spec.mjs`（新，网关忠实静态服：`/`→index、
  `/index.html`→404 空体、WS upgrade 拒）**11 PASS / 0 FAIL**：
  - S1 有会话开窗直达内容：主窗点「独立」⇒ 独立窗落 `/?card-window=1…`、
    真容渲染、零 `/index.html` 请求、引导面即撤、无登录面、零 JS 错；
  - S2 无会话（relay 形态）：引去 `/api/auth/login?return_to=…`，
    return_to 原样回带 card-window 参数（登录回来直达同一卡窗）；
  - S3 无会话（直连 LAN 形态）：就地不白屏双面 = 「登录过期」错误卡（快失败）
    + 账号登录模态，无导航循环。
- `tests/canvas-card-window.spec.mjs`（既有）22 PASS / 0 FAIL（打开链改口后回归）。
- `IndexEntryAliasSpec.scala`（新）：真实 WebSocketRoutes 路由表驱动 ——
  `/index.html`（含 query）=200 brand 注入 index、HEAD 空体 parity、`/` 零变化、
  根白名单不扩权（未知根文件仍 404）。
- checkJs：257 = 基线，零新增。
- 截图：`shots/before-old-url-404-white.png`（旧链 404 空体 = 作者白窗逐位复现）、
  `shots/after-new-url-content.png`（新链弹出即真容）。
  生成器：`tests/cardwin-whitepage-shots.mjs`。

## 生效口径

前端改动随刷新生效（`/` 与 `/index.html` 双入口都通）；Scala 别名随下次
引擎重启窗生效（boot jar 口径）——别名是兜底面，现役打开链改口后不重启
也已消除白屏。
