## 复核方法（纯标准库复算 RMS，实测输出与 readings.json 一致）

```
python3 - <<'PY'
import wave, struct, math
p = "evidence/20261102_fm-threeface-align/mic/transcribe-seg1.wav"
w = wave.open(p); n = w.getnframes()
data = struct.unpack("<%dh" % n, w.readframes(n))
print("%.5f" % math.sqrt(sum((s/32768.0)**2 for s in data)/n))
PY
```
