## 交付面

1. **vault 发现式注册（零配置）**：项目挂载即注册 `<workspace>/docs` vault；
   卸载/归档项目自动消失（`ProjectStore.list` 单一来源）。
2. **子项目层级（约定式）**：vault 内任何 `SUB/docs` 直接子目录即子 vault
   （递归 ≤3 层、每 vault ≤32 个）；父图谱渲染**聚合节点**（双环石墨圆点 +
   `名称 (N)`常显标注）→ 详情卡「进入子图谱」下钻 → 面包屑 `X › sub` 回溯。
3. **面板项目切换器**：左栏控制面头部 + 移动层 panebar 同款 glass `<select>`
   （`--glass-*` 家族材质）；默认「全部项目」= pre-#744-B 合并视图（形状
   逐字节兼容）；选项来自 `GET /api/wiki/vaults` 轻量清单（不做内容扫描）。
4. **多图谱数据管线**：每 vault 独立 VaultScan + 独立缓存键
   （`merged` | `p:<project>` | `p:<project>|v:<vault>`，TTL 30s 不变）；
   单视图响应带 `view/childVaults/stats`；跨 vault 引用解析为
   `external:true` 占位——计数「N 条跨库引用」、永不画成节点、永不进断链清单。
5. **校验按 vault 独立跑**：check_wiki_docs.py 新增 `--include-subvaults`
   （逐 vault 独立 R1-R3 + 跨 vault 引用 info 级 `cross-vault-link`）；
   **无旗标调用输出逐字节不变**（--json 与人读双侧 diff main 验证）。
6. **C 批接口**：`?project=__user__` 预留（空占位视图 `reserved:true`）。
7. **A 批兼容**：段落锚维度零触碰（edge.anchor/headings/blocks 原样），
   项目/vault 维度与段落锚正交；合并冲突按语义解（A 段落锚 = B 项目面）。
