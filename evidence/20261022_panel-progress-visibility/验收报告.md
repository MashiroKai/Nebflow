## 1. 改动面总览

### #752 空闲 delegate 在等什么（可见化）

后端（数据源面）：
- `gateway/WebSocketRoutes.scala` `activeAgentEntryJson`：快照出帧补五字段——
  `currentTool`（在飞/最后工具名）、`lastActivityMs`（agent 侧活动戳）、
  `outstandingSubagents`（barrier spawn 计数）、`bgWaiting`（会话自有等待型
  后台任务 `{taskId, description, startedAt}` 数组）。
- `gateway/WsSessionChatHandlers.scala` `handleGetActiveAgents`：快照组装时
  一次全表扫描 `BgTaskRegistry.waitingBySession`（按自有 sessionId 分组、
  persistent 过滤），逐行查自有集——禁逐行查表。
- `core/tools/BgTaskRegistry.scala`：新增 `waitingBySession`（#752 数据源）
  与 `lineCounts`（#753 快照行数面，见下）。

前端（呈现面）：
- `js/main/bgAgents.js`：`bgIdleDetail()` 空闲细分判据链（多命中全显、顿号连接）——
  ① 等后台任务 ×N：名+已运行时长（快照 `bgWaiting`，引擎 bg-wait 屏障自有子集）；
  ② 等子代理回执 ×N（heldReceipts + unreadReceipts + outstandingSubagents）；
  ③ 长空闲提醒徽标：Idle 且 ①②皆空、`lastActivityMs` 距今 >10min → 琥珀字
  「空闲 N 分钟，无在飞工作」（`role=alert` + timer-off 图标）。idle/waiting 行
  次行渲染（`bg-task-idle-detail`），active 行零变化。
- `js/main.js`：activeAgents 快照合并携带新字段（快照权威、实时值不降级——
  currentTool 例外面：实时值优先、快照 currentToolName 兜底）；agentStart 跨
  turn 保留同款。
- `js/bgAgentWorkStrip.js`（新模块）：delegate 详情弹窗「会话在做什么」条——
  最近动作（在飞工具名/思考中/停靠等待/空闲细分透传/长空闲徽标）+ 本会话
  后台任务行（描述·状态·行数·时长，点击行 = openBgTaskOutput 输出卡，零新弹层）。
  15s 自刷新拍，弹窗关闭即停（幂等卸载）。挂载点 = `bgAgentPopup.js`
  openStepPopup（摘要条之下），closeStepPopup 成对卸载。
- `js/bgTaskOutputPopup.js`：运行中且暂无输出的明示——placeholder 改
  「运行中 · 暂无输出——等待型任务（轮询/监听）可能整段无 stdout，进程仍在运行」；
  meta 段运行态补「已运行 {dur}」（等待型任务行数/字节恒 0，时长是「还在跑」的
  唯一可见信号）。

### #753 后台任务输出流式可见 + waiter 刷屏闸

引擎侧速率闸（熔断）：
- `core/tools/BgTaskRegistry.scala`：`BgRateGate`（纯判定面，spec 直测）+
  `gateCreation`（IO 面，判定与记账一次 Ref.modify，并发无竞态双记）。两档：
  - 告警档：窗口内创建数达 `BgRateWarnAfter`（默认 12/10min）→ 引擎告警日志；
  - 熔断档：窗口内既有创建数达 `BgRateBreakerAfter`（默认 20/10min）→ 熔断
    `BgRateBreakerCooldownMs`（默认 10min）——期间该会话新后台任务创建一律
    拒绝（可读错误回执给 LLM，文案给出替代姿势：等完成通知 / 收敛为 ONE 个
    轮询任务 / 结束 turn 而不是等待）。
- `core/tools/BashTool.scala`：显式 run_in_background 路径**前置**闸（拒绝 =
  不建任务）；前台预算转后台收编路径事后记账（本拍已在前台跑着不能拒，熔断
  生效后下一个被拒）；`persistent=true`（服务型 server）不设闸（合法低频）。
  熔断**触发沿**向 wsSend 发 `bgRateAlert` 帧（激活期重复拒绝不重发——防告警刷屏）。
- `shared/Defaults.scala`：四常量（带 `nebflow.bg.rate*` prop 缝，I2 先例同款）。
- 前端：`ws.js` TERMINAL_MSG_TYPES 收编 `bgRateAlert`（无 sessionId 过滤集同律
  ——否则入口过滤器静默丢弃、toast 永不出现）；`main.js` bgRateAlert 处理器
  → toast（作者不点开面板也看得见「某会话在刷后台任务」）。

面板侧（输出流 + 行数 + 聚合）：
- 行数 chip（「永远 0 行」的收口）：实时行走心跳 `outputLines`（既有、实证截图
  中 sbt 行 6行/8行 即此路径）；**快照恢复行**（页面刷新后无心跳）此前无来源 →
  `activeTasksJson` 快照补 `outputLines`（`BgTaskOutputStore.lineCounts` 一次
  全表取当前总行数），前端 `hb?.outputLines ?? task.outputLines`；终态行也显示
  （可回看语义）。
- 同族聚合（waiter N 递增族收起为一行）：族键 = description 去数字归一
  （"background waiter 67" → "background waiter N"；无数字描述自成族）；
  族内 ≥3 条 → 一行组头（默认收起）：状态聚合点 + 运行中 ×N / 已毕 ×N +
  「同族 ×N」chip + Σ行数 + 族龄（最早 startedAt）+ carets；点击展开成员行
  （缩进一格、保留取消按钮与输出卡交互——回归红线）；再点收起。展开态按
  （桶 sid, 族键）记模块级账本（512 键护栏）。头部计数 = 桶真值不变
  （badge == bucket 不变量保持）。
- 实测修复的本批引入缺陷：族头重渲会 detach 被点行 → click 冒泡到 document
  的「点击外部收起」守卫时 `contains(脱离节点)=false` → 面板被误关（展开一帧
  即收起）。族头 handler `stopPropagation` 拦在行级；键盘 Enter/Space 等价
  （APG listbox 先例）。
- 输出流式：既有 2s 轮询尾随 + 增量追加 + 滚动跟随保持；「点进去永远空」的
  语义面见 #752 的 waitingLive 明示（等待型任务整段无 stdout 是常态，不再
  貌似空数据）。

## 4. 已知边界（申报）

- `bgWaiting`/回执计数来自**快照拍**（面板打开时 `getActiveAgents` 回填 +
  15s 弹窗刷新拍）——两拍之间新产生的等待不即时上屏（快照轮询是既有口径，
  本批未引入主动推送）。
- 族聚合键基于描述文本归一：描述格式突变的同族（如 `waiter #068` vs
  `waiter 68`）不成一族——保守侧（漏聚合 ≠ 误聚合）。
- 熔断闸按 `ctx.sessionId`（执行会话）计；同一根会话下多个子会话各自计数
  （单会话刷屏是实证形态，按会话闸即可收敛）。
- e2e §G 的弹窗开启走生产模块入口直调（行点击出口在合成序列中的点序依赖，
  与本批改动面无关；行点击路径由邻族 spec 钉住）。
